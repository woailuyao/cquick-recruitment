\## USART 串口练习



我用 STM32F1 的 USART1 做了一个简单练习：串口助手发送字符 `0` 时点亮 PC13 板载 LED，发送 `1` 时熄灭。串口设置是 115200、8N1。USART1 重映射后，PB6 是 TX、PB7 是 RX，所以 USB-TTL 的 RXD 接 PB6，TXD 接 PB7，另外还要共地。



代码和测试照片放在这个文件夹里：`串口接收控制LED.png`、`02\_串口重映射和初始化.png`、`实物图（亮）.jpg`、`实物图（灭）.jpg`。



\## 调试时遇到的问题



刚开始我打开的是 `USARTLibTest`，以为它会根据串口数据控制 LED。看了实际运行的代码才发现，它是在等一整行数据，收到 CRLF 后再把内容回传，LED 控制部分当时被注释了。后来我换到 `预习USART` 工程，自己写接收字符控制 LED。



写初始化时我也漏了 GPIOB、GPIOC 的配置，还把 PB6 和 PB7 的初始化弄乱了，检查后才修好。烧录完成后 LED 还是没反应，我一开始怀疑串口接线，后来发现忘了按 RESET；复位后再发送数据，LED 才按预期变化。ST-Link 一开始插在扩展坞上也无法识别，换到电脑的 USB 接口后就能下载了。



\## 这次记住的事



PC13 板载 LED 是低电平点亮，所以输出低电平会亮，输出高电平会灭。调串口时除了检查代码，也要确认选对工程、参数和接线正确，并且烧录后的程序已经开始运行。
