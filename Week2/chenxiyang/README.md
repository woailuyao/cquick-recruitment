## 任务 3：通信方式对比（Topic / Service / Action）
| 通信方式 | 模型 | 特点 | 足球机器人典型场景 |
| --- | --- | --- | --- |
| 话题 Topic | 发布/订阅，多对多 | 单向、持续流、不管对方在不在 | 视觉持续广播球位置 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 执行清屏操作 `ros2 service call /clear` |
| 动作 Action | 目标/反馈/结果 | 长任务、报进度、可取消 | 走到指定点并中途反馈进度 |

## 差速三公式
- 线速度：v = (vL + vR) / 2
- 角速度：ω = (vR - vL) / L
- 转弯半径：r = v / ω
