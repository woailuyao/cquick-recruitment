## 1. 串口四参数

| 参数 | 是什么 | 常见值 |
|---|---|---|
| 波特率 | 每秒传多少位，收发双方必须一致 | 115200 / 9600 |
| 数据位 | 一个字符用几位 | 8 |
| 停止位 | 一帧的结尾标志 | 1 |
| 校验位 | 简单查错 | 无（N） |

默认组合叫 8-N-1。

（收到一堆乱码。不是设备坏了，是两边采样节拍对不上——接收方在错误的时刻去读电平，读出来就是随机的 0/1。就好比两个人约好"每秒说一个字"，一个说快了、一个听慢了，听到的只是一串听不懂的音节。）

## 1.5 串口硬件连接（半双工 / 共地 / 电平）
单线半双工：收发共用一根信号线，自己发出去的数据自己也会“听到”。所以同一条总线上不能两个设备同时说话，必须靠指令里的 ID 轮询来避免冲突。

必须共地（GND）：两个设备只有电平参考点相同，才能判断“高”还是“低”。只接 TX/RX 不接 GND，收不到数据是必然的，因为电平没有一个共同的零“点”。

电平必须匹配：5V 和 3.3V 的设备不能直连，会烧毁 3.3V 那一侧。要么加电平转换模块，要么确认器件本身兼容。

## 3. 波特率不一致的原理

 波特率 = 每秒传多少位，发送方按自己的节拍一位一位往外推；
 接收方按自己的节拍去采样每一位，两边节拍一致才能采到正确的 0/1；
不一致时，接收方在错误的时间点采电平，采出来就是乱码。
打个比方：两个人约定每秒说一个字，一个说快了，另一个就听错。
115200 和 9600 差 12 倍，必然全乱。）

## 4. 舵机指令逐字拆解

以 `#001P1500T1000!` 为例：

| 段 | 含义 |
|---|---|
| `#` | 指令起始符 |
| `001` | 舵机 ID，固定 3 位，1 号写 001 |
| `P` | 功能码，P 表示写角度（PWM 位置） |
| `1500` | PWM 值，固定 4 位，范围 500–2500，1500 = 中立位 |
| `T` | 功能码，T 表示时间 |
| `1000` | 时间值，固定 4 位，单位 ms，舵机用这么久平滑转到位 |
| `!` | 指令结束符 |

通信参数：波特率 115200，供电 5–8.4V。

**自己写的两条：**

- 让 1 号舵机转到中立、用 1.5 秒：`#001P1500T1500!`
- 让 3 号舵机卸力：`#003PULK!`
