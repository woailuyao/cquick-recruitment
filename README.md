## 如何提交（Fork + Pull Request）

两个组流程完全一样：

1. **Fork** 本仓库到你自己的 GitHub 账号（右上角 Fork 按钮）；
2. **Clone** 你自己 Fork 出来的仓库到本地；
3. 进入**你所在组的对应周目录**，新建你的**个人文件夹**（姓名拼音）；
4. 按该周 `README.md` 里的目录规范放入文件（代码 + 截图 + 说明）；
5. `git add` → `git commit -m "..."` → `git push`；
6. 回到 GitHub，在你自己的仓库页面发起 **Pull Request**。

> **不要**直接往主仓库 push，也不要自创目录层级 —— 目录结构是统一的，评审批量对照。

## 命名规范（两组通用）

- **个人文件夹** = 姓名拼音，全小写，不要空格（如 `zhangsan`）；
- **截图/结果图** = `序号_内容.png`（如 `01_环境自检.png`、`02_运行日志.png`）；
- **说明文件** = `README.md`，每组都有现成模板，复制改名即可；
- 路径一律用**相对路径**，脚本里别写死自己电脑上的绝对路径。

## 防抄袭（两组通用）

关键截图必须带「**姓名拼音 + 实时时间戳**」，截关键图前先在终端执行：

```bash
echo "姓名: <你的姓名拼音>"; date "+%Y-%m-%d %H:%M:%S"
```

把这行输出**和命令/运行结果截在同一张图里**。无时间戳 → 未自证扣分；同图复用 / 姓名对不上 → 该项 0 分。

## 提交前的三条硬提醒

1. **别提交大文件**：不要传数据集、模型权重、虚拟环境、`__pycache__`、缓存目录；单文件尽量控制在 10 MB 内；
2. **别覆盖别人的文件夹**：只在你自己名字的目录里写东西；
3. **README 别敷衍**：写清「做了什么 / 遇到什么问题 / 怎么解决的」，这比多交几张图更能拿分。
