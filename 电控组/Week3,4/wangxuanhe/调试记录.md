## 已知未解决问题与如实说明

- **三遍耗时不完全一致**：6.45 / 9.08 / 6.53 s。第 2 遍中途有一次 PRAD 未到位重发，多等约 2.5 s。动作路径三遍相同，不是用 `sleep` 猜时间导致；要压平就把 `duration_ms` 再放大一档（屈膝 3500、髋前压 3000）。
- 该控制板不支持 `#001PID!` 回读 ID，只能用 `#001PRAD!` 位置回显间接证明，属硬件限制，已在 README 与 `01_PID回显.png` 标注。
- 加分项四项行为（PRAD 重发 / 看门狗卸力 / 动作组抢占 / 串口重连）在代码与运行日志里都能看到，但没有单独截图；`加分项/verify_bonus.sh` 给了逐条取证顺序，需要时按它补拍。
- 1、6、7 号关节在 ±30 小幅度下曾经卡住不动，换 ±150 大摆确认三颗都能正常运转——小幅度时卡的多半是「带载 + 幅度小于到位容差」，不是结构卡死。
- 任务 3 的 `03_ID扫描.png`、`03_多舵机动作_关键帧.png` 里姓名+时间是同一屏幕的另一个终端窗口打印的（`sign` 别名），时间真实、未做后期处理。
