# 03_串口与总线舵机笔记

## 1. 串口四参数
| 参数 | 说明 |
| ---- | ---- |
| **波特率** | 波特率是串口通信中每秒传输的二进制位数，通信双方必须使用完全相同的波特率，这是串口能正常通信的最基本前提 |
| **数据位** | 数据位是数据中真正用来表示一个字符的二进制位数，决定了到底装了多少有效信息，常见为8位，因为一个字节是8位 |
| **停止位** | 停止位是一帧数据结束后的标志位，告诉接收方这一帧已经传完了，常见为1位，还可以给接收方留出缓冲时间来处理上一帧的数据 |
| **校验位** | 校验位是错误检测位，用来判断传输有没有出现01翻转，常见有无校验、奇校验和偶校验，大多选无校验，因为串口通信本身可靠性已经足够，加校验反而会占用带宽 |

波特率不一致就会收到一堆乱码，串口通信靠时间节拍来对齐，波特率不一致导致收发的速度不一样，接收方采样的位置就会慢慢偏移，形成错位，造成乱码

单线半双工：指收发共用一根串口线，同一时间只能有一个设备发送数据，且本设备发出的数据自身也能接收到。

共地（GND 必须连）：共地指通信双方的GND必须物理相连，否则电平参考点不一致，接收端无法正确识别高低电平。

电平不匹配：5V和3.3V设备不能直接相连，否则高压侧会向低压侧引脚灌入过压，永久损坏低压芯片。

## 3. 波特率不一致的原理
串口通信没有独立的时钟线，收发双方靠提前约定好的每一位持续时间来对齐，这个时间长度就是波特率决定的，双方各自用本地时钟独立计时，只要双方约定的每位持续时间一致，接收方就能在每一位准确采样，逐位还原出发送的数据；波特率不一致，收发双方的每位持续时间就存在偏差，接收方按照自己的节拍采样时，采样点会随着位数增加逐渐偏移，最终拼接出来的字节和发送端实际发送的字节错位，接收方还原出的数据就是无规则的乱码。

## 4. 舵机指令逐字拆解
指令示例：`#001P1500T1000!`
| 字符 | 含义 |
| ---- | ---- |
| # | 指令开头标志，告诉舵机一条新指令开始了 |
| 001 | 舵机ID，必须三位，001表示一号舵机 |
| P | 功能码，后面跟PWM值 |
| 1500 | PWM 值，范围 500~2500，1500对应中间位置 |
| T | Time，时间的意思，后面跟转动时间 |
| 1000 | 表示用1000ms即1s的时间转到目标位置 |
| ! | 指令结束标志，告诉舵机这条指令发完了 |

- 让 1 号舵机转到中立、用 1.5 秒：`#001P1500T1500!`
- 让 3 号舵机卸力：`#003PULK!`
