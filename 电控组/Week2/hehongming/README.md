## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅，多对多 | 单向、持续发送、不管对方在不在 | 视觉节点持续广播场上球的位置 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 发送清屏指令、切换防守模式 |
| 动作 Action | 目标/反馈/结果 | 长任务、报进度、可中途取消 | 控制机器人底盘移动至某个精确坐标 |

**我实际用到的服务调用**：任务 2 开始前调用的 `ros2 service call /clear std_srvs/srv/Empty`。因为它是一次性的请求并等待返回结果，清空画面后即结束，不需要像话题那样持续不断地发布数据流。

## 四、差速三公式

- `v = (vL + vR) / 2` → 机器人中心点的线速度等于左右轮速度的平均值。
- `ω = (vR − vL) / L` → 机器人的角速度由左右轮的速度差除以轮距决定。
- `r = v / ω` → 机器人的转弯半径，线速度越大或角速度越小，转弯半径越大（走得越直）。

## 五、踩过的坑 & 怎么解决的

1. **CMake 编译报错缺少 `rosidl_interface_packages`** → 查阅报错日志发现缺了分组声明 → 在 `package.xml` 中添加了 `<member_of_group>rosidl_interface_packages</member_of_group>` 后解决。
2. **`ros2 run` 报错 `Exec format error`** → 排查发现是 Python 脚本第一行缺少 Shebang，且文件带有 Windows 的 CRLF 换行符 → 在文件首行加上 `#!/usr/bin/env python3`，并把编辑器右下角改为 LF 格式后成功运行。
3. **Git 拉取/推送频繁报 `GnuTLS recv error` 和 `OpenSSL 不支持`** → 尝试修改 Git 的 SSL 后端无效后 → 最终通过使用 `gh-proxy.com` 的代理前缀，成功绕过了不稳定的网络连接。
4. **脚本找不到（No executable found）** → 编译时忘记在 `CMakeLists.txt` 中 `install(PROGRAMS ...)`，且没有对 `.py` 文件执行 `chmod +x` → 补全安装脚本并赋权后解决。
