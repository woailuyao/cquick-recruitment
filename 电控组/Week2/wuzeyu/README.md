## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
| :--- | :--- | :--- | :--- |
| 话题 Topic | 发布/订阅，多对多 | 单向、持续流、不管对方在不在 | 视觉持续广播球位置；战术持续广播速度指令 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 「现在比分多少」「切到防守模式」 |
| 动作 Action | 目标/反馈/结果 | 长任务、报进度、可取消 | 「走到点(1,1)」→ 过程报进度，可中途取消 |

**我实际用到的服务调用：**
任务 2 开始前用到了 `ros2 service call /clear std_srvs/srv/Empty`，说明它为什么是服务而不是话题：
> 因为清屏是一个明确的“请求”动作，我需要系统给出一个“响应”（清屏完成），它是同步的、一次性的，不需要像话题那样一直持续广播，所以用服务最合适。

## 四、差速三公式

* `v = (vL + vR) / 2` → 线速度等于左右轮速度的平均值。
* `ω = (vR - vL) / L` → 角速度等于左右轮速度差除以轮距。如果右轮快左轮慢，就会左转。
* `r = v / ω` → 转弯半径。速度越快、角速度越小，转弯半径越大；如果角速度为 0，就是直线。

## 五、踩过的坑 & 怎么解决的

> 这一节最值分，别写「没遇到问题」。

1. **现象：** 编译时 CMakeLists.txt 报错 `Install PROGRAMS given unknown argument ")"`。
   **怎么查的：** 看终端红色的报错代码行号。
   **怎么解决的：** 重新用 `nano CMakeLists.txt` 打开文件，发现 `install(PROGRAMS ...)` 里面文件路径没有写完整，括号闭合位置不对，重新按照标准格式每一行写一个文件路径，保存后编译通过。
2. **现象：** 一开始运行发布者，订阅者收不到消息。
   **怎么查的：** 用 `ros2 topic list` 看话题存不存在，用 `ros2 topic info /ball_pos` 看发布者/订阅者的数量。
   **怎么解决的：** 发现是订阅者代码里的消息类型导入写错了，没有导入自定义的 `ball_task_pkg.msg`，改对包名后成功接收。
