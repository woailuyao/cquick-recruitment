## 三、三种通信方式对比
| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布‑订阅，多对多 | 发布者自顾自地发，不管是否有回应以及人数 | 视觉节点持续广播场上球的坐标；战术节点持续下发底盘速度指令 |
| 服务 Service | 请求‑响应，一对一同步 | 聊天一样的，一句一句的，一来一回 | 查询机器人状态；切换攻防模式； |
| 动作 Action | 目标‑反馈‑结果 | 一个很大的任务，走一步看一步，中途可以更具反馈停止 | 机器人自主导航走到指定场地点位，可以中途终止导航 |

**我实际用到的服务调用**：`ros2 service call /clear std_srvs/srv/Empty`。
它是服务不是话题：因为他只执行一次请求，得到一次应答就结束

## 四、差速三公式
- `v = (vL + vR) / 2` → **左右轮转速的平均值，中心的速度**
- `ω = (vR − vL) / L` → **L是两轮轮距，谁快就像那边转**
- `r = v / ω` → **运动转弯半径，转的时候的圈有多大**
