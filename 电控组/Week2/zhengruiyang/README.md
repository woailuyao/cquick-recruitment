## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅/多对多 |发布者持续发布消息，由一个或多个收听者收听。从发布到收听，是单向的。发布者发布是高频的，形成一条数据流，不管有没有收听都会一直产生。 |视觉节点将球的坐标发布到话题中，战术节点收听到了消息，作出判断后再发布速度指令，让负责运动的节点收听并执行 |
| 服务 Service |请求/响应/一对一 |请求一次就同步响应一次，响应后会有反馈结果 |机器人切换战术，开球，获取目前比分这些一次性立刻执行的任务 |
| 动作 Action |目标/反馈/结果 |发一个长任务，执行过程中持续反馈情况，可以提前取消，结束后会反馈结果 |机器人前往某个位置，途中不断反馈情况，可以取消导航 |

**我实际用到的服务调用**：我调用了 `ros2 service call /clear std_srvs/srv/Empty`来进行清屏。它是一次性立即执行的指令，响应后会得到清屏的反馈结果。而话题是持续不断的，没有结束，没有反馈，不是一次性的。所以它是服务。

## 四、差速三公式

- `v = (vL + vR) / 2` → 物理上，左右轮速度相加再除以2就是中心的线速度。线速度就是直线速度或者切线速度。
- `ω = (vR − vL) / L` → 左右轮速度相减再除以宽度，就是角速度。右轮快，角速度为正，顺时针转动，即右转。反之，左转。
- `r = v / ω` → 线速度除以角速度就是曲率半径。半径越小，说明曲线越弯曲，拐的越厉害；半径越大，说明曲线越平直。当v为0，w不为0，就会自转；w为0，v不为0，r趋于无穷，就是直线运动。
