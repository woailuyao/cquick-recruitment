## 二、三种通信方式对比

| 通信方式 | 通信模型 | 特点 | 足球机器人中的例子 |
|---|---|---|---|
| 话题 Topic | 发布者持续发布，订阅者按需接收 | 异步，适合连续状态或传感器数据 | 持续发布机器人位置、相机检测结果或速度指令 |
| 服务 Service | 客户端发送一次请求，服务端处理后返回响应 | 有请求和结果，适合快速完成的一次性操作 | 清空 turtlesim 轨迹；本次用 `/clear` 服务在导航开始前清屏 |
| 动作 Action | 客户端发送长任务目标，执行端持续反馈进度并返回最终结果，也可取消 | 适合执行时间较长、需要反馈或取消的任务 | 让机器人导航到指定位置，并持续反馈距离或当前阶段 |

任务 2 中我实际调用的服务是：

```bash
ros2 service call /clear std_srvs/srv/Empty "{}"
```

`/clear` 的请求为空，服务端处理后清除画布内容并返回响应。它只用于清理轨迹；三点导航是由控制节点订阅位姿话题并发布速度话题实现的。

## 三、差速运动的三个公式

设左右轮的线速度分别为 `vL`、`vR`，两轮间距为 `L`：

1. **车体线速度**：`v = (vL + vR) / 2`
   两侧车轮共同决定机器人向前或向后的速度。
2. **车体角速度**：`ω = (vR − vL) / L`
   左右轮速度不同会让机器人转向；速度差越大，转得越快。
3. **瞬时转弯半径**：`r = v / ω`（`ω ≠ 0`）
   它表示机器人此刻绕瞬时圆心运动时的半径；当两轮速度相同，`ω = 0`，机器人直行，转弯半径可看作无穷大。
