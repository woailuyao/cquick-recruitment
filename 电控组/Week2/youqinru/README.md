## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅，多对多 | 单向、持续、不管对方在不在 | 视觉持续广播球位置；战术持续广播速度指令 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 「现在比分多少」「切到防守模式」 |
| 动作 Action | 目标/反馈/结果 | 长任务、能报进度、可中途取消 | 「走到点 (1,1)」→ 过程上报进度，可取消 |

**我实际用到的服务调用**：任务 2 开始前执行

```bash
ros2 service call /clear std_srvs/srv/Empty
```

用来清掉龟板上之前的轨迹。它是**服务**不是话题，因为返回了一次明确的应答（`response: std_srvs.srv.Empty_Response()`），调一次就结束；而不是像话题那样持续不断地往外发数据。

## 四、差速三公式

- `v = (vL + vR) / 2` → 线速度是左右轮速度的平均值。两轮同速时就是这个速度，一快一慢时取中间值，所以整体前进的快慢由两轮平均决定
- `ω = (vR − vL) / L` → 角速度由左右轮的速度差决定，再除以轮距 L。差值越大转得越快；差值为 0 时 ω=0，就是走直线
- `r = v / ω` → 转弯半径 = 线速度 ÷ 角速度。角速度越小、转得越慢，画出的弧越大；ω 接近 0 时半径趋于无穷大，也就是直线
