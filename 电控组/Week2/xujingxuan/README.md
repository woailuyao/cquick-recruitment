## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅，多对多 | 单向、持续流，不关心对方在不在，会丢帧 | 视觉持续广播球坐标（本任务 `ball_pos`）；决策持续广播速度指令 `cmd_vel` |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值，调一次答一次，调用方会阻塞等 | 开跑前清空画布 `/clear`；查询比分、切换防守模式 |
| 动作 Action | 目标/反馈/结果 | 长任务，过程能报进度、能中途取消 | 「走到点 (9,4)」——走的过程持续反馈，跑偏了能取消 |

一句话记法：**话题是广播，服务是打电话，动作是下单后能查物流还能取消。**

**我实际用到的服务调用**：任务 2 开跑前用
`ros2 service call /clear std_srvs/srv/Empty` 清空画布，让轨迹截图干净。
它必须是**服务**而不是话题：我需要「清完」这个确定的结果，而且只调一次——
用话题的话没有返回值，也说不清到底清没清。

## 四、差速三公式

- `v = (vL + vR) / 2` → 线速度是左右两个轮速的**平均值**：两轮同速前进，车就走直线。
- `ω = (vR − vL) / L` → 角速度是两轮速**之差**除以轮距 `L`：右轮快就左转，左轮快就右转，两轮一样快就不转。
- `r = v / ω` → 转弯半径等于线速度除以角速度：`ω` 越小弯越大，`ω → 0` 时半径无穷大（走直线）。

对应到 `Twist`：`linear.x` 走直线、`angular.z` 原地转、两个都给就是画弧。

## 五、踩过的坑 & 怎么解决的

1. **`package.xml` 被我粘贴成两份，XML 非法。**
   现象：编译前校验报 `junk after document element: line 22`。
   怎么查的：一开始只用 `grep -c` 数 rosidl 标签，数到 3 以为对了——**假通过**；
   后来用 `python3 -c "import xml.etree.ElementTree as ET; ET.parse('package.xml')"` 才看出文件里有两个 `<package>` 根节点。
   怎么解决的：改用 `cat > package.xml <<'EOF' … EOF` 整份覆盖，不再往文件开头粘。

2. **`ros2 run` 报 `No executable found`。**
   现象：包编译通过了，但 `ros2 pkg executables` 是空的。
   怎么查的：`ros2 pkg executables ball_pos_pkg` 无输出 → 说明脚本没被安装。
   怎么解决的：两个原因都踩过——脚本没有执行权限（`chmod +x`），以及 `CMakeLists.txt` 里漏了
   `install(PROGRAMS ... DESTINATION lib/${PROJECT_NAME})`。另外可执行名**要带 `.py`**。

3. **定时器参数是周期不是频率。**
   现象：乌龟几秒才动一下，日志也刷得极慢。
   怎么查的：回头看 `create_timer(0.5, ...)` —— 0.5 是**秒**（2 Hz），写成 10 就是 10 秒一次。
   怎么解决的：改成 `create_timer(1.0 / freq, ...)`，频率和周期永远绑定，改频率不用重算。

4. **`ros2 param set` 在运行期改不了发布频率。**
   现象：`ros2 param set /ball_publisher freq 5.0` 参数值确实变了，但实际还是 2 Hz。
   怎么查的：对照计数——5 秒内仍是 30 条（2 Hz × 3 条 × 5 秒）。
   怎么解决的：参数只在 `__init__` 读一次、定时器只建一次，运行期改了也没人重新建定时器。
   必须用启动参数 `--ros-args -p freq:=5.0`（实测 75 条/5 秒）。

5. **方位角差没归一化，乌龟原地转圈。**
   现象：乌龟朝反方向一直转，转一整圈才继续。
   怎么查的：打印 `e` 发现有 +6.x 的值——本该是 −0.1 的角度差被算成了接近 2π。
   怎么解决的：`e = atan2(sin(e), cos(e))` 把角度折回 `[−π, π]`。

6. **到点不停，冲过界撞墙。**
   现象：日志已经打印「到达」，乌龟还在往前冲。
   怎么查的：查 turtlesim 行为——它每帧都按**最后一条** `cmd_vel` 积分位置，不会自己停。
   怎么解决的：到点先 `publish(Twist())` 发一条全 0 速度刹车，再切下一个目标点。

7. **`ros2 topic info` 报 `Unknown topic`、`ros2 node list` 偶尔返回空。**
   现象：节点明明在跑，查询却说话题不存在。
   怎么查的：重启一次查询就正常 → 判断是 ros2 daemon 缓存了旧索引。
   怎么解决的：`pkill -f _ros2_daemon` 杀掉守护进程（`ros2 daemon stop` 不管用），下次调用自动重建。
