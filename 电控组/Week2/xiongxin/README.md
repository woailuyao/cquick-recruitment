## 二、 三种通信方式对比 & 服务调用
| 通信方式 | 模型 | 特点 | 足球机器人场景 |
| :--- | :--- | :--- | :--- |
| **话题 Topic** | 发布/订阅 | 单向、持续发 | 视觉一直广播球的位置 |
| **服务 Service** | 请求/响应 | 同步、调一次答一次 | 查询当前比分 |
| **动作 Action** | 目标/反馈 | 长任务、可中途取消 | 走到某个坐标点 |

**我在任务 2 中用到的服务调用**：在跑导航前，我执行了 `ros2 service call /clear std_srvs/srv/Empty`。这是一个标准的服务调用，发出去一次请求，小乌龟清空轨迹后返回一次响应，不像话题那样一直持续发送。

## 三、 差速控制三公式
在给小乌龟发 `Twist` 速度时，底层的两轮差速原理：
1. **线速度**：`v = (vL + vR) / 2` （左右轮速度之和的一半，决定了往前跑多快）
2. **角速度**：`ω = (vR - vL) / L` （左右轮速度差除以轮距，决定转弯的快慢）
3. **转弯半径**：`r = v / ω` （线速度除以角速度。如果要直行，角速度为 0，转弯半径无穷大）
