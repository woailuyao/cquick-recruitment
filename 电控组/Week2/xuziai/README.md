| 话题 Topic   | 发布订阅   | 单向异步多对多 | 发布球的·位置，机器人的位置   |

## 四、差速三公式

- `v = (vL + vR) / 2` → 左右轮子速度求平均推算合速度
- `ω = (vR − vL) / L` → 转向角速度
- `r = v / ω` → 转弯半径
