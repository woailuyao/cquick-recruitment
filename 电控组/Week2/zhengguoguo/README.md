## 二、三种通信方式对比表和用到的服务调用

| 通信方式   | 模型             | 特点                                  | 足球机器人典型场景                |
| **话题**   | 发布/订阅，多对多 | 单向且持续、不管对方是否有回应         | 视觉持续广播球位置；战术持续广播速度指令     |
| **服务**   | 请求/响应，一对一 | 同步、有返回值、调一次答一次           | 「现在比分多少」「切到防守模式」         |
| **动作**   | 目标/反馈/结果    | 运行较长时间、不断更新任务进度、可取消  | 「走到点 (1,1)」→ 过程报进度，可中途取消 |
我在任务2中实际用到的服务调用是最开始那条清屏命令，因为服务调令需要响应且只调一次，所以与刷屏的话题截然不同。

## 三、差速三公式

**线速度**：v = (vL + vR) / 2
**角速度**：ω = (vR − vL) / L
**转弯半径**：r = v / ω
