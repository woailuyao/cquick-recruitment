## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| Topic | 发布订阅 | 单向流式、多对多，持续推送数据，无应答 | 底盘速度指令、编码器里程、视觉识别球坐标、相机图像流 |
| Service | 请求应答 | 一问一答同步调用，单次触发，执行后返回结果 | 仿真画面清零、急停触发、读取静态参数、硬件状态单次查询 |
| Action | 目标-反馈-结果 | 长时任务，持续反馈进度，支持中途取消 | 自主导航、定点射门、自动带球等耗时可中断任务 |
**我实际用到的服务调用**：<clear 是一次性操作，发一次请求执行完就结束。话题是一直源源不断往外发数据，不适合这种单次指令，所以选service。

## 四、差速三公式

- `v = (vL + vR) / 2` → <小车整体的线速度，就是左右轮子速度取平均值，两轮速度一样就直着走。>
- `ω = (vR − vL) / L` → <小车转动的角速度，L是两轮之间的距离；两轮速度不一样才会转弯，差得越多转得越快。>
- `r = v / ω` → <转弯半径，半径越大转弯越平缓；半径无穷大就是直行；速度为0的时候原地转圈。>
