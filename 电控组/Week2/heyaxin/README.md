## 三、三种通信方式对比

| 通信方式       | 模型       | 特点                                      | 足球机器人场景                          |
| ---------- | -------- | --------------------------------------- | -------------------------------- |
| 话题 Topic   | 发布者/订阅者  | 单向传递，持续，无应答；一对多，多对多，多对一；异步，不用等待回应       | 不断地输出自身位置坐标，发布速度指令；检测足球和对手位置坐标   |
| 服务 Service | 请求/响应    | 同步，请求发出后会卡住，等待服务端返回结果；有应答；一对一；单次请求，单次响应 | 切换战术模式（防守还是进攻），清楚场上标记位置之类，一键回到起点 |
| 动作 Action  | 目标/反馈/结果 | 长时间任务，中途会反馈进度，可以中途取消                    | 带球前行，自动导航跑接应点，避障移动               |

**我实际用到的服务调用**：任务 2 开始前的 `ros2 service call /clear std_srvs/srv/Empty`。清画布是一次性触发的动作，调用一次执行一次，不需要一直发数据，并且它执行后需要给反馈，所以是服务；而话题是持续流，不适合清画布这种单次触发的操作。

## 四、差速三公式

- `v = (vL + vR) / 2` → 底盘中心线速度，即左右两轮线速度取平均值；当左右两轮速度一致时直行。
- `ω = (vR − vL) / L` → vR 为右轮线速度、vL 为左轮线速度；底盘旋转的角速度取决于两轮线速度差，可以粗略认为若右轮线速度大，就围绕左轮转，角速度为线速度差除以轮距。
- `r = v / ω` → 底盘中心点绕圆弧转动的半径，用底盘中心线速度除以角速度求得。

## 五、踩过的坑 & 怎么解决的

1. 新开终端执行 `ros2 run` 时找不到可执行文件 → 询问豆包 → 检查脚本有没有执行权限，并且新开终端要先 `source`。
2. 修改 `BallPos.msg` 之后，订阅节点报「不存在该消息类型」→ 询问 AI → 因为改 msg 只是改动了文本，没有生成新接口，重新 `colcon build` 编译生成消息接口，然后 `source` 刷新环境。
3. 有时长命令执行不动，排查命令，发现长命令换行导致语法错误；在一条命令写完后再回车，不中途换行拆分。
4. 编译成功，但是 `ros2 interface show` 查看不到自定义消息 → 借助 AI → 发现 `CMakeLists.txt` 里没有配置消息生成相关代码；补全 `rosidl_generate_interfaces` 配置，重新编译。
