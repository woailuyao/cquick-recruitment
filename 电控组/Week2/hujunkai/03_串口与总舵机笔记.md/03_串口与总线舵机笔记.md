                                                                   串口与总线舵机笔记

波特率：比作说话频率，常见的9600   115200    如果波特率不同的话，就比如说话开的和说话慢的在一起两边都听不懂
数据位：串口一帧中真正要传的数据，一般十八位
校验位：检验数据传输是否出错，偶尔误差正常

回环测试（未做，计划下周拿到舵机后补做）
期待看到什么：发出段和接收端的信息是一致的，验证数据的传输是正常的


舵机指令：#数据从这里开始读
                后三位是舵机的编号
                 P是PWM值
                T是运动时间，单位是毫秒
                !结束语
功能	指令	说明
控制角度	#001P1500T1000!	1 号转到 PWM 1500，用时 1000 ms
读 ID	#001PID!	查询当前舵机 ID
读位置	#001PRAD!	读回当前 PWM 位置
恢复扭力	#001PULR!	重新上力（要它动之前必须先发这个）
卸力	#001PULK!	断电前卸力，防堵转PWM发热烧舵机（安全下电必发）
 
自己写：#001P1500T1500!   #003PULK!

注意事项：单线半双工：一个设备用一根线
                共地：两个设备必须共地，否则接受不到数据
                电平不匹配：如果不匹配会烧掉设备
