## 四、差速三公式

- `v = (vL + vR) / 2` → 这其实算的是小乌龟两轮中点的速度，即小乌龟向前跑的速度，左轮加右轮的速度除以二就是中点速度。
- `ω = (vR − vL) / L` → 这个算法就相当于假定左轮不动，那么右轮相对于左轮做圆周运动，那么速度差除以两轮的距离就是角速度。
- `r = v / ω` → 这就是角速度和线速度的定义：v=ω*R.
