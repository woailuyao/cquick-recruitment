## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布订阅 | 单向、持续、可以多对多 | 持续播报球位置、机器人位置 |
| 服务 Service | 请求响应| 有来有回、只执行一次就结束 | 询问机器人位置、询问比分 |
| 动作 Action | 目标反馈 | 在任务过程中报备进度、可取消、内容长 | 机器人在执行行动过程中可以报备位置也可停止 |

## 四、差速三公式

- `v = (vL + vR) / 2` → <线速度是机器人左右轮的速度的平均值>
- `ω = (vR − vL) / L` → <机器人左右轮速度存在差距时会进行转弯>
- `r = v / ω` → <转弯时将轨迹类似于圆周时得到该半径>

## 五、踩过的坑 & 怎么解决的

问题：写完导航代码，执行ros2 run ball_comm nav_turtle提示找不到可执行文件。
我怎么查的：先检查文件有没有加执行权限，再意识到ball_comm是ament_python包，不是ament_cmake，不能用 CMakeLists的install(PROGRAMS)注册节点，查看 setup.py里的console_scripts，发现没有新增nav_turtle的入口。
最后怎么解决的：修改 setup.py，添加 nav_turtle = ball_comm.nav_turtle:main，保存后重新colcon build，新开终端source环境，节点正常启动。
