1 串口四参数
1.1 波特率：衡量符号传输速率的参数，代表每秒传输的符号的个数，常见值为9600和115200。
    波特率不一致会导致接收端采样错位，引发乱码、丢帧甚至通信失败。
    原理：接收端会按照设定波特率的时间间隔对信号线电平采样，如果收发两边速度不一样，采样时机错位，解析出来的每一个字节全部出错，就显示乱码。
    帧错误、奇偶校验错误、丢帧，严重时完全无法通信。
    错误数据需重传，降低有效吞吐量。
1.2 数据位：衡量通信中实际数据位的参数。一个字符数据所占比特数，一般固定8位，代表一帧里面有效数据的长度。
1.3 停止位：一帧的结尾标志，常用1位；接收端检测停止位，代表当前字节接收完毕，准备接收下一个字节。
1.4 校验位：简单检错，无(N)、奇校验(O)、偶校验(E)，机器人项目绝大多数使用无校验N。
1.5 8‑N‑1含义：8个数据位，无校验位，1个停止位。

3 波特率不一致的原理
本质是发送端与接收端的时间基准不同，导致采样点偏移。
比如发送方是115200波特，接收端设置9600波特的情况，两边采样时间间隔不一致，接收端每次采样的时候，没有对准真实数据比特的中间位置，读取到错误电平，会解析出来一堆乱码字符。
4 舵机指令逐字拆解
4.1 将#001P1500T1000!拆成 # / 001 / P / 1500 / T / 1000 / ! 七段。
#指令帧的起始标记，每条总线舵机指令必须以#开头。
001舵机ID，固定3位，不足3位前面补0，这里代表1号舵机。
P位置控制命令标识符，后面跟随PWM数值。
1500PWM值，固定4位，范围 500–2500，1500 = 中立位。
T时间标识符，后面跟随运动时间。
1000运动时间，单位ms，固定4位，代表舵机平滑转动到目标位置消耗1000毫秒（舵机用这段时间平滑转到位，不是瞬间跳）。
!指令结束标志，每一条指令末尾必须以!结尾。
4.2 按照要求书写两条指令
1. 让1号舵机转到中立位置，用时1.5秒：#001P1500T1500!
2. 让3号舵机执行卸力：#003PULK!
4.3 指令格式笔记
功能	    指令	           说明
控制角度	#001P1500T1000!	   1号舵机转到 PWM 1500，用时1000 ms
读ID	   #001PID!	          查询当前舵机 ID
读位置	    #001PRAD!	       读回当前 PWM 位置
恢复扭力	#001PULR!	       重新上力（要它动之前必须先发这个）
卸力	   #001PULK!	       断电前卸力，防止堵转发热烧舵机（安全下电必发）
4.4 总线串口三个重点概念
4.4.1 单线半双工：收发复用同一根信号线；同一时刻总线上面只能有一个设备发送数据。因为自己发出去的数据自己总线上也会收到，所以不能多个设备同时说话，不然会导致信号冲突错乱。
4.4.2 共地GND必须连接：电压高低是相对GND参考点的，只接TX、RX，不接GND，会导致两边电平基准不一致，无法识别高低电平，大概率收不到任何有效数据。
4.4.3 电平不匹配：5V设备和3.3V设备不能直接直连，5V信号直接输入3.3V芯片引脚，会烧毁3.3V一侧芯片。需要增加电平转换电路，或者确认器件支持兼容电平。
