# 03 串口与总线舵机笔记

## 1. 串口四参数
（波特率/数据位/停止位/校验位 逐个解释 + 8-N-1 + 位宽换算）
波特率:每秒传输的符号数，单位波特（Baud），比特率 = 波特率 × 每个符号携带的比特数。DS：一个“符号”是信号在某一时刻可表示的一种状态，比如电压高低、相位、频率等。发送、接收双方必须一致。常见值：115200、9600
数据位:有效数据位数，一个字符用几位。常见值：8
停止位:一帧的结尾标志。常见值：1，一些为了抗干扰、老机器为了兼容会是2
校验位:做简单的错误检测，没有常见值
8N1：1起始位+8位数据位+无校验吗+1停止位
位宽换算：
每帧总位数 = 1 + 数据位 + 校验位 + 停止位
有效数据速率 = 波特率 × 数据位 / 每帧总位数
字节速率 = 波特率 / 每帧总位数
波特率   |位时间      |一帧时间   |帧/字节速率  |有效数据速率
9600     |104.17 µ s |1.0417 ms |960 B/s     |7680 bit/s
115200   |8.68 µs    |86.81 µs  |11520 B/s   |92160 bit/s

## 3. 波特率不一致的原理
异步通讯没有共享时钟，发送/接收方按自己的波特率发送/接收，从起始位开始对齐，波特率不一致时，导致接收方解码错误。通俗来说，双方密钥不一致，接收方去解密码的时候解出来乱码。简单通俗来说是这样
这里随便乱举例，例子不是串口通讯的，但是那个意思
原码：14 11
密钥1：4
密码：11101011
密钥2：2
解码：3 2 2 3
而且，这个波特率不一致的效应会叠加，越偏越多

以下是 大肥鱼 给的原文（引用哈，查重不查引用（））
“串口是异步通信，没有时钟线，靠起始位的下降沿对齐。
接收方对齐后，按自己的波特率算“一个位有多宽”，并在每个位的正中间采样。
双方波特率一旦不同，接收方算出的位宽就偏了，采样点会一帧一帧往外漂。
漂到超过半个位宽，采样就落到隔壁位上，0 被判成 1、1 被判成 0 —— 于是你看到的是 ÿþÃ 这种“有数据但是垃圾”，而不是“没数据”。
所以乱码 ≠ 线断了、≠ 设备坏了。线断了是一个字节都收不到，波特率不对是收得到但全是垃圾。这个区分写进笔记，是加分项。
再补一句量化：一般双方误差在 2%~3% 以内还能忍受，超过就开始出错；115200 对 9600 差了 12 倍，必然全乱。”

## 4. 舵机指令逐字拆解
以#000P1500T1000!为例
“#”“！”是固定格式
000是舵机id（可以自己改0-254,必须是三个数字，如001.255是广播，能控制所有舵机）
P代表PWM脉冲宽度调制，后接4位数,不足补0
1500是PWM值，在500-2500之间，必须是4个数字，不足补0，如0500
T代表时间，后接4位数,不足补0，单位ms
1000是时间值，必须是4个数字，不足补0，如0500

「让 1 号舵机转到中立、用 1.5 秒」和「让 3 号舵机卸力」两条指令
#001P1500T1500!
#003PULK!

## 5. 半双工/共地/电平
全双工：普通串口（UART）有两条信号线：TX 专门发送，RX 专门接收。可以像打电话一样双方同时发送
半双工：一根信号线接收和发送数据，相当于TX与RX直接通了。甲发送的甲也能收到，所以需要区分是回声还是对方的信号。类似于对讲机，不能双方同时发送
共地：单片机与舵机不是使用同一个电源时。到将两个电源负极相接，让它们有共同的低电平，以免异常或者故障
电平：机器的电平要相匹配。舵机大电流，不能用电脑USB供电，要用7.4V聚合物锂电池。不同电平的设备不能直接连接，存在烧机风险，想连接就要加电平转换
