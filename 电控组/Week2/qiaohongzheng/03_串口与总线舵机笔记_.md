# 03_串口与总线舵机笔记

## 1. 串口的四个参数

串口通信就是设备之间一位一位地传数据。通信两边的设置要一致，主要有四个参数：

-   **波特率**：可以简单理解成传数据的速度，比如
    9600、115200。两边不一样，接收数据时就可能出错。
-   **数据位**：一帧数据里真正传输数据的位数，常见的是 8 位。
-   **校验位**：用来简单检查数据有没有出错，常见的是无校验、奇校验和偶校验。
-   **停止位**：告诉接收方这一帧数据结束了，常见的是 1 位。

平时经常看到的 `8-N-1`，就是 8 位数据、无校验、1
位停止位。波特率要另外设置，比如 `115200, 8, N, 1`。

我了解到的回环测试方法是：把 USB 转 TTL 模块的 TXD 和 RXD
接在一起，然后在电脑串口助手里发送一段文字，比如 `Hello123`。

如果接线和参数都正确，发送窗口发出的内容应该能在接收窗口里原样显示。如果没有收到，或者出现乱码，就要检查接线、串口号和通信参数。

## 3. 为什么波特率不一致会出问题？

我理解波特率就是双方传数据时的节奏。发送方按照自己的速度发送，接收方也按照设置好的速度读取。

如果两边速度不一样，接收方就可能在不合适的时间读取数据，把原本的 0 和 1
认错，最后就可能出现乱码、数据丢失，甚至设备无法识别指令。

所以串口通信时，除了接线要正确，还要保证两边的波特率、数据位、校验位和停止位一致。

## 4. 舵机指令拆解

例子：

``` text
#001P1500T1000!
```

可以拆成七部分：

  内容     意思
  -------- -----------------------------
  `#`      指令开始
  `001`    1 号舵机
  `P`      后面是位置参数
  `1500`   目标位置
  `T`      后面是时间参数
  `1000`   时间为 1000 ms，也就是 1 秒
  `!`      指令结束

整句话就是：让 1 号舵机在 1 秒内转到 1500 对应的位置。这里的 1500
可以理解为中间位置，具体对应角度还要看舵机型号。

**指令一：让 1 号舵机转到中立位置，用 1.5 秒**

``` text
#001P1500T1500!
```

其中 `001` 是 1 号舵机，`P1500` 是目标位置，`T1500` 表示用 1500
ms，也就是 1.5 秒完成动作。

**指令二：让 3 号舵机卸力**

``` text
#003PULK!
```

`003` 表示 3 号舵机，`PULK` 表示卸力，最后的 `!`
表示指令结束。卸力后舵机不再主动保持扭力，外力可能让它转动。具体指令还是要以实际舵机的说明为准。
