## 三、ROS2 三种通信方式

  ----------------------------------------------------------------------------------------------------------------------

  通信方式          简单理解                               特点                                 常见用途

  ----------------- -------------------------------------- ------------------------------------ ------------------------

  Topic（话题）     发布者持续发消息，订阅者接收           适合连续、频繁的数据传输             传感器数据、球的坐标

  Service（服务）   客户端发起请求，服务端处理后返回结果   一问一答，适合短时间完成的操作       清除 turtlesim 轨迹

Action（动作）    发送一个目标，执行过程中还能反馈进度   适合耗时较长、需要反馈或取消的任务   机器人导航、机械臂动作
----------------------------------------------------------------------------------------------------------------------

## 四、差速运动的三个公式

差速小车左右轮速度不一样时，就可以改变运动方向。设：

- (v_L)：左轮线速度
- (v_R)：右轮线速度
- (L)：左右轮之间的距离
- (v)：小车前进的线速度
- (`\omega`{=tex})：小车转动的角速度

三个常用公式：

1. 小车前进速度：

   \[ v = `\frac{v_R + v_L}{2}`{=tex} \]

2. 小车转动角速度：

   \[ `\omega `{=tex}= `\frac{v_R - v_L}{L}`{=tex} \]

3. 已知小车前进速度和转动角速度，反算左右轮速度：

   \[ v_L = v - `\frac{\omega L}{2}`{=tex}, `\qquad`{=tex} v_R = v +
   `\frac{\omega L}{2}`{=tex} \]

简单来说，左右轮速度相同，小车直行；左右轮速度不同，小车就会转弯。这里的正负方向要和实际采用的坐标系、轮子定义保持一致。
