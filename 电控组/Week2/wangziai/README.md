### 任务 2 · 三个球的目标点导航

- 实现路线：闭环，订阅 `/turtle1/pose`，实时计算目标距离与方位角；先对准再走，越近越慢。
- 到达情况：

| 球编号 | 目标坐标 | 实际到达坐标          | 误差    |
|---|---|-----------------|-------|
| 1 | (2.0, 3.0) | (2.261 ,3.052 ) | 0.266 |
| 2 | (5.5, 8.0) | (5.291 ,7.813 ) | 0.281 |
| 3 | (9.0, 4.0) | (8.870 ,4.256 ) | 0.287 |

- 关键参数：`max_linear_x = 1.0`、`max_angular_z = π/4 ≈ 0.785`、`angular_z_k = 1.2`、`linear_x_k = 2.0`、`err_deadband = 0.03`、到点阈值 `0.3`
- 为什么这样调：先算线速度再算角速度。先通过v^2=2ax以及预期延迟'1.0 / self.rate'得到最大减速距离，
- 在此之外用max_linear_x*max(0.0, math.cos(err))（弧度err为角误差）得到耦合速度，
- 在最大距离之内用当前距离-预期延迟*预期速度得到预期距离，大于零则用预期距离重新计算我的速度，小于零则用指数衰减得到速度（衰减参数为预期距离与linear_x_k = 2.0，此时时间最短）
- 速度算出来后再统一乘上max(0.0, math.cos(err))获得耦合速度
- 再算角速度，当err大于1.2时使速度为0，实现先转后动
- 然后对最大角速度进行指数衰减（衰减参数为err角误差与angular_z_k = 1.2，此时时间最短）
- 此时比较角误差与err_deadband角误差死区的大小，小于则使角速度为0，防止运动路线呈波浪形
- 大于则判断是用反向最大角速度还是可以使用的衰减后的正向角速度

## 三、三种通信方式对比

| 通信方式 | 模型                       | 特点                          | 足球机器人场景                    |
|---|--------------------------|-----------------------------|----------------------------|
| 话题 Topic | 有发布者和订阅者，可以同时由多个终端发往多个终端 | 能够持续工作，发布与订阅不需要确保订阅者与发布者的存在 | 算法组持续发布足球位置，电控组持续发布决策状态    |
| 服务 Service | 向终端请求一次服务，获得一次响应         | 类似有返回值的函数，请求一次响应一次并返回信息     | 向机器人发送控制指令，或索要工作状态         |
| 动作 Action | 有完成目标，实时反馈状态，达到目标结果      | 在完成工作流时持续反馈工作状态，可随时取消       | 让机器人完成一项工作流，在任务途中可根据反馈随时取消 |

**我实际用到的服务调用**： `ros2 service call /clear std_srvs/srv/Empty`，我向终端请求一次服务，终端给我一次反馈。这里我只调用一次并拿到一次响应，没有持续发布/接收，因此是服务调用而不是话题。

## 四、差速三公式

- `v = (vL + vR) / 2` → 左右轮速的平均速度即机器人的线速度
- `ω = (vR − vL) / L` → 右轮与左轮的线速度之差除以轮距，得到机器人的角速度（正值左转）
- `r = v / ω` → 机器人的线速度除以角速度即机器人的转弯半径（曲率半径），正值为左转。
