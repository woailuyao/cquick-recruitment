##任务三：自定义消息+三种通信方式
--总的来说吧，这一周的任务中小球就可以说是一个自定义的消息，首先是建立他，创建了一个ballpos的一个文件，然后输入代码确定他的id和位置。然后根据我学ai来看，我还得在package那个文档里面加入相应的一堆代码让这个ros知道我生成新的接口，然后让编译器生成了python能用的代码，最后通过了colcon build编译。
--三种通信方式： （1）-话题：就是一直发布，不停的运作，任务一中就是订阅者和发布者一直在刷屏，不停的传输信息。而且这种传输方式是单向的，不管你订阅者听不听，就一直发送。对应的就是机器人在场上可以持续的获取场上的环境特征和球的位置。
 （2）-服务：就是一种一一对应的信息传递方式，和话题完全不同，他是一个节点发出消息然后另一个节点接受消息，这种必须是一一对应的，而且是会停止的的，也就是说发出一次消息后得到了一次消息的反馈就直接结束。这就可以对应机器人在足球场上作出一次正确的判断和正确的动作。
 （3）-动作：他像是服务的升级版，他也是有发送信息以及反馈的，不过他还可以反悔，也就是发出了指令后，目标不仅可以一直反馈给你进度，还可以视情况来中断。对应到机器人比赛中就是可以即使判断比赛情况而修改机器人的下一步决策。
