## 二、 三种通信方式

| 通信方式 | 模型 | 特点 | 比赛用在哪 |
| --- | --- | --- | --- |
| **话题 Topic** | 发布/订阅，多对多 | 单向 持续，只管发，不管有没有人收，一对多 | 视觉一直发球坐标，战术节点一直发速度 |
| **服务 Service** | 请求/响应一对一 | 同步，叫一次应一次，得等对方回话 | 像清屏 `/clear`，或者问问当前电量 查询当前状态 |
| **动作 Action** | 目标/反馈/结果 | 长任务，报进度，能随时取消 | 走到指定坐标，机械臂抓去，比如「走到(1,1)」然后一路报进度 |

*注：任务2开头敲的 `ros2 service call /clear ...` 就是个服务。*

## 三、 差速运动学三公式
- 线速度：`v = (vL + vR) / 2` （左右轮速度加起来除以2）
- 角速度：`ω = (vR − vL) / L` （左右轮速度差除以轮距，决定转弯快慢）
- 转弯半径：`r = v / ω` （速度除以角速度，ω越小转的弯越大）
