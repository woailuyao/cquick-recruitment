三、三种通信方式对比

| 通信方式     | 模型              | 特点                       | 足球机器人场景    |
| 话题 Topic   | 发布/订阅，多对多 | 单向、持续发、不管对方在不在 | 视觉持续广播球位置 |
| 服务 Service | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 查比分、切防守模式 |
| 动作 Action  | 目标/反馈/结果   | 长任务、报进度、可取消      | 走到某个点，过程报进度，可中途取消 |
