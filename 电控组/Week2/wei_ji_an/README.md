三、差速运动学三公式
设左右轮速为 `vL`、`vR`，轮距为 `L`：
1. 线速度：`v = (vL + vR) / 2` （决定机器人前进/后退的速度）
2. 角速度：`ω = (vR - vL) / L` （决定机器人转向的快慢和方向）
3. 转弯半径：`r = v / ω` （角速度越小，转弯半径越大；角速度为0时走直线）
