## 1. 串口四参数
串口通信必须双方约定四个参数，默认组合通常写作 **8-N-1**。
| 参数 | 是什么 | 常见值 |
|---|---|---|
| 波特率 | 每秒传多少位，双方必须一致 | 115200、9600 |
| 数据位 | 一个字符用几位 | 8 |
| 停止位 | 一帧的结尾标志 | 1 |
| 校验位 | 简单查错 | 无（N） |
**波特率不一致会怎样：** 收到一堆乱码，不是设备坏了。
**为什么：** 串口是异步通信，没有单独的时钟线。发送方按自己的波特率一位一位发，接收方按自己的波特率去采样。两边节拍不一致，采样点会逐渐偏移，采到的位边界全错，拼出来的字节就没有意义。所以是乱码，不是“稍微错一点的数据”。

另外三个容易忽略的点：
- **单线半双工**：收发共用一根线，自己发的数据自己也听得到，所以同一条总线上不能两个设备同时说话；
- **共地**：两边 GND 必须连，电平参考点不一样就分不清高低电平，只接 TX/RX 不接地必然收不到；
- **电平匹配**：5V 和 3.3V 不能直连，会烧 3.3V 那一侧，要么加电平转换，要么确认器件兼容。

## 3. 波特率不一致的原理
串口没有时钟线，发送方和接收方各自按约定的波特率计时。发送方按 115200 的节拍一位一位发，接收方如果按 9600 的节拍采样，每个位的采样点都会偏。偏到半个位宽以上，就会把 0 采成 1、1 采成 0，拼出来的字节完全不对，所以看到的是乱码。
可以这样理解：两个人约好每秒钟说一个字，一个按 1 秒说，一个按 2 秒听，听的人永远对不上说的人的节奏，听到的就不是原来的话。

## 4. 总线舵机指令逐字拆解
以 `#001P1500T1000!` 为例，拆成七段：
| 段 | 含义 |
|---|---|
| `#` | 帧头，指令开始 |
| `001` | 舵机 ID，固定 3 位，1 号写 `001` |
| `P` | 位置 / PWM 命令 |
| `1500` | PWM 值，固定 4 位，范围 500–2500，1500 是中立位 |
| `T` | 时间参数 |
| `1000` | 用时 1000 ms，平滑转到位 |
| `!` | 帧尾，指令结束 |
字段规则：
- ID 固定 3 位，1 号写 `001`；
- PWM 固定 4 位，范围 500–2500，1500 = 中立位；
- 时间固定 4 位，单位 ms，舵机用这段时间平滑转到位，不是瞬间跳；
- 通信参数：波特率 115200，供电 5–8.4V。
自己写两条指令：
- 让 **1 号舵机**转到中立、用 **1.5 秒**：`#001P1500T1500!`
- 让 **3 号舵机**卸力：`#003PULK!`
补充：
- `PULR` 是恢复扭力，**要它动之前必须先发**；
- `PULK` 是卸力，**安全下电必发**，防止堵转发热烧舵机。
