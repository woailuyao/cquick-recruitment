1. 串口四参数

串口通信需要收发双方约定好四个基本参数，通常称为 8-N-1：

- 波特率：每秒传输的位数（bit/s）。常见的有 9600、115200。双方必须严格一致。
- 数据位：一个字符实际用几位表示，通常是 8 位，刚好对应一个字节（Byte）。
- 停止位（Stop Bits）：一帧数据结束的标志，通常是 1 位。给接收方一个缓冲时间。
- 校验位（Parity）：简单的查错机制，通常是无（N）。

波特率不一致会怎样？

如果两边波特率不一致，接收方收到的全是乱码，甚至触发帧错误。因为串口是异步通信，没有时钟线，接收方只能按照自己设定的节拍去每一位的中间采样。如果发送方发得快（比如 115200），接收方采得慢（比如 9600），采样点完全错位，高低电平组合出来的字节定然错误。

## 3. 波特率不一致的原理

发送方按每秒 115200 下的频率发送时（每个电平持续约 8.6 微秒），接收方必须严格在每个电平的正中接受。

如果接收方用 9600 的慢频率去听，它会在一个电平持续期间听错位，采样错误的电位。最后导致原本高电平被读成低电平，校验位或者停止位错接，串口助手就会直接报错或者显示成乱码。

## 4. 舵机指令逐字拆解


| `#` | 起始符，代表舵机指令的开始 |
| `001` | 舵机 ID 号，固定 3 位。第n 号舵机就写 `00n` |
| `P` | 位置控制指令，表示准备控制角度 |
| `1500` | PWM 值，固定 4 位。范围 500~2500 |
| `T` | 时间控制指令，表示用平滑转动所需的时间 |
| `1000` | 时间参数，固定 4 位，单位是毫秒（ms），代表1s |
| `!` | 结束符，代表指令结束 |

自己写指令：

- 让 1 号舵机转到中立位、用 1.5 秒：`#001P1500T1500!`
- 让 3 号舵机卸力：`#003PULK!`
