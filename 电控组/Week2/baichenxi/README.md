## 二、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人典型场景 |
| :--- | :--- | :--- | :--- |
| **话题 (Topic)** | 发布/订阅，多对多 | 单向、持续流、不管对方在不在 | 视觉持续广播球位置；战术持续广播速度指令 |
| **服务 (Service)** | 请求/响应，一对一 | 同步、有返回值、调一次答一次 | 「现在比分多少」「切到防守模式」 |
| **动作 (Action)** | 目标/反馈/结果 | 长任务、报进度、可取消 | 「走到点 (1,1)」→ 过程报进度，可中途取消 |

**任务 2 里实际用到的服务调用**：
在跑小乌龟前，我执行了 `ros2 service call /clear std_srvs/srv/Empty`，这就是一次典型的服务调用（请求清屏，收到响应后结束），不同于话题的持续广播。

## 三、差速运动学公式
- 线速度：`v = (vL + vR) / 2` （左右轮速平均值）
- 角速度：`ω = (vR - vL) / L` （速度差除以轮距）
- 转弯半径：`r = v / ω` （线速度除以角速度）
