## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅 ，多对多|单项持续流，不管对方收不收 |视觉持续广播球的位置 |
| 服务 Service |请求/响应，一对一 |调一次答一次。有返回值 |清屏，问当前比分 |
| 动作 Action |目标/反馈/结果 |长任务，进度，中间可以取消 |走到某一位置可以叫停 |

**我实际用到的服务调用**：任务 2 开始前的 `ros2 service call /clear std_srvs/srv/Empty`，它调用一次，响应一次。返回一个Empty_Response，就结束了，而话题是持续的。清屏只需要一次，所以用服务

## 四、差速三公式

- `v = (vL + vR) / 2` → 车身整体的平移速度
- `ω = (vR − vL) / L` → 两轮的速度差比轮距，如果轮距L大，同样的速度差，转弯会慢
- `r = v / ω` → 角速度很大，转弯半径很小，就接近于原地转；角速度很小，转弯半径就很大，近似于直线
