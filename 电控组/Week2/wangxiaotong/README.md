## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 多对多，发布/订阅 |无需反馈，单向持续流动 |视觉持续广播球位置；战术持续广播速度（本任务是给定球坐标持续广播，通过闭环不断广播球位置调整速度） |

| 动作 Action |目标/反馈/结果 |随时反馈进度，任务持续时间长，中途可取消 |[走到点（1，1）]→过程报进度，可中途取消 |

## 四、差速三公式

- `v = (vL + vR) / 2` → 两个力拉一个物体，等价于二者平均力拉这个物体
- `ω = (vR − vL) / L` → 两轮角速度之差导致的物体转向
- `r = v / ω` → 速度转换公式
