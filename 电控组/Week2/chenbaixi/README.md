## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic | 发布/订阅,多对多,或一对多，或多对一| 单向发布不管是否有订阅者|球位置的广播，球状态的广播，相应状况对应战术的广播 |
| 服务 Service |请求/响应，一对一|一次性响应，有问才有答,且一定有答复 |场上比分多少|
| 动作 Action |目标/反馈/结果 | 一次任务，中间能随时停止,能反馈进度|带球推进到对方半场,走到点 (1,1)|

**我实际用到的服务调用**：我用`ros2 service call /clear std_srvs/srv/Empty` 来清理画布，，这就是请求，发出请求后必须等到一个 response 才结束，这就是回答，所以它是服务.

- `r = v / ω` → 由v=ωr的公式可得
