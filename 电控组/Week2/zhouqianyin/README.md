## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
|---|---|---|---|
| 话题 Topic |发布-订阅| 请求-应答 | 同步、一对一，一次请求一次应答，请求方等待结果 | 里程清零、重置仿真环境 |
| 服务 Service |请求-应答 | 同步、一对一，一次请求一次应答，请求方等待结果 | 里程清零、重置仿真环境 |
| 动作 Action | 目标-反馈-结果 | 长时间任务，支持过程反馈、中途取消 | 机器人自主导航到目标点 |

**我实际用到的服务调用**：<任务 2 开始前的 `ros2 service call /clear std_srvs/srv/Empty`，这是一次性的请求操作，发送请求后等待仿真环境清零完成，不需要持续不断推送数据流，符合服务请求应答的模型，因此是服务，不是话题。>

## 四、差速三公式

- `v = (vL + vR) / 2` → <小车整体往前的速度，就是把左右两个轮子的速度加起来取平均值>
- `ω = (vR − vL) / L` → <小车转得快不快。左右轮子速度不一样，小车就会转弯；两轮距离 L 固定，速度差越大，转得越快>
- `r = v / ω` → <转弯的时候绕着多大的圈走。走得越快、转得越慢，圈就越大>

## 五、踩过的坑 & 怎么解决的

> 这一节最值分，别写「没遇到问题」。

1. 问题现象：新开终端运行节点，提示找不到包
   - 我怎么查的：报错提示包不存在，回忆工作空间编译逻辑
   - 最后怎么解决的：每次新开终端先执行 `source install/setup.bash`
2. 问题现象：导航时小车很容易冲过目标点，误差很大
   - 我怎么查的：观察日志，靠近目标时速度没有及时降下来
   - 最后怎么解决的：调低最大线速度，设置合适的到点阈值，靠近目标减速
3.问题现象：新增追踪节点，ros2 run 提示 No executable found
   - 我怎么查的：核对 setup.py 入口配置，检查 colcon build 是否成功，查看 install 目录下有没有生成对应程序
   - 最后怎么解决的：在 setup.py 补充节点入口点，重新 colcon build 编译
4.问题现象：Python 脚本运行报格式异常
- 我怎么查的：查看脚本首行，检查文件换行符，确认是否缺少 python 解释器声明
- 最后怎么解决的：脚本第一行添加 #!/usr/bin/env python3，调整换行格式，添加执行权限
