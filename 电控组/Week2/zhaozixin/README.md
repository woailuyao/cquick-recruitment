三、三种通信方式对比
通信方式	模型	特点	足球机器人场景
话题 Topic	发布/订阅，多对多	单向、持续流、不管对方在不在	视觉持续广播球位置；战术持续广播速度指令
服务 Service	请求/响应，一对一	同步、有返回值、调一次答一次	「现在比分多少」「切到防守模式」
动作 Action	目标/反馈/结果	长任务、报进度、可取消	「走到点 (1,1)」→ 过程报进度，可中途取消
我实际用到的服务调用：任务 2 开始前的 ros2 service call /clear std_srvs/srv/Empty，因为它是请求一次回应一次并立刻结束，不需要像话题那样一直持续广播，所以是服务。
四、差速三公式
v = (vL + vR) / 2 → 线速度等于左右轮速度的平均值。
ω = (vR − vL) / L → 角速度等于右轮速度减左轮速度的差除以轮距。
r = v / ω → 转弯半径由线速度除以角速度得出，ω为0时走直线。
五、踩过的坑 & 怎么解决的
