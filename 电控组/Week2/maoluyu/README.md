## 三、三种通信方式对比

| 通信方式 | 模型 | 特点 | 足球机器人场景 |
| 话题 Topic | 发布-订阅模型 | 单向数据流，持续周期性发送，不需要应答，一对多，适合持续状态 | 小球位置、机器人底盘实时位姿持续上报 |
| 服务 Service | 请求-应答模型 | 一问一答，同步调用，发请求后等待对方返回结果，单次触发 | 重置海龟画布、急停指令、单次查询机器人状态 |
| 动作 Action | 目标-反馈-结果模型 | 长时间任务，过程中持续反馈进度，中途可以取消 | 机器人自主导航走到指定点位、机械臂抓取动作 |

我实际用到的服务调用**：任务2开始前的 `ros2 service call /clear std_srvs/srv/Empty`
解释：清除画布是一次性触发的操作，只需要执行一次、不需要持续不断推送；服务适合单次请求执行动作，话题是源源不断持续发数据，所以这里用服务而不是话题。

## 四、差速三公式

- 四、差速三公式
- `v = (vL + vR) / 2` → 机器人车体中心的线速度，是左右两轮速度的平均值
- `ω = (vR - vL) / L` → 机器人的旋转角速度，左右轮速度差越大，转得越快；L是两轮轮距
- `r = v / ω` → 瞬时转弯半径，线速度除以角速度，r越大转弯弧度越平缓
