## 反复出现的四类问题

按出现次数排下来，前三类占了这次调试的绝大部分时间：

1. **环境没 source**（出现 4 次）。表现是 `Package not found`、`type is invalid`、`bag 里少条数`。根源是 `source` 只对当前 shell 生效，而开新终端太顺手了。最后写进 `~/.bashrc` 才根治。
2. **改了没重编**（出现 3 次）。`src` 改了、`install` 里还是旧文件。`--symlink-install` 只对 Python 源码生效，`config/` 和 `package.xml` 改了必须重新 build。
3. **参数有多层来源**。节点默认值 < yaml < launch 的 `parameters` 字典 < 命令行 `--ros-args -p`。不把这四层顺序想清楚，就会出现“yaml 明明改对了，跑起来还是旧值”。
4. **串口/硬件层的问题只能靠二分**。波特率、ID、接线、供电四件事，用“扫波特率 → 扫 ID → 回环测试 → 量电压”的顺序排除，比盯着代码猜快得多。
