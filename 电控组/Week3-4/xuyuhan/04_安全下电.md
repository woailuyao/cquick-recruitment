# 任务 4 · 安全下电记录

> 姓名：xuyuhan　顺序：**先卸力 → 再断动力电 → 最后关板卡**

## 操作顺序

### ① 全部舵机卸力

保持驱动在线，在终端执行：

```bash
echo "姓名: xuyuhan"; date "+%Y-%m-%d %H:%M:%S"
ros2 param set /servo_driver torque_enable false
ros2 param get /servo_driver torque_enable
```

`torque_enable=false` 会调用驱动的 `release_all()`：先禁止任何新运动，再向 `servo_ids`
中的 001～010 全部发送 `#xxxPULK!`，预期参数读回 `Boolean value is: False`。

### ② 拔电池，断动力电

在录屏画面中清楚拍下拔电池过程。先卸力已完成，不在带电状态插拔舵机信号线。

### ③ 正常关闭板卡/虚拟机

```bash
sudo shutdown now
```

不直接拔电脑或板卡电源，避免损坏文件系统。
