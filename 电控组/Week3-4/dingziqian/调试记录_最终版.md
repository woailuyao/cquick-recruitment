## 下电命令备忘

1–10 号舵机卸力指令（应发送到舵机控制器串口或通过上位机执行）：

```text
#001PULK!
#002PULK!
#003PULK!
#004PULK!
#005PULK!
#006PULK!
#007PULK!
#008PULK!
#009PULK!
#010PULK!
```

板卡 Ubuntu 终端关机命令：

```bash
sudo shutdown now
```

卸力 → 拔电池 → 正常关闭板卡，不能颠倒顺序。
