# 下电流程

## 操作步骤

1. 在终端中 Ctrl+C 停止 servo_driver 节点
2. 确认节点已完全退出（无残留进程）：
   ps aux | grep servo_driver
3. 关闭串口舵机控制器的电源开关
4. 断开 USB 连接线
5. 确认 /dev/ttyUSB0 设备消失：
   ls /dev/ttyUSB*

## 注意事项

- 下电前必须确保所有舵机已回到 safe_pwm（1500）位置
- 禁止带电插拔舵机接线
- 禁止直接拔USB不断节点（可能导致串口占用无法释放）
- 下次上电前确认电池电压充足（>7.4V）

## 验证方法

- 节点停止后运行：ros2 node list，确认 servo_driver 已消失
- USB拔出后：ls /dev/ttyUSB* 应提示无此文件
