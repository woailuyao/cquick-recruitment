# 参数表 · servo_driver（7 个，全部来自 yaml）

>

---

## 一、总表

| 参数                    | 类型     | 默认值               | 为什么是这个默认值                                                                  |
| --------------------- | ------ | ----------------- | -------------------------------------------------------------------------- |
| `port`                | string | `/dev/ttyUSB0`    | CH340 在本机**实测枚举为 0**。插拔或重启会漂到 1，所以这个 0 只是"当前值"、不是契约 —— 启动后必须看日志里有没有「串口已打开」 |
| `baudrate`            | int    | `115200`          | 厂家协议固定 **115200 8-N-1**。9600 / 19200 / 38400 / 57600 实测全不转；白名单外的值直接拒       |
| `pwm_min`             | int    | `900`             | 结构行程的安全下限，留了余量。撞到限位还继续发力就是堵转，三分钟能烧穿舵机                                      |
| `pwm_max`             | int    | `2100`            | 上限同理。1500 是中立位，900–2100 就是 **±600 的对称行程**                                  |
| `default_duration_ms` | int    | `800`             | 当初填 800 是图快，但**实测偏短**：舵机还没走到位就被判超时（ABORTED）。建议改 **1500**（实测 1500 最稳）       |
| `servo_ids`           | int[]  | `[0,1,2,3,4,5,6]` | 实测本舵机 ID = **000**（考核文档写"从 1 开始"，实际不是），列 0 才能兼容；1–6 留给整机 6 个舵机             |
| `startup_reset`       | bool   | `true`            | 上电先回中位，保证每次启动姿态一致。否则会带着上次停下的角度上电，结构可能已经顶住                                  |
