# 电控组 · 招新考核

> 电控组负责足球机器人的**战术编写**与**运动控制**——即「机器人在场上该做什么」和「怎么让它真的做出来」。

## 目录导航

| 周次 | 考核细则 | 提交目录 | 主题 |

| 第 1 周 | [考核细则_第1周.md](../考核细则_第1周.md) | [`../Week1/`](../Week1/) ⚠️ 历史目录 | 环境搭建 + ROS2 入门（小乌龟） |

> ⚠️ **第 1 周为什么还在根目录？**
> 因为已经有一批同学按根目录 `Week1/` 提交了 PR，现在移动目录会让这些 PR 全部冲突。**等所有 PR 合并完，才会统一迁移到 `电控组/Week1/`**。在此之前：第 1 周继续交到 `Week1/`，第 2 周交到 `电控组/Week2/`。

## 提交方式

1. Fork 本仓库 → 2. Clone 你的 Fork → 3. 在对应周目录下建 `<姓名拼音>/` → 4. 放文件 → 5. commit + push → 6. 发起 Pull Request。

详细目录规范见各周目录下的 `README.md`；评分标准、防抄袭要求见对应细则。

## 两条铁律

1. **截图必须带「姓名拼音 + 时间戳」**（细则里给了具体命令），否则按未自证扣分；
2. **目录结构和给定参数不许自创**——比如第 2 周那三个球坐标是统一基准，改了评审就复现不出来。
