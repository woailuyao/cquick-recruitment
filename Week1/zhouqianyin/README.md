## 任务 2：小乌龟
节点是ROS2里一个个独立运行的进程，每个节点只负责自己的功能；话题是节点之间异步通信的通道，遵循发布-订阅模型。发布节点往话题里发数据，订阅节点主动监听这个话题拿数据，节点之间不用互相知道对方的存在。在小乌龟例子中，键盘控制节点是发布者，持续把速度指令发布到话题；小乌龟仿真节点是订阅者，接收话题里的速度消息来移动。二者解耦，更换发布节点也不会影响小乌龟订阅接收消息。
