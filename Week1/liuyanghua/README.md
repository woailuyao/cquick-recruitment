## 任务 2：小乌龟

节点类似于一个运行的独立程序，话题可以说是节点之间互相联系的通路，节点之间的通讯通过话题来完成，同时，话题**似乎**是单向的。  
例如，在本次的小乌龟中，第一个终端运行小乌龟窗口，创建第一个节点**turtlesim\_node** ，第二个终端运行键盘监听，创建第二个节点**turtlesim\_teleop\_key.**  
两个节点之间通过topic沟通，节点2通过话题/turtle1/cmd\_vel向节点1传递信息，以此控制小乌龟的移动。  
此外还有2个节点是节点1指向节点2的，教程中未提及。  
此外，我发现Linux的许多程序都需要依赖一个终端来运行，或许不同终端之间的联系也是通过话题？
