## 任务 2：小乌龟
没想到ros2自带小乌龟啊，一开始看到任务还以为要去安装初中那种小乌龟编程器（）；
我对节点和话题的了解：
- 节点是一个个独立运行的程序指令，类似代码的运行
- 而话题则是节点间传输指令的通道，类似于我们输入一些信息给前端，然后让背后的代码就可以收到指令然后执行；
- 两者配合，可以组成工程协作的效果
> 我一开始点小乌龟窗口没反应，后来才知道要点我终端输入的那个窗口，倒是也很合理了。
