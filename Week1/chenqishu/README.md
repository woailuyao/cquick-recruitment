**## 任务 1：环境自检**



做了什么：

使用 VirtualBox 安装 Ubuntu 22.04.5 LTS 虚拟机，配置为 4GB 内存、2 核 CPU、30GB 虚拟硬盘，虚拟机文件放在 D 盘。

ROS2 使用鱼香 ROS 一键脚本安装，选择 Humble、桌面版，并更换中科大镜像源。自检结果：

\- `printenv ROS\\\_DISTRO` 输出 `humble`

\- `ros2 --help` 能正常显示帮助信息



遇到的问题和解决方式：

1\. VirtualBox 安装程序多次闪退。排查后暂停火绒防护，并改用 7.1.18 安装包，安装成功。

2\. Ubuntu 安装时键盘布局不是美式布局，按 `-` 和 `\_` 分别输出 `'` 和 `?`。在“设置 -键盘 -输入源”中添加 English (United States)，切换到该输入源后恢复正常。
