## 任务 2：小乌龟
**我理解的节点与话题：**
节点（Node）就是独立运行的程序，比如小乌龟窗口是一个节点，键盘控制是另一个节点，它们互相独立，关掉键盘控制，小乌龟不会消失，但是小乌龟会无法控制走动。
话题（Topic）是它们沟通的频道。键盘通过 /turtle1/cmd_vel 频道发指令，小乌龟接收指令并移动，通过 `ros2 topic list` 可以看到这些频道。
