## 任务 2：小乌龟
我理解:节点就好比独立的个体，话题相当于传递消息的通道。人与人依靠这条通道传递信息，互相配合。节点则是一个特定的程序，负责某一项功能；话题是各个节点之间传递消息的通道，让不同节点协同工作。
在小海龟例子里，执行 ros2 run turtlesim turtlesim_node 和 ros2 run turtlesim turtle_teleop_key ，前者仿真出小乌龟，后者可驱动小乌龟移动会启动。这是两个独立的节点。键盘节点识别按键信息，把信息发送到话题中；小乌龟仿真节点订阅 /turtle1/cmd_vel这个话题，读取消息，控制小海龟移动。
