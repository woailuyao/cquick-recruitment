## 任务 2：小乌龟

启动的两个节点：

- `turtlesim_node`：显示小乌龟窗口，订阅 `/turtle1/cmd_vel` 接收速度指令，发布 `/turtle1/pose` 上报位置。
- `turtle_teleop_key`：读取键盘方向键，把按键转成 `geometry_msgs/msg/Twist` 消息发布到 `/turtle1/cmd_vel`。

我对「节点」和「话题」的理解：

- 节点（node）：它是一个独立运行的程序，`ros2 run` 每执行一次就多一个节点。
- 话题（topic）：节点之间按名字传递消息的通道，具有多对多的特征。发布者负责往话题里写，订阅者可以从话题里读取，双方不需要知道对方是谁，只需要话题名即可。
- 两者的关系：话题是类似频道的事物，节点则可以监听频道。`turtle_teleop_key` 并不直接调用 `turtlesim_node`，而是把速度指令发到 `/turtle1/cmd_vel` 这个频道；`turtlesim_node` 一直在监听这个频道，收到指令后就让乌龟动起来。所以替换其中任何一个节点，另一个依旧能工作
