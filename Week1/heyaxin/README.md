## 任务 2：小乌龟

- 在我看来，节点类似于功能模块，一个节点负责一个功能，它是基本功能单元。而话题则是通信方式，它发布模式，传递数据，有一对多，多对多类型。可以把节点看作通信的两方，而话题则是他们中间传输数据的通道。拿乌龟来说，我认为刚开始那个可以出现小海龟的指令就是一个节点，接着再输入指令启动负责读键盘输入转化运动节点，一只小乌龟运动有两个节点在背后操作，但是两个节点是孤立的，互相不认识，那么是什么把他们联系到一起，作用于同一只乌龟呢？通过任务表中输入的ros2 topic list,出现了两个节点间通信的话题即数据通道。我认为这个例子可以同时说明节点和数据的概念以及他们之间的关系。
