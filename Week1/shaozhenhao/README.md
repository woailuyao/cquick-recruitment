## 任务 2：小乌龟

- 节点（Node）：ROS2中负责执行特定功能的运行单元。在运行小乌龟时turtlesim_node 负责显示和控制小乌龟，teleop_turtle 负责接收键盘输入并生成控制指令。在我的理解中就是负责不同工作的程序
- 话题（Topic）：ROS2节点之间传递消息的一种通信机制。节点可以向话题发布消息，也可以订阅话题来接收消息。
- 二者的关系：节点可以通过发布或订阅话题，与其他节点交换数据。话题是节点之间传递信息的方式，比如小乌龟实验中，一个节点负责接收键盘输入，另一个节点负责显示和控制小乌龟，它们通过话题传递运动指令。这样两个节点就能各自做自己的工作，也能配合起来完成控制
- 实际运行结果：小乌龟在方向键的操作下进行运动并且留下运动轨迹。
