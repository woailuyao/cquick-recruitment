## 任务 2：小乌龟
<节点：是ROS2系统中负责完成某一任务的程序运行单元，不同节点负责不同工作，但可以相互通信，可以理解成团队里的不同成员：有人负责控制电机，有人负责环境感知......
话题：是ROS2中节点之间相互传递消息的一种通信机制，一个节点可以向某个话题发布消息，其他节点可以订阅这个话题，从而接收消息
节点与话题的关系：节点负责执行任务，话题负责让节点之间交换消息>
