## 任务 2；小乌龟
<说明：对"节点"和"话题"的理解，以及它们的关系（加分项就看这里）>
      节点，顾名思义就是节点，可以简单理解成目标，在我的理解下可以认为每个节点就是一个人，各个节点在一起组成了一个庞大的人群，而话题则是当几个人碰在一起时可以选择讨论的共同话题，并非有话题就一定要沟通，但是有话题是人与人之间沟通的必要条件。所以当多个人碰在一起时，他们可以选择用共同话题来进行沟通和互动，进而传递信息。显而易见的是，一个人也可以选择用不同的话题同时和多个人沟通，即认为一个节点可以通过多个话题与不同节点进行信息的传递。
