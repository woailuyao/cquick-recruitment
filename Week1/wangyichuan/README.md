## 任务 1：环境自检
安装VMWare；配置虚拟机；为虚拟机安装Ubuntu 22.04系统

### 遇到的问题及处理

- **Ubuntu 版本不匹配**：最初安装的是 Ubuntu 24.04。ROS2 在此系统下默认的版本为Jazzy。 后为避免由环境不同导致的问题，重装为Ubuntu 22.04。

- **虚拟机磁盘空间不足**：最初仅为虚拟机分配了 20 GB 磁盘空间，询问AI后了解到此磁盘空间用于电控开发过于紧张。于是在VMWare中将虚拟磁盘扩容至 40 GB，随后在 Ubuntu 系统内使用 GParted 管理扩展分区，并通过 `df -h` 确认可用容量。

## 任务 2：小乌龟
**节点(node)** 是独立运行的程序。
**话题(topic)** 是节点间传输数据的总线。
二者之间通过 **“发布”** 与 **“订阅”** 进行通信。

**Publisher** 节点发布话题，并将 **“消息(message)”** 发送至此话题。**Subscriber** 节点订阅此话题，从而收到Publisher发送的消息。两节点之间必须使用完全相同的消息类型才能完成通信。同时两个节点之间无需知道对方的存在，只需约定好话题名称和数据格式就能配合，非常灵活。

## 任务 3：Git 提交

### 网络问题
github 难以直连。起初尝试直接在虚拟机中创造出合适的网络环境访问 github，故下载 watt toolkit 尝试加速。然而并没有成功，反而虚拟机因网络代理被改乱导致无法联网。万幸最后得以将虚拟机通过快照还原。

最终解决：首先在宿主机中运行 watt toolkit，加速 github。此时宿主机已可访问github。
随后在宿主机的 vscode 中通过“远程资源管理器”插件，远程连接虚拟机并访问本地 git仓库。此时即可成功将本地仓库推送至 gitHub 的远程仓库。
