- 话题是节点间传递数据的通道。本次实验中有两个主要节点：`/turtlesim`（负责仿真显示与运动）和 `/teleop_turtle`（负责键盘控制）。
- 小乌龟节点订阅话题并驱动乌龟移动。节点是“干活的人”，话题是“传送数据的通道”；节点通过话题共同协作，实现机器人的复杂功能。

首次尝试了 Fork + PR 的协作流程。我理解了整体逻辑是：先 Fork 到个人账号 → Clone 到本地修改 → 推送到自己的仓库 → 发起 PR 合入主仓库。

但我在实际操作时，遇到了比较严重的网络问题。虚拟机内一直报 `Connection refused`，无法通过终端完成 `git push`，尝试了修改 DNS 和网络模式均无果。最终为了不耽误进度，我经老师允许后采用了在 GitHub 网页端直接上传文件夹的方式完成了作业提交。虽然没能在终端跑完最后的 push 指令，但这次踩坑让我对 Git 的分支和仓库流转有了很深刻的理解。我后续会查找问题所在及时解决！
