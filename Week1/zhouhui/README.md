## 任务 2：小乌龟
<说明：对"节点"和"话题"的理解，以及它们的关系（加分项就看这里）>
节点："turtlesim_node"和"turtle_teleop_key"是两个独立运行的程序。在 ROS2中，节点就是执行具体任务的最小单位。
话题：它们通过"/turtle1/cmd_vel"这个话题进行通信。键盘节点是发布者，把按键转化成速度指令发到话题里；乌龟节点是订阅者，接受指令后移动。两者不需要认识对方，只通过话题传数据。
