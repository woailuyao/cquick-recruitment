## 任务 2：小乌龟
节点：通讯发起/接收者
话题：通讯媒介/渠道
两者好比枢纽机场与各地（当然是枢纽机场时代而不是现在的点对点时代）
在节点1与节点2建立通讯，需要话题这个媒介
好比从甲地去乙地，没有航司的直飞航班，需要先到枢纽机场转机
这个枢纽机场就是话题
一个地方可以有多条前往不同枢纽机场的航线
一个节点可以发布或者订阅多个话题
地方直接的联系需要枢纽机场这一重要媒介
节点之间的通讯需要话题这一媒介

我相信你肯定想问为什么是枢纽机场而不是机场
注意到有 多个节点 - 一个话题 - 多个节点 这种通讯方式
用机场来比喻的话
那就是两地直飞，是一对一，不满足多对多
枢纽机场机就可以体现 甲乙丙 - 枢纽机场 - ABC 这种多对多通讯

当然，要是实在觉得我说的太绕，用 UP主 - 小破站 - 粉丝  这个比喻也是可以的
