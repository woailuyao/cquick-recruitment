## 任务 2：小乌龟

理解：
    节点是一个独立的程序进程。小乌龟窗口是一个节点，读键盘的又是另一个节点，相互独立的。

    话题是节点之间传数据的通道，它本身也有名字。发布者往通道里写，订阅者从里面读。
    如/turtle1/cmd_vel 这条通道传的是"前进速度 + 转向速度"，乌龟节点作为订阅者接受数据。

关系：
    节点之间靠话题来连接，只要话题匹配即可通信；就算发出话题的节点换成了另一个，只要话题可以保持一致，
    依旧可以实现通信。

我用 `ros2 topic info /turtle1/cmd_vel` 验证：Publisher count = 1，Subscription count = 1。
又用 `ros2 topic echo /turtle1/cmd_vel` ，能看到按方向键时 `linear.x` / `angular.z` 的实时变化。
此处附有截图，放在了文件夹中，命名带有03前缀。
