## 任务 2：小乌龟
节点是一个个可以执行任务的单元，比如显示图像，键盘录入等，但是以我现在的知识看来好像一个节点只能完成一个任务，比如显示图像的同时不能键盘录入。

话题充当的是一个类似传输信息，实现节点间通信的角色。
比如键盘录入节点收到录入信息后，通过话题把信息传给图像显示节点，再显示图像。

关系：节点是一个小的独立单元，话题是连接节点的桥梁
