## 任务 2：小乌龟
<我认为节点是一个个独立的程序 相当于足球场上的球员们（当然节点不必全是同一类型） 节点之间相互独立运行，但是又间接地相互影响（这里我参考了一下AI地回调机制），主要原因是节点之间处理速度的差异，当一个节点的算力消耗多，那么其他节点的运行速度会被阻塞，好比球员之间传球，当一个球员受到压迫而减缓传球速度，其他球员也会调整步伐来去接球，那么整个进攻节奏就会被放缓,节点又是一个动态过程，可以随时启动随时关闭
 话题则类比于数据传输的通道，在对手包夹下能传出球的线路，既然是数据传输，就对数据类型要有一定的要求，即要求数据是同类型的
节点与话题之间，多个节点通过话题而相互连接，彼此影响，一个节点也可以对接多个话题，传输不同的数据，不是简单的一一对应关系；同时两者之间存在着解耦关系，节点和话题彼此陌生但并不影响数据的传输与运行，比如小乌龟虽然没启动，但我可以输入指令，当小乌龟启动之后，这些指令会被执行，并且这个过程是可以监视的>
