## 任务 2：小乌龟
节点就像动词，负责执行命令；话题就像名词，代表着执行的对象。
节点对于话题，就像动词对于名词，使话题能够“动”起来；话题对于节点，就像动作承受的对象，当话题相同时，节点也对于着同一个目标。就如指挥乌龟运动来说，命令是节点，乌龟是话题。
