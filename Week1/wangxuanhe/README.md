## 任务 2：小乌龟
节点：ROS2中独立运行的程序单元，一个功能对应一个节点。相当于构成整个大功能的小零件，钉子、锤子、螺丝、螺母，各司其职，每个节点只做一件事，只有一个功能可以组合。

话题：节点之间单向传输数据的通信通道。有一个人持续发出话题一直说，可以给多个人听，不管有无回应一直讲，好比老师上课，不管有没有人反应，不管有几个人听，自顾自地讲。这样的一个通道。

关系：发布节点向话题持续推送数据，订阅节点监听话题接收数据。

小乌龟示例：键盘控制节点把按键转为速度信息，通过 `/turtle1/cmd_vel` 话题发给turtlesim节点，驱动乌龟移动。
