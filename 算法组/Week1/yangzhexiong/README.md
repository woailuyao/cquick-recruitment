# W1 视觉算法 - 第一周作业记录

## 一、运行环境与说明
- **需要安装的库**：`opencv-python` 和 `numpy`（使用 `pip install opencv-python numpy` 即可）
- **代码运行方式**：直接在 PyCharm 里右键运行对应的 `.py` 文件
- **文件夹说明**：`images` 放我找的原图 `outputs` 里放了跑出来的结果图

## 二、调参记录（主要参数说明）
- **高斯滤波的参数（5x5和15x15）**：数字填得越大 图片就越糊 去噪点越厉害 但边缘也看不清了
- **黑白二值化的阈值（80和160）**：阈值越低 变成白色的地方就越多 阈值调高后 只有特别亮的地方才会变白
- **找颜色的 HSV 范围**：我发现红色的范围比较特殊 在OpenCV里跨越了0和180两头 所以要写两段范围把它拼起来才能找全 橙色就正常写一段
- **过滤杂色的面积阈值（min_area = 500）**：如果不加这个 草地上的小反光也会被当成目标框出来 我设成500就是告诉电脑“太小的色块直接忽略”

## 三、任务一：基础操作
用了两张图 成功读取后打印了宽高和通道数 把图片缩小了一半 剪了中间一块 还变成了黑白图 都存进了 `outputs/task1` 原图没动 代码用的是相对路径（即前面加 `../` 那个）

## 四、任务二：基础处理对比
我用了一张红色球体的图：
1. **滤波模糊**：5x5的图看起来和原图差不多15x15的图边缘就明显糊了
2. **阈值黑白**：阈值设80的时候 球暗的地方也变白了 设成160时 球大部分地方都变成了黑的 只有最亮的地方是白的
3. **Canny 找边**：球的轮廓找得挺准的 就是球中间光影过渡的地方没找出来
4. **开运算**：在黑白图（阈值80的那张）上做了一次开运算 发现背景里一些乱七八糟的小白点被去掉了 球还是好好的

## 五、任务三：找颜色和框轮廓
我找了3张网图：两张是草地里的红苹果 一张是路面上的橙色锥形桶
- **测试效果**：锥形桶识别特别稳 因为路面是灰的 对比太明显了 但是红苹果那张图 苹果背光的地方有点黑 有时候边缘会断开 另外草地里有几片枯黄的叶子 差一点被认成了橙色
- **结果**：最后成功输出了黑白的 mask 图 还有画了绿框和中心点坐标的结果图
