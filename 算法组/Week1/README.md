## 提交目录

在本目录下新建你的个人文件夹（**姓名拼音，全小写**）：

```
算法组/Week1/
└── <你的姓名拼音>/
    ├── README.md              # 环境、运行方式、参数与问题记录（用 README模板.md 改）
    ├── src/
    │   ├── task1_basics.py
    │   ├── task2_processing.py
    │   └── task3_color_detect.py
    ├── data/images/           # 你的测试图片（≥3 张，公开素材注明来源）
    └── outputs/
        ├── task1/             # 缩放 / 裁剪 / 灰度结果
        ├── task2/             # 灰度、高斯滤波、阈值、Canny、形态学（≥5 张）
        └── task3/             # mask.png、result.png、≥3 张测试图的标注结果
```

> 任务四（选做，实时摄像头）：有视频/摄像头就做，脚本可以叫 `task4_camera.py` 一起放进 `src/`。

## 交什么、不交什么

| 要交 | 不要交 |
|---|---|
| 全部 `.py` 源码（注释清楚、相对路径） | 整个 conda 环境 / `venv` |
| `outputs/` 里的中间结果与对比图 | 数据集、模型权重、视频原文件（几 MB 以上） |
| `data/images/` 里的测试图（≥3 张） | `__pycache__`、`.pytest_cache` 等缓存 |
| `README.md`（依赖、运行命令、参数含义、一次失败案例） | 只交几张最终截图、「已完成」式说明 |

**图片体积**：单张压到 1 MB 内，单文件不超过 10 MB。原图太大就先缩放到 1280 宽以内再存。

## 提交流程

1. Fork 本仓库 → 2. Clone 你的 Fork → 3. `cd 算法组/Week1/` 建 `<姓名拼音>/` → 4. 按上面结构放文件 → 5. `git add` / `commit` / `push` → 6. 发起 Pull Request（模板会自动带出自查清单）。

## 提交前自查（最容易翻车的四条）

- [ ] 把仓库 clone 到**新目录**，照 README 的命令跑一遍，脚本还能跑通（这一步能查出一半问题）；
- [ ] 脚本里**没有** `C:\Users\...` 这种绝对路径；
- [ ] 换一张**没用过**的图跑任务三，掩膜还能出来（说明你真的调过参数，不是只对一张图调好）；
- [ ] 每张关键截图都带「姓名拼音 + 时间戳」。

> 时间戳命令：
> ```bash
> echo "姓名: <你的姓名拼音>"; date "+%Y-%m-%d %H:%M:%S"
> ```
