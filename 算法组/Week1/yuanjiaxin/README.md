## 3.任务二记录
- 关键参数及含义：
(1)ksize=(3, 3) 与 (7, 7):高斯滤波的平滑窗口尺寸（必须是正奇数）。
(2)thresh=150 与 180:灰度分割的亮度界限值。
(3)(30, 90) 与 (80, 200):边缘检测的低阈值（用于连接边缘）与高阈值（用于寻找强边缘）。
(4)kernel=(5, 5):开/闭运算的结构元素大小。
- 滤波前后变化：3x3 核去噪且保留边缘，7x7 核平滑效果更强，花瓣边缘变模糊。
- 阈值变化后发生变化区域：阈值 150 时花瓣面积大且干净；阈值 180 时过滤掉较暗的部分，花瓣面积变小。
- 边缘是否完整：：Canny (30,90) 边缘丰富但背景噪点多；Canny (80,200) 边缘干净，只保留强轮廓，但细小花蕊丢失。
- 开运算及闭运算解决的问题：开运算去除了背景残留的小白噪点；闭运算填补了花瓣内部的小黑洞。

## 4.任务三记录
- 关键参数及含义：
(1)lower_color / upper_color:目标颜色的上下限。
(2)kernel=(11, 11):用于开闭运算的结构元素。
(3)cv.RETR_EXTERNAL:只提取最外层轮廓。
(4)cv.CHAIN_APPROX_SIMPLE:压缩水平、垂直和对角线段，只保留端点。
(5)min_area=5000 min_area=1000:轮廓面积阈值。
- HSV范围设置依据：OpenCV 中 HSV 的取值范围分别是 H(0-179), S(0-255), V(0-255)。由于目标物体的颜色差异，分别设置了不同的阈值：
（1）img1.jpg：H 设为 [10, 30]（棕黄/橙色范围）；S/V 下限设为 [50, 50]，以提取暖色调的杯子和咖啡。
（2）img2.jpg：H 设为 [20, 35]（黄色色相范围）；S 和 V 下限设为 100，依据是防止将高亮偏白的云彩或偏暗的阴影误认为黄色。
（3）img3.jpg：H 设为 [35, 85]（绿色色相范围）；由于苹果表面有反光，S 和 V 下限调低至 [43, 46]，尽可能保留苹果主体。
- 面积阈值设置依据：测试图像分辨率较高，目标主体（杯子/苹果/花朵）的像素面积均在几万级别，5000 以下的连通域基本属于背景的零星噪点或细碎草叶，直接通过 if area > 5000 过滤，可大幅减少误检。
- 识别稳定的情况：目标颜色鲜明，且背景颜色与目标颜色差异极大，光照相对均匀。
- 容易误检的情况：背景中存在与目标物体颜色高度相近的干扰物。
- 容易漏检的情况：物体表面存在强烈的反光、高光，或者存在极暗的阴影。

## 5.失败案例和改进思路:
- 失败案例：任务三中在进行img3.jpg的颜色目标提取使用HSV 颜色阈值 [35, 43, 46] ~ [85, 255, 255] 提取绿色时，由于背景的草地同样是绿色，而min_area设定过低，导致大量草叶被判定为目标，画面上出现了几十个大大小小的红色外接矩形。
- 改进思路：将代码中的 min_area 阈值提高到 5000。由于苹果在画面中占据主体位置，其面积远大于单片草叶，通过 if area > 5000，成功过滤掉了大部分细碎的草叶噪点。
