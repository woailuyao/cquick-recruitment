## 一、本周目标

> 一句话：**搭好视觉开发环境，学会读取、观察、处理图像，并把成果规范地交到仓库。**

本周不要求训练深度学习模型，也不要求接入真实机器人。先把视觉算法最基础的输入输出跑通：

```text
摄像头 / 图片文件
      ↓
读取图像（OpenCV）
      ↓
观察图像尺寸、颜色通道、像素值
      ↓
完成基础图像处理
      ↓
保存结果 + 展示结果 + Git 提交
```

本周的三项任务对应这条链路上的三个环节：

| 任务 | 对应能力 | 干什么 |
| --- | --- | --- |
| 任务 1 | 环境与工具 | 配好 Python、OpenCV，确认版本和运行环境 |
| 任务 2 | 图像输入与理解 | 读取一张图片，查看尺寸、通道和像素信息 |
| 任务 3 | 基础图像处理 | 完成灰度化、颜色空间转换、阈值分割与结果保存 |

> ⚠️ **本细则只给流程和要求，不提供现成完整代码。** 可以查官方文档、教程，也可以问 AI；但必须理解自己写的每一行，并能现场解释结果。

## 二、前置准备

1. **准备 Ubuntu 22.04 环境**  
   优先使用战队统一的 Ubuntu 22.04 环境。虚拟机、双系统均可；如果已经有可用的 Linux 开发环境，不需要重复安装。遇到安装问题可以搜索「Ubuntu 22.04 安装 Python3」。
2. **安装 VSCode**  
   熟悉打开文件夹、编辑文件、打开终端、保存文件等基本操作。
3. **确认 Python 可用**

```bash
python3 --version
which python3
```

4. **建立个人练习目录**

```bash
mkdir -p ~/vision_ws/week1
cd ~/vision_ws/week1
```

5. **安装 OpenCV 与 NumPy**

```bash
python3 -m pip install --user opencv-python numpy
```

如果提示系统禁止直接安装 Python 包，请自行查阅 Ubuntu 的虚拟环境用法，使用独立虚拟环境安装，不要随意删除系统 Python 或强行覆盖系统依赖。

6. **确认依赖**

```bash
python3 -c "import cv2, numpy; print('OpenCV:', cv2.__version__); print('NumPy:', numpy.__version__)"
```

> 后续如果使用 ROS2、相机或深度学习框架，应优先使用独立环境，并记录 Python 版本与依赖版本。不要把不同项目的依赖随意装进同一个环境。

### 任务 2：读取图片并分析图像信息（35 分）

**要做什么**：自行准备一张图片，使用 OpenCV 读取，并在终端输出图像的基本信息。图片可以是足球、彩色物体或普通场景，但必须注明图片来源；优先使用自己拍摄的图片。

#### 2.1 必须输出的信息

| 信息 | 要求 |
| --- | --- |
| 图片是否读取成功 | 读取失败时要有明确提示，不能直接继续处理 |
| 图像宽、高 | 输出像素尺寸，例如宽 640、高 480 |
| 图像数组形状 | 输出 `shape`，解释各维度的含义 |
| 数据类型 | 输出 `dtype`，说明图像像素数据通常是什么类型 |
| 像素示例 | 打印一个像素位置的数值，并说明 OpenCV 默认彩色图像的通道顺序 |

> 提醒：OpenCV 读取彩色图片时通常采用 **BGR** 通道顺序，而不是 RGB。不要只背结论，最好用一个像素值或颜色转换实验验证。

#### 2.2 实现流程

1. 在个人目录下新建 `read_image.py`；
2. 使用 `cv2.imread()` 读取图片；
3. 判断返回结果是否为空；
4. 输出宽、高、`shape`、`dtype`；
5. 选取一个合法像素坐标，打印该像素的通道值；
6. 使用 `cv2.imshow()` 显示图片，按键后正常退出；如果当前环境没有图形界面，可以保存图片并说明原因。

**完成标准：**

- [ ] 图片读取成功，失败时能给出提示；
- [ ] 正确输出图像宽、高、`shape`、`dtype`；
- [ ] 能解释图像数组为什么通常是二维或三维；
- [ ] 能解释 BGR 与 RGB 的区别；
- [ ] 能处理图片路径错误，而不是让程序直接崩溃。

**截图要求：**

1. 终端输出图像信息；
2. 原始图片显示窗口或保存后的图片；
3. `read_image.py` 关键代码截图。

### 任务 3：基础图像处理小实验（35 分）

**要做什么**：基于任务 2 的图片，生成至少三种处理结果，并保存到个人提交目录。

#### 3.1 必做处理

| 操作 | 需要做什么 | 需要理解什么 |
| --- | --- | --- |
| 灰度化 | 把彩色图转成灰度图 | 为什么颜色通道数会改变 |
| HSV 转换 | 把 BGR 图像转换为 HSV | HSV 中色调、饱和度、明度分别描述什么 |
| 阈值分割 | 选择一个阈值或颜色范围，生成二值图 | 阈值变化为什么会影响分割结果 |

#### 3.2 结果要求

- 原图、灰度图、HSV 相关结果、二值分割结果都要保存；
- 至少比较两组不同的阈值/颜色范围，并写出结果变化；
- 如果选择足球或彩色物体，尝试解释颜色分割在真实场景中可能遇到的干扰，例如光照变化、阴影、背景颜色相似；
- 不要求本周达到稳定识别效果，重点是理解参数如何影响图像结果。

建议输出文件名：

```text
01_original.png
02_gray.png
03_hsv_or_mask.png
04_threshold_a.png
05_threshold_b.png
```

**完成标准：**

- [ ] 至少完成灰度化、HSV 转换、阈值分割；
- [ ] 结果图片可以重新打开，且不是空文件；
- [ ] 比较两组参数结果，说明差异；
- [ ] 能讲清楚阈值分割的局限性；
- [ ] 代码中有必要的注释，路径错误有提示。

**截图要求：**

1. 原图与处理结果对比图；
2. 两组阈值结果对比；
3. 终端运行成功的截图。

## 七、常见问题（FAQ）

**Q1：`import cv2` 报错怎么办？**  
A：先执行 `python3 -m pip show opencv-python`，确认安装位置；再检查运行脚本的 Python 是否与安装时一致。不要只反复安装而不检查解释器。

**Q2：`cv2.imread()` 返回 `None`。**  
A：通常是图片路径错误、文件不存在或格式无法读取。先检查 `ls`、路径和文件名，再给代码增加读取失败判断。

**Q3：为什么显示的颜色不对？**  
A：检查是否把 OpenCV 的 BGR 数据直接当成 RGB 显示；需要时显式转换颜色空间。

**Q4：阈值分割出来全黑或全白。**  
A：阈值范围可能不合适，也可能图像颜色、光照和背景不适合当前规则。尝试可视化 HSV 通道并比较不同参数。

**Q5：能直接复制 AI 给出的代码吗？**  
A：可以把 AI 当作辅助，但必须能解释关键语句、修改参数并说出输出变化。评审会随机提问，无法解释视为未完成。
