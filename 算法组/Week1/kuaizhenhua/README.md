至少两组参数对比已完成：

1. **高斯核 5×5 → 11×11**，其余参数不变，结果在 `gaussian_changed/`。11×11 比 5×5 更模糊，说明平滑增强的同时会损失细节。
2. **固定阈值 127 → 167**，高斯核均为 5×5，结果在 `threshold_changed/`。167 时勉强能认出上方文字，黑色区域变多。普通二值化中，大于阈值才变白，升高阈值会让部分原来的白色像素变黑。

这里的阈值按亮度分黑白，不能直接当成蓝色目标掩膜。闭运算先膨胀后腐蚀，能够填小黑空隙；开运算先腐蚀后膨胀，通常去除小白噪声。

其他对照包括 Canny 80/160 → 40/80、开运算核 3×3 → 9×9，按处理环节分别改变参数。补充目录还有均值/中值滤波、自适应阈值、腐蚀、膨胀和通道拆分。

### 任务三 · 颜色目标提取与轮廓定位

- 目标颜色：蓝色。
- HSV 范围：`lower=(95,80,70)`，`upper=(130,255,255)`。H 范围覆盖当前合成目标约 110 的色相；S 下限排除低饱和度区域，V 下限排除过暗区域。
- 面积阈值：500 像素平方。当前小噪点较小，最小目标的轮廓面积约 2525，这个门槛能排除小噪声并保留目标；换距离、分辨率或素材时需要重新比较。
- 形态学：3×3 椭圆核开运算，再做 5×5 椭圆核闭运算，均为 1 次。小核用于处理小噪点与小缺口，过大可能删掉小目标或粘连物体。

处理顺序为 BGR → HSV → `inRange` → 开闭运算 → 外轮廓 → 面积过滤 → 绘制外接矩形和质心。普通 8 位 HSV 的 H 为 0～179，S/V 为 0～255。以下五张图使用相同默认参数，均已亲自运行和观察。

每张图在 `outputs/task3/图片名/` 有独立目录：`01_mask_raw.png` 是原始颜色掩膜，`02_mask_opened.png` 是开运算结果，`mask.png` 是开闭运算后、**尚未按面积过滤**的掩膜；`04_mask_filtered.png` 则只保留面积合格的轮廓区域，两者用途不同。`05_extracted.png` 为提取的彩色区域，`result.png` 为标注图，`07_comparison.png` 为对比图。坐标、面积和矩形保存在各图的 `detections.json`，汇总见 `outputs/task3/detections.json`。

质心使用 `cx=m10/m00`、`cy=m01/m00`，分母为 0 时跳过。坐标单位是像素，左上角为原点，x 向右、y 向下。面积来自外轮廓，不扣内部孔洞，不等于白色像素数或外接框面积。方块的绿色轮廓与橙色框重合，后画的框会盖住绿色线；圆的两条线不重合，所以绿色更明显。

## 四、一次失败案例与改进思路
