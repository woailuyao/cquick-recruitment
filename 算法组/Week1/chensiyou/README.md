## 任务2：图像滤波、阈值分割、边缘检测
运行代码：python task2.py
功能：打开图片，转灰度，做高斯滤波，二值化，还有Canny找边缘，把处理好的图存起来。

### 滤波前后变化记录
原图是彩色的，先转成灰度图。
滤波之前的灰度图：图片上有很多小小的噪点，看着颗粒感很重。
做完高斯滤波之后：图片变平滑了，那些小杂点少了很多，代价就是图片稍微变糊一点点。
滤波之后再做后面的阈值和边缘检测，就不会冒出很多假的边缘，提取出来的轮廓干净不少。

处理完的图片会放在 outputs/task2 文件夹里。运行代码会弹出图片窗口，随便按一个键就能关掉窗口。

## 任务3：图像检测实验
运行代码：python task3.py
要求：找至少3张图片测试，图片的背景或者光线不一样，观察效果。
测试图片：
图片1：test1.jpg，光线正常，背景简单干净
图片2：test2.jpg，光线比较暗，背景东西很多很乱
图片3：test3.jpg，光线很强，画面有反光

### 测试记录
1. 图片1（正常光线、简单背景）：
检测效果最好，目标轮廓基本都识别出来，杂点很少。

2. 图片2（暗光、背景复杂）：
整张图偏暗，目标有些地方的边缘看不清，多出来一些噪点，有的轮廓直接断掉了。

3. 图片3（强光反光）：
反光的地方灰度乱跳，出来很多不该有的边缘，目标有些区域被亮光盖住，检测出错比较多。

总结：光线稳定、背景简单的时候检测效果更好；光线太暗、太亮或者背景东西多，检测效果就变差。

运行生成的图片保存在 outputs/task3 文件夹。

## 运行遇到的问题
1. 最开始忘记写保存图片的代码，跑完程序找不到输出图片，加上imwrite之后就好了。
2. 一开始任务2和任务3的保存路径写的不对，图片存到别的地方去了，还多出了没用的文件夹。后来学会用`../`跳到上一层文件夹，改完路径之后，图片就能正确存到output对应的文件夹里，弄懂了相对路径怎么用。
3. 如果输出文件夹不存在，代码会报错，所以我加了代码自动创建文件夹。
4. 任务3最开始没有弹窗看图片的代码，运行不会弹出图片窗口，加上imshow和waitKey之后就能预览图片了。
5. 图片路径写错的时候程序读不到图片，修改好相对路径后才能正常读取。
