## 四、一次失败案例与改进思路

- 现象：把蓝圆柱的参数（S≥120、7×7 开运算）套到蓝鸟上，mask 只剩翅膀一小块，尾羽丢了；换成闭运算后变成两个框。
- 怎么查的：打印目标像素 HSV，发现羽毛饱和度只有 60 左右；对 S 下限扫 40/60/80/100，看前景占比和连通块；再对核大小扫 9/15/21/31，看轮廓数。
- 原因：浅蓝饱和度低被筛掉，白肚子把蓝羽隔成两块，7×7 的核连不起来。
- 改进：S 下限降到 60，闭运算核加到 21×21，面积阈值改成按图像比例。
- 效果：静态图单框 304918，视频 193 帧全部单框，中心轨迹连续。彻底背对时仍可能漏检。

另外 OpenCV 5 的高斯核必须是正奇数，写 (20,20) 会断言失败，改成 21 才能跑。

## 五、给下周自己的提醒

- 先看目标区域的 HSV 分布再定区间，S 和 V 的下限比 H 更容易出问题。
- 形态学核大小和分辨率绑定，换尺寸要跟着换，不要直接照抄。
- 二值化前先看背景占比，cat_bin 前景 86.85% 说明 OTSU 不适合这种浅背景的图。
- 中文路径只影响 imread 和 imwrite，VideoCapture 和 VideoWriter 没这个问题。
