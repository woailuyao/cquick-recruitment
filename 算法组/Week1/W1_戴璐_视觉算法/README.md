## 四、一次失败案例与改进思路

- **现象**：在处理图 3（密集键盘背景）时，同一组 HSV 参数下，原本用于识别橙色笔的绿框，突然变得极其庞大，把旁边的白笔和键盘全都框了进去。
- **我是怎么查的**：查看掩膜图（Mask），发现闭运算把相近颜色的物体糊成了一个巨大的连通区域。打印最大轮廓面积，发现从原本的 4 万变成了 8.3 万。
- **原因**：背景物体太近且存在阴影，导致掩膜严重粘连。算法使用了 `max()` 提取最大轮廓，导致系统误以为这个超级大色块就是目标。
- **改进**：收紧 HSV 阈值（提高饱和度S的下限）剔除浅色阴影；同时在代码中准备加入“长宽比（Aspect Ratio）”过滤，剔除方正的大色块。
- **改进后效果**：目前图1完美识别，图2、图3已定位出漏检/误检的原因，后续将继续优化算法。
