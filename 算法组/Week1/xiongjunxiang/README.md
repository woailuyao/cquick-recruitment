## 四、一次失败案例与改进思路

- **现象**：三张图一开始全都读不出来，`cv2.imread` 返回 `None`，但图片在资源管理器里双击能正常打开。
- **我是怎么查的**：先在代码里打印 `img is None`，确认不是文件名写错；接着把同一张图复制到纯英文目录
  能正常读出，放回中文目录就失败，于是确定问题出在路径字符， 发现 OpenCV 在 Windows 上处理中文字符有问题。
- **原因**：路径里含中文（本作业的文件夹名 `W1_熊俊翔_视觉算法` 就带中文）时，`cv2.imread`
  打不开文件，但**不抛异常，只返回 None**，看起来就像"图片坏了"，很难一眼看出是路径问题。
- **改进**：读图改成 `np.fromfile(path, np.uint8)` ，再用 `cv2.imdecode(data, 1)` ；
  写图改成 `cv2.imencode(ext, img)` 后再 `buffer.tofile(path)`。
- **改进后效果**：3 张图全部能正常读取和保存。

另一个还没解决的现象：`cqu.jpg` 用绿色阈值会把树林、草地和泛绿水面
连成一块跨全宽的大目标，属于"颜色法分不清背景和目标"，下一步准备给面积加一个上限、
并把阈值改成按目标区域统计色相后取区间。
