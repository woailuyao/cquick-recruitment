## 3. 关键参数及其含义

在图像预处理与颜色提取过程中，代码中使用了以下关键参数，其具体含义如下：

- **图像缩放比例**:原图分辨率极高（4096x3072）且存在噪点，缩放至原图20%不仅能大幅提升处理速度，还能平滑边缘的高频噪点。
- **高斯滤波核大小**:高斯模糊的窗口大小。必须为奇数。在任务三中用于平滑图像，消除图像中的高斯噪声，减少毛绒玩具纹理造成的干扰。
- **HSV 颜色范围**:在任务三中，目标物体为绿色。H(色调)取35-85覆盖绿色区间；S(饱和度)和V(亮度)下限设为50，用于过滤偏灰和偏暗的背景噪点。
- **形态学核大小**:用于开运算和闭运算。核越大，消除噪点/填补孔洞的能力越强。在任务三中，由于毛绒玩具边缘破碎，调大至15x15可强行将目标连接成一个完整的大白块。
- **轮廓面积阈值**:过滤面积小于5000的轮廓。在任务三中用于剔除背景中偶然出现的小色块和玩具表面断裂的小纹理，仅保留真正的目标主体。
- **固定阈值**:将灰度图转化为二值（黑白）图。阈值越高，白色区域越少（只保留极亮的部分）；阈值越低，白色区域越多。
- **Canny 阈值**:Canny边缘检测的高低阈值。低阈值用于发现更多边缘细节（但易引入噪点），高阈值用于保留强边缘。

## 5. 任务二：参数记录与对比
- **滤波前后变化**：高斯滤波后图像变模糊，去除了噪点，保留了大体轮廓。
- **阈值影响**：阈值设为100时，白色区域较多；调高到180时，白色区域减少，较暗的部分变成了黑色。
- **Canny边缘**：阈值较低（50,150）时，提取的边缘细节多但可能有噪点；阈值升高（100,200）时，只保留最明显的边界，边缘变少。
- **形态学作用**：使用开运算（MORPH_OPEN）去除了阈值图中周围的小白噪点。

## 6. 任务三：颜色提取记录
- **HSV范围设置依据**：目标物体为绿色，因此H值设定在100-130之间，S和V设定在较高范围以过滤背景。
- **面积阈值**：设为500，用来过滤画面中偶然出现的小色块噪点，只保留主体目标。
- **识别情况**：
  - **识别稳定的情况**:img2光照充足，背景单一，绿色物体占据画面大部分区域，掩膜图完整，识别准确。
  - **容易漏检，误检的情况**:极暗光环境或画面存在多个同色不连通区域时容易漏检，存在强反光环境时容易误检。
  **失败案例**:img3原图分辨率极高，且毛绒玩具表面存在大量阴影纹理，导致生成的Mask图断裂。findContours找到大量小碎块，标记出大量绿框，无法定位主体。
  **改进思路**:将图片按比例缩小，加快处理速度并减少噪点，加入高斯滤波平滑，增大形态学操作的核，放弃遍历所有轮廓，直接使用max()提取面积最大的轮廓。
