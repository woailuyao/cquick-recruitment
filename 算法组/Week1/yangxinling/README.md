## 3. 任务二：基础图像处理对比

**完成情况**：代码位于 `src/task2_processing.py`。选取了一张目标清晰的红苹果图片进行测试，输出了灰度图、滤波图、阈值图、Canny 边缘图及形态学处理图，共13张。

**参数对比与记录分析**：
1.  **滤波前后变化**：
    *   使用 `(5,5)` 高斯核时，苹果表面斑点变淡，边缘依然锐利。
    *   更换为 `(25,25)` 大核后，苹果外轮廓轻微模糊。
    * **结论：核越大平滑越强，但会损失边缘细节。**
2.  **阈值调高/调低的影响**：
    *   阈值设为 `100`（调低）时，白底部分被识别为目标（变白），未包含阴影。
    *   阈值设为 `200`（调高）时，只有最亮的部分变白，阴影被剔除。
    * **结论：阈值越高，提取的亮区越纯粹、越少。**
3.  **边缘是否完整**：
    *   使用 `Canny(10, 30)` 时，因为白底与红苹果对比极强，边缘较完整，但没能排除了苹果内部细微纹理的干扰。
4.  **形态学处理解决什么**：
    *   对阈值分割后的图使用 `(20,20)` 核进行闭运算，有效填补了果蒂附近的细小黑色孔洞。
    * 开运算有效去除了苹果表面的细小白色噪点。

**失败案例与改进思路**：
*   **失败场景**：最初选用浅绿色保温杯测试，由于杯身与木纹背景的灰度值非常接近，阈值分割时两者粘连在一起，无论怎么调整单一阈值都无法分离。
*   **改进思路**：换成红苹果和白底。

## 4. 任务三：颜色目标提取与轮廓定位

**完成情况**：代码位于 `src/task3_color_detect.py`。选择红苹果作为目标，在 3 张不同背景/光照的图片上测试了颜色提取、形态学去噪、轮廓查找及中心点标注。

**参数设置依据**：
*   **HSV 范围**：由于红色在 HSV 空间中横跨 0 和 180 两个区域，因此设置了两段阈值并用 `cv2.bitwise_or` 合并：
    *   区间一：`[0, 100, 50]` 到 `[10, 255, 255]`
    *   区间二：`[170, 100, 50]` 到 `[180, 255, 255]`
    *   S（饱和度）和 V（明度）的下限设为 100 和 50，是为了过滤掉白底背景和暗部阴影，防止误检。
*   **面积阈值**：过滤掉 `area < 10000`。
	*   **失败场景**：初试设置为`area < 1000`，产生误检
    *   苹果在画面中占据面积较大，而背景噪点面积较小。

**测试结果与问题分析**：
1.  **白底图（简单背景）**：识别极其稳定，掩膜完整，矩形框和中心点定位精准。
2.  **杂乱背景图（强干扰）**：
	*   **失败场景**：背景右侧有一个红色的零食包装袋，由于颜色与苹果相近，直接被算法识别并框出，产生**误检**。
    *   **改进/解决办法**：结合“目标通常位于视野中心”的逻辑，增加了**位置过滤**（判断中心点 X 坐标是否在图像宽度的 25%~75% 之间和中心点 Y 坐标是否在图像高度的 25%~75% 之间），成功忽略了边缘的红色干扰物。
