# W1_杨舒媛_视觉算法

## 1. 运行说明
* **环境**：Python 3.12 + OpenCV 5.0.0
* **运行方式**：在终端进入 `src` 目录，依次运行 `task1_basics.py`、`task2_processing.py`、`task3_color_detect.py`、`task3_improved.py`。

---

## 2. 任务一：图像基础操作
* **执行简述**：读取图片并打印了宽、高、通道数；完成了缩放、指定区域裁剪与灰度转换。所有处理后的结果均已保存至 `outputs/task1/`，原图未被覆盖。

---

## 3. 任务二：基础图像处理对比
* **执行内容**：对图片进行了灰度、滤波、阈值分割、Canny边缘检测以及形态学处理，结果保存在 `outputs/task2/` 中。
* **参数对比与分析**：
  * **高斯滤波**：对比 `(5,5)` 和 `(21,21)` 核。核越大图像越模糊，细节丢失越严重，但平滑背景噪点的效果更明显。
  * **阈值分割**：对比阈值 `100` 和 `150`。阈值调低（100）时，阴影等暗部变白；阈值调高（150）时，目标白色区域缩小，丢失部分卡片内容。
  * **边缘检测与形态学**：Canny提取了轮廓，但背景木纹也形成了噪点；开运算有效去除了这些小面积白色噪点，使边缘平滑。

---

## 4. 任务三：颜色目标提取与轮廓定位
* **执行内容**：BGR转HSV生成掩膜；形态学清理；`findContours` 查找轮廓并计算外接矩形与中心点，输出坐标面积，保存 `mask.png` 和 `result.png`。
* **参数依据**：
  * **HSV 范围**：H 值锁定 85~135。S、V 下限设为 40，是为了包容阴影与反光造成的光照变化，防止目标漏检。
  * **面积阈值**：设定下限 `1000`，用于过滤桌面碎小的反光噪点，保留主体。

### 4.1 测试记录与失败案例
* **正常场景（图2、图3）**：识别稳定，反光环境下依靠闭运算依然能准确定位。
* **极端干扰（图4）**：发生严重误检。同色高数书与卡片紧贴，在掩膜中粘连，导致画出了面积达 95 万像素的巨型错误框。

### 4.2 改进思路与局限性总结
* **改进实现**：尝试形态学强行分割（导致卡片碎裂）和宽度过滤（导致漏杀）均失败。最终采用**特征色细分**，通过提高 HSV 的饱和度与明度下限，成功过滤掉深蓝色的书本，仅提取卡片上方的“淡蓝色”区域，实现精准定位。
* **局限性反思**：在传统视觉中，目标与干扰物颜色一致且物理紧贴时，仅靠颜色特征很难完美分离。若要彻底根治，后续需引入**深度学习目标检测模型**。
