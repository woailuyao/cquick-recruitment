## 五、任务二参数对比分析（实测数据）

输入：real\_red\_apple.jpg（真实照片，红苹果静物，2364×1773）；另一张真实照片（公园）对比见 5.5

### 1. 高斯滤波 —— 核大小的影响



| 参数             | 与灰度图平均绝对差 |
| -------------- | --------- |
| kernel = 5×5   | 0.75      |
| kernel = 31×31 | 1.96      |

**结论**：核越大，平滑越强、图像与原始灰度图的差异越大、边缘越模糊；真实照片纹理细节多，5×5 保留更多细节，31×31 去噪更彻底但损失边缘。

### 2. 阈值分割 —— 阈值高低的影响



| 参数                   | 白色像素占比          |
| -------------------- | --------------- |
| thresh = 100         | 84.5%（浅色木桌大片保留） |
| thresh = 200         | 30.7%（苹果高光区仍保留） |
| 自适应阈值（block=51, C=5） | 93.1%           |

**结论**：阈值越低保留的区域越多。真实照片亮度分布广：t100=84.5%（浅色背景大片留下）、t200=30.7%（高光区仍保留），固定阈值很难一劳永逸；自适应阈值按局部亮度逐像素分割，93.1% 最稳、鲁棒性更好。

### 3. Canny 边缘 —— 双阈值的影响



| 参数         | 边缘像素数 |
| ---------- | ----- |
| (50, 150)  | 42906 |
| (100, 200) | 13834 |

**结论**：真实照片边缘丰富、弱边缘多：高阈值 (100,200) 比低阈值 (50,150) 滤掉 68% 弱边缘，双阈值作用清晰可见；阈值越高轮廓越干净，需按图像噪声水平调整。

### 4. 形态学处理 —— 开 / 闭运算的作用



| 操作              | 白色像素占比 |
| --------------- | ------ |
| 处理前（thresh=100） | 84.5%  |
| 开运算（5×5 核）      | 83.8%  |
| 闭运算（5×5 核）      | 85.2%  |

**结论**：真实照片存在噪点与内部空洞：**开运算**（先腐蚀后膨胀）去除小噪点，白比下降（84.5%→83.8%）；**闭运算**（先膨胀后腐蚀）填补小洞，白比上升（→85.2%）。二者实际用途在真实照片上可见效果。

### 5. 真实照片横向对比（红苹果 vs 公园）

输入：两张真实照片，验证不同场景下参数的实际效果（红苹果 2364×1773 / 公园 2364×1773）：



| 对比项                   | 红苹果             | 公园             | 差异解读                       |
| --------------------- | --------------- | -------------- | -------------------------- |
| 高斯 gray-g5            | 0.75            | 7.52           | 公园纹理丰富（树叶 / 石板），模糊差异最大     |
| 高斯 gray-g31           | 1.96            | 17.87          | 核越大差异越大，公园最明显              |
| 阈值白比 t100             | 84.5%           | 15.3%          | 苹果浅色背景大片保留，公园暗部多           |
| 阈值白比 t200             | 30.7%           | 3.5%           | 固定阈值随画面亮度变化大，需按图调整         |
| 自适应阈值白比               | 93.1%           | 50.9%          | 自适应按局部亮度分割，两场景均稳定          |
| Canny 边缘像素 (50,150)   | 42906           | 649883         | 公园细节边缘暴增（树叶 / 纹理全算作边缘）     |
| Canny 边缘像素 (100,200)  | 13834           | 527845         | 高阈值滤弱边：苹果滤 68%，公园滤 19%     |
| 形态学 before/open/close | 84.5/83.8/85.2% | 15.3/8.4/20.4% | 开 / 闭运算在真实照片上均明显见效（公园幅度更大） |

**结论**：



1. **真实照片让参数效果全面显现**：高斯核大小（0.75→1.96、7.52→17.87）、Canny 双阈值（弱边缘剔除）、形态学开 / 闭（去噪 / 补洞）均可用数据证明；

2. **固定阈值不稳定**：苹果 t200=30.7% 仍保留高光区、公园 t200=3.5% 暗部丢失 —— 自适应阈值按局部亮度分割更稳，印证任务三应优先用 HSV 颜色提取而非固定阈值；

3. **场景差异显著**：公园细节多（Canny 达 64 万像素、高斯差值 17.87），苹果目标单一（形态学开闭变化小但可测）—— 参数效果强度与图像纹理复杂度成正比。

## 六、任务三参数分析（实测数据）

输入：3 张合成图，每张提取一个目标色

### 1. HSV 范围设置依据

目标色由合成图的已知 RGB 经 BGR→HSV 换算实测（脚本内附计算值）：



| 图     | 目标  | RGB          | 实测 HSV        | inRange 范围                         |
| ----- | --- | ------------ | ------------- | ---------------------------------- |
| test1 | 橙矩形 | (255,160,40) | (17,215,255)  | H 5\~30, S 100\~255, V 100\~255    |
| test2 | 绿圆  | (40,180,60)  | (64,198,180)  | H 50\~80, S 100\~255, V 100\~255   |
| test3 | 蓝圆  | (50,60,220)  | (118,197,220) | H 100\~135, S 100\~255, V 100\~255 |

S/V 下限取 100：目标饱和度均 >75%，背景为低饱和灰 / 深蓝，可在饱和度维度安全分离。

### 2. 面积阈值设置依据

目标实际面积 9318\~50400 px，最小目标远大于 500 px；合成图无噪声，掩膜中不存在大块噪声连通域，故取 500 px 过滤孤立小连通域。

### 3. 识别结果（3/3 全部成功）



| 图     | 目标  | 中心 (x,y)  | 面积 px | 理论中心      | 理论面积   | 偏差    |
| ----- | --- | --------- | ----- | --------- | ------ | ----- |
| test1 | 橙矩形 | (320,240) | 50400 | (320,240) | 50400  | 0     |
| test2 | 绿圆  | (320,240) | 31130 | (320,240) | ≈31416 | <0.9% |
| test3 | 蓝圆  | (200,240) | 9318  | (200,240) | ≈9503  | <1.5% |

**结论**：中心点与理论值一致（≤1px），面积误差 <1.5%，"HSV 提取 → 开 / 闭运算 → 轮廓定位" 全流程稳定；外接矩形与目标贴合（test2 圆的外接矩形为 199×199 近正方形）。

### 4. 局限与改进

1，HSV 范围为固定值，真实照片光照变化需重新标定（可先手工取色再微调）。

2，面积阈值需按场景目标大小调整：过低引入背景噪声，过高漏检小目标。

3，开 / 闭运算在合成图上无可见效果（无噪点 / 空洞）；真实照片掩膜中作用明显。

## 七、已知局限与改进思路（失败案例分析）

1，**固定阈值不稳定**：苹果 t200=30.7% 仍保留高光区、公园 t200=3.5% 暗部丢失 → 改进：改用自适应阈值或 HSV 颜色范围提取（任务三使用 inRange 按颜色分割）。

2，**形态学核大小需按目标调整**：苹果开闭运算变化较小（±0.7%），公园变化显著（±5%）→ 核大小与是否使用需按图像噪点 / 空洞程度调整。

3，**Canny 双阈值需按图调整**：苹果高阈值滤掉 68% 弱边、公园只滤 19% → 需按图像纹理 / 噪声水平实验选取，避免边缘断裂或噪声过多。
