任务二：基础图像处理对比

本任务使用图片 img2.jpg（郁金香），输出的中间结果保存于 outputs/task2/。

参数对比与观察记录：

1. 高斯滤波对比 (3x3 vs 33x33)
   · 观察结果：(3,3) 核仅有轻微平滑效果；(33,33) 核模糊程度极高，丢失大量边缘细节。
   · 结论：核尺寸必须为奇数。核越大，平滑效果越强，去噪能力变强但细节保留变差。
2. 固定阈值分割对比 (80 vs 127)
   · 观察结果：阈值为 80 时，较暗的花瓣也被纳入了白色区域；阈值调高至 127 后，只有高亮区域变白。
   · 结论：阈值调低，白色目标区域扩大；阈值调高，目标区域缩小。
3. Canny 边缘检测对比 ((50,150) vs (100,200))
   · 观察结果：低阈值 (50,150) 提取的边缘更密集、完整，但也包含了噪点；高阈值 (100,200) 边缘线条变少，主体轮廓出现部分断裂。
   · 结论：低阈值敏感度高，高阈值过滤严格。先做高斯滤波再找边缘，效果更干净。
4. 形态学开运算 (3x3)
   · 观察结果：对阈值为 80 的二值图进行开运算后，边缘变得平滑，原本孤立的细小白色噪点被成功去除，且目标主体大小基本不变。

任务三：颜色目标提取与轮廓定位

本任务以红色物体为目标，测试了 3 张不同背景的图片（img2.jpg, img7.jpg, img10.jpg），结果保存至 outputs/task3/。

1. 关键参数设置依据

· HSV 范围设置：在 OpenCV 中，红色的 H 值横跨了 0 和 180 两端。因此必须分两段提取：[0, 80, 50] ~ [10, 255, 255] 和 [160, 80, 50] ~ [179, 255, 255]，然后用 cv2.bitwise_or 合并。如果只用单区间，一定会漏检。
· 形态学处理：使用了 (5,5) 核的开运算（先腐蚀后膨胀），目的是去除背景中散落的细小红点噪声，使目标区域更加干净。
· 面积阈值依据：设置 area > 500。通过观察掩膜（mask）发现，背景干扰噪点的面积通常在几十到一百左右，而正常目标物体的面积远超 500。该阈值能有效过滤小噪点，同时避免把真正的目标滤掉。

2. 多图测试记录

· 测试图 1 (img2.jpg)：识别稳定。画面中红色特征明显，成功框出最大的红色目标，并计算出中心点。
· 测试图 2 (img7.jpg)：识别稳定。在绿背景下的红花，对比度很高，HSV 阈值提取非常完整，中心点定位准确。
· 测试图 3 (img10.jpg)：出现轻微误检/漏检。画面中出现了多个包含红色的区域（比如红蘑菇和其他暖色块），因为代码里使用了 max() 只取面积最大的一个轮廓，导致画面中其他较小的红色目标没有被框出来。

3. 失败案例分析与改进思路

· 失败现象：在 img10.jpg 中，画面里存在多个红白相间的物体或红色反光，由于代码只取面积最大的轮廓，导致其他红色小目标被忽略。
· 改进思路：如果场景中存在多个目标，不应该使用 max() 取最大，而应该遍历所有的轮廓（for cnt in contours:），只要面积大于 500 的，都给它画上框和中心点。
· 补充：如果目标表面有强反光导致红色提取断裂（掩膜断开），可以在开运算之后增加一次闭运算，或者把形态学核的尺寸调大（如 7x7 或 11x11），让断开的地方重新连起来。

学习过程中的踩坑与总结

1. 读取失败无防护：cv2.imread 找不到图不会报错，只返回 None，必须用 if img is None: 判断。
2. 路径拼接：直接用字符串加容易漏斜杠，使用 os.path.join() 更安全。
3. 颜色空间转换：GRAY（灰度）用于阈值和边缘；HSV 专门用于颜色检测，不能混淆。
4. OpenCV 与 Matplotlib 显示冲突：OpenCV 读进来是 BGR 格式，Matplotlib 显示用 RGB 格式，显示彩色图前必须 cv2.cvtColor(img, cv2.COLOR_BGR2RGB)，否则红蓝会互换。
5. 形态学核类型：kernel = np.ones((5, 5), np.uint8) 中的 np.uint8 绝对不能漏。
6. cv2.imshow 窗口超出屏幕：如果直接使用 cv2.imshow 显示高分辨率图片，弹出的窗口会远超显示器范围，且无法拖动或关闭。解决方法：
使用 Matplotlib 的 plt.imshow() 替代 cv2.imshow。Matplotlib 不仅会自动适配屏幕大小，还能方便地在同一张图里并排对比多张中间结果，非常适合算法调试。
