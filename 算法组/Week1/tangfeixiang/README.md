# W1 视觉算法第一周作业

## 1. 环境与运行说明

- **开发环境**：Python 3.10 (Conda 环境 `cv_practice`)
- **依赖安装**：`pip install opencv-python numpy matplotlib`
- **运行方式**：脚本里读写用的是相对路径（如 `../data/images/test1.jpg`），所以**必须先进入 `src` 目录再执行**，不能在项目根目录直接跑。
  ```bash
  cd src
  python task1_basic.py
  python task2_processing.py
  python task3_color.py
  ```
- **路径说明**：在项目根目录执行 `python src/xxx.py` 会报「图片读取失败」，因为 `../` 会指到项目目录的上一层。另外在 Windows 上 OpenCV 读含中文的绝对路径也会失败，而 `../data/...` 这种全 ASCII 的相对路径没有这个问题。
- **输入输出**：输入读 `data/images/`，输出写到 `outputs/task1|task2|task3/`。

## 2.任务一

- **读取与信息**：用 `test1.jpg`，读入后打印尺寸 `宽:381 高:266 通道:3`。
- **缩放**：`cv2.resize` 缩到 100×100，输出 `outputs/task1/resized.jpg`。
- **裁剪**：按 `img[100:200, 100:200]` 截取一块区域，输出 `outputs/task1/crop.jpg`。注意 OpenCV 是先行后列，`img[y1:y2, x1:x2]`。
- **灰度**：`cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)`，输出 `outputs/task1/gray.jpg`。
- **验证**：最后把 `gray.jpg` 再读回来一次，确认文件真的保存成功。

## 3.任务二

- **滤波**：使用后图片噪点减少，物体边缘变得平滑柔和。
- **阈值**：阈值越高，白色区域越少，说明阈值与亮度门槛有关。
- **Canny与闭运算**：有效填补目标的孔洞与边缘轮廓，使得输出轮廓更完整。

## 4.任务三

- **hsv范围**：通常是查阅hsv颜色的相应范围表来锁定相应范围，同时可以通过调参来扩大/缩小目标范围，达到准确找到目标的目的。这次用的橙色范围是 `lower=(0,50,50)`、`upper=(15,255,255)`。
- **轮廓筛选**：目前**没有设最小面积阈值**，是直接用 `max(contours, key=cv2.contourArea)` 取面积最大的轮廓来定位目标。这样能跳过小噪点，但当背景有相近颜色时，最大轮廓可能被背景抢走（见失败案例）。最小面积阈值是下周需要补上的。
- **中心点**：用轮廓矩计算，`cx = m10/m00`、`cy = m01/m00`，并处理 `m00 == 0` 的情况。

## 5.失败案例

- **失败原因**：在test3_warm.jpg的调试中，由于背景的颜色与目标颜色hsv范围接近，导致mask生成时有过多背景被加入进来，导致识别不准确，范围变大。
- **改正方法**：调试hsv参数，发现目标的颜色更接近红色，于是将原来的[15,25]改为[0,15]，发现生成的背景白点被分散，再加上运用的max函数，使得准确识别目标。

## 6.目录结构

- **src**：包含任务源码。
- **data/images/**：测试用的原图。
- **outputs**：中间结果，掩膜图和最终结果。
