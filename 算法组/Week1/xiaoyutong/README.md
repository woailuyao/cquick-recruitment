##      任务二：处理对比与观察结果（重点）

跑完任务二，我对着弹出来的图对比了一下，具体变化如下：

1.  **高斯滤波前后的变化**：
    *   加了高斯滤波（核设成了 5x5）之后，最直观的感觉就是**图片像开了磨皮一样变糊了**。原本图片里比较尖锐的噪点和纹理变得柔和了。
2.  **阈值调高/调低的变化**：
    *   我试了 80 和 150 两个阈值。我发现**阈值调低（80）的时候，画面里大片区域都变成白色了**，因为门槛低，很多稍微亮一点的地方就过关了；而**阈值调到 150 时，大部分都变成了纯黑**，只有最亮的反光部分留了下来。
3.  **Canny 边缘是否完整**：
    *   用了两组参数对比（30,100 和 100,200）。低阈值的时候，抓取到的线条非常多，连一些细微的纹理都画出来了，但显得很杂乱，**边缘不够干净**；高阈值的时候，线条少了很多，**轮廓虽然干净了，但有些弱边缘断裂了，不够完整**。
4.  **形态学开运算解决了什么**：
    *   把 Canny 提取出来的线稿做了开运算，原本线条周围有很多孤立的、碎碎的小白点，做完开运算之后，**那些像头皮屑一样的小白点（噪点）真的被抹掉了**，主体轮廓变得很顺滑。

##     任务三：颜色提取与漏检分析

这个任务是用 HSV 找颜色并画框（见 `outputs/task3/`）。

*   **成功的情况**：测试那张蓝色包装的冰淇淋图时，把 H 值调到 90-130 范围，能精准抓到那个蓝色。画了绿色的外接矩形和红色的中心点。为了防止反光导致掩膜内部有小黑洞，我还加了 `MORPH_CLOSE`（闭运算）把它填满。
*   **漏检/误检分析**：我拿了黄色鸭子和抹茶蛋糕测试，结果它们两个的 mask 完全是黑的。去查了一下才发现，HSV 对颜色要求极高，黄鸭（H值约20）和蛋糕（H值约50）根本不在我设的蓝色范围里。这就说明，如果换个环境或者光照变了，这套参数可能就废了，实际用的话必须得根据现场光线重新调 H 和 S 的值，否则极易漏检。
