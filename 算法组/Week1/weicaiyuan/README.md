## 任务二：基础图像处理对比 

# 一、环境与运行方式

# 二、关键参数及现象分析  

1. 高斯滤波对比（02_blur_3x3 vs 03_blur_7x7）

现象：3x3 核滤波后，边缘相对清晰；7x7 核滤波后，派大星身体的黑线轮廓明显变模糊。

结论：高斯核越大，平滑去噪越强，但会抹除图像的高频细节（细线）。  

2. 正向阈值分割（04_thresh_bin_80 vs 05_thresh_bin_150）

现象：阈值设为80时，由于门槛低，很多线条没被判定为黑色，身体轮廓断裂消失；阈值设为150时，保留了更多的黑线。
   
结论：阈值调低，容易丢失深色线条；阈值调高，能保留更多细节，但背景噪点也会增加。针对灰度差异较小的图，固定阈值效果有限。  

3. 反向阈值提取目标（06_thresh_inv_200）操作：使用反向阈值（cv2.THRESH_BINARY_INV），阈值设为200。

现象：将白背景变黑，灰色身体变白，成功得到了完整的派大星剪影。

结论：当目标比背景暗、但又不是纯黑时（如灰色），反向阈值比正向阈值更容易提取完整目标。  

4. Canny 边缘检测（07_canny_50_150 vs 08_canny_100_200）

现象：50/150 检测出的边缘呈双线，噪点较多；100/200 边缘更干净，但嘴巴和眼睛的部分线条出现断裂。  

结论：Canny 的高低阈值决定了边缘的强弱。低阈值越多越杂，高阈值越干净但容易漏掉细节。  

5. 形态学处理（09_morph_open_5x5 vs 10_morph_close_5x5）  

操作对象：对反向阈值图（06）进行操作。  

现象：开运算（Open）去除了剪影边缘细微的白色毛刺噪点；闭运算（Close）把剪影内部的小黑洞（如眼睛内部、嘴巴缝隙）全部填平了，使白色区域更加完整。  

结论：开运算用于去噪点，闭运算用于填补孔洞。  

# 三、失败案例与改进思路  

1. 失败案例：在进行正向固定阈值（阈值80）时，派大星的身体轮廓大面积断裂，只剩下少许极黑的线条。  

2. 原因分析：原图是灰度图，身体轮廓的灰度值较高。阈值80太低，导致大部分轮廓线未被识别为前景。  

3. 改进思路：对于这种灰度图像，改用反向阈值或自适应阈值能更好地保留目标的整体形状，而不是单纯依赖固定全局阈值。



## 任务三：颜色目标提取与轮廓定位  


# 图片一测试记录（data/images/picture3. jpg）  

1. 环境条件：室内正常光照，木纹背景，带有绿叶遮挡及高光反光。  

2. 参数设置：lower_color \(=\) [5,120,100]，upper_color \(=\) [25,255,255]；面积阈值min_area \(=\) 3000。  

3. 成功现象：
1.成功提取到了两个橘子，背景木纹和绿色叶子被有效过滤。
2.算法正确输出了两个目标的中心坐标（686，534）和（376，529），以及对应的轮廓面积68092.0和49351.5。
3.右侧橘子表面的高光反光在掩膜图（mask.png）中形成了一个黑洞，但并未影响该目标主体轮廓的识别。  

4. 失败/干扰情况分析：  

左侧橘子边缘受到绿叶遮挡，导致其轮廓面积小于右侧。如果在实际应用中目标被遮挡更严重，可能会导致提取的掩膜面积小于min_area，从而发生漏检。  

改进思路：后续可以通过调整V（明度）的下限，或者使用闭运算 （cv2.MORPH_CLOSE）来填补高光产生的黑洞，使目标轮廓更加完整。


# 图片二测试记录（data/images/picture4.jpg） 

环境条件：
暗光/背光环境，深色树叶背景，橘子表面有树叶遮挡和阴影。  

参数设置：  

1. HSV范围：lower_color=[5,120,100]，upper_color=[25,255,255]  

2. 形态学处理：14x14闭运算（填补裂缝），5x5开运算（去噪）  

3. 过滤条件：面积阈值min_area=3000，宽高比aspect_ratio限制在0.5到2.0之间。  

运行现象：  

1. 掩膜图（mask）呈现断裂状：由于光照极暗，橘子左下角的阴影区域明度（V）低于设定的下限100，被判定为背景；
   同时表面树叶遮挡区域也变成了黑色，导致最终提取的白色掩膜像一个月牙，中间有巨大缺口。  

2. 结果图（result）定位精准：尽管掩膜残缺，但最终在原图上画出的绿框框住了橘子，红点中心坐标也落在橘子中部。  

3. 算法正确输出了目标的中心坐标(237,373)，以及对应的轮廓面积21401.0。  

成功原因分析：  

1. 闭运算（MORPH_CLOSE）发挥了作用，用14x14的核将断裂的边缘强行连接，防止了轮廓碎片化。

2. OpenCV 的 cv2.boundingRect 函数计算的是轮廓的最外层极值点（最上、最下、最左、最右）。
   虽然内部有破洞，但外边缘轮廓依然存在，因此算出的外接矩形非常准确。  

3. 形状过滤（宽高比）有效排除了可能因为噪点产生的长条形误检。  

失败案例：暗光阴影环境导致轮廓断裂误检  

输出目录：outputs/task3/  

现象描述：算法未能识别出完整的橘子，而是画出了两个绿色的外接矩形。观察掩膜图发现，受阴影影响，完整的橘子轮廓被切断成了左右两块。  

原因分析：  

1. 当前使用的形态学闭运算核太小，导致橙色区域成碎散的小块。  

2. 面积过滤（min_area）设置偏小，导致左侧较小的碎块未被过滤，被误识别为第二个目标。  

改进思路：
1. 加大闭运算（MORPH_CLOSE）的卷积核（如增大至14x14）

2. 适当提高最小面积（min_area）阈值，直接过滤掉左侧的阴影小碎块  



## 图片三测试记录：（data/images/picture5.jpg）
环境条件：正常强光环境，纯亮黄色背景，目标为橙色橘子，且带有绿色树叶。  

# 参数设置：  

1. HSV范围：lower_color=[6,180,150]，upper_color=[19,255,255]
2. 形态学处理：17x17闭运算（填补高光黑洞），1x1开运算（无需去噪）
3. 过滤条件：面积阈值 \(5000< \text{area}< 300000\) ，宽高比aspect_ratio限制在0.5到2.0之间。  

# 运行现象：  

1. 掩膜图（mask）：纯黄色背景和绿色树叶完全被过滤成黑色，只留下一个非常饱满、纯白色的橘子圆形轮廓。  

2. 结果图（result）：绿色的矩形框非常贴合橘子的边缘，红色的中心点准确落在橘子正中央，没有受到叶子的任何干扰。  

3. 算法正确输出了目标的中心坐标(277，314），以及对应的轮廓面积81489.5。  

# 参数调节与改进方法：  

1. 极限收紧H（色相）范围：将上限死死卡在19（黄色起始于22左右），下限提至6，精准锁定纯正橙色，将黄色背景剔除。  

2. 大幅提高S（饱和度）和V（明度）下限：提高至180和150。由于橘子颜色极其鲜艳且处于强光下，提高下限可以进一步过滤掉偏暗的黄色背景。

3. 调整形态学核大小：由于纯色背景无需去噪，将开运算核设为 1x1（相当于不操作），保护了橘子圆润的边缘不被腐蚀；
   同时橘子表面的高光反光在掩膜中会形成黑洞，将闭运算核加大到 17x17，成功将这些黑洞填补成实心白色。  

# 经验总结：  

在 HSV 颜色提取中，遇到颜色极其相近（如橙与黄）的背景时，单纯依靠调整面积或形状容易误检。核心手段是精确划定 H（色相）的边界。
同时，形态学操作的核大小需根据实际噪点和孔洞大小灵活调整，而不是固定使用某个数值。
