## 问题与解决过程

**问题 1：** Windows 下跑 PyTorch 时报错 `OSError: [WinError 4551] 应用程序控制策略已阻止此文件`。
**解决：** 这是因为 Windows 11 的智能应用控制（SAC）拦截了 PyTorch 的 DLL 文件。通过关闭智能应用控制并重新安装带有 CUDA 的 PyTorch 2.7.0 解决。

**问题 2：** 外接摄像头读取时帧率只有 2 FPS。
**解决：** 发现是 OpenCV 默认使用 YUYV 格式导致 USB 带宽不足，在代码中强制设置 `cv2.CAP_PROP_FOURCC` 为 `MJPG` 格式后，帧率恢复到 30 FPS。

## 当前局限与下一步计划

- **当前局限**：
  1. 由于场地标志有些被严重磨损或反光，模型在极端光照下仍会漏检。
  2. 地图匹配算法使用了暴力两两遍历，当场地特征点极度密集时，计算量较大。
  3. 单目相机高度和俯仰角依赖人工测量，若相机被碰撞位移，需要重新标定外参。
- **下一步计划**：
  1. 增加数据集多样性，训练一个更强鲁棒性的场地标志模型。
  2. 优化地图匹配算法，加入 RANSAC 或卡尔曼滤波进行时间平滑，减少跳变。
  3. 深入学习 ROS2，将视觉节点封装并发布标准的 `Pose2D` 话题给决策模块。
