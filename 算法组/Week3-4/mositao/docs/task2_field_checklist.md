# 任务二 · C0 场地一次进场清单

> 目标：一趟把任务二需要**自己拍**的原始材料拍齐。
> 预计 1 小时。**相机全程同一台、1280×720、不许动对焦环、不许改分辨率。**

## 先说清楚：地图不由我们量

细则把 `field.yaml` / `field_geometry.yaml` 定为**组织方统一发放**，并明确三条分工：

| 细则位置 | 原文要点 |
| --- | --- |
| §1.2 地图坐标约定 | 「统一发放 `config/field.yaml`，记录 L/T/X / 点球点等特征点的已知坐标」 |
| §1.2 坐标系必须统一 | 「学生**不得**自行平移、旋转或缩放官方地图来迎合自己的算法。若实际考核场地与官方 `field.yaml` 的几何布局不一致，**组长必须先测量并发布**与实际场地一致的修订版地图」 |
| §2.11 地图一致性 | 「正式考核前，**组长必须核实**官方坐标与 C0 实际场地的特征位置和尺度一致；如果不同，必须由组长统一测量并发布实际场地版本，所有学生使用同一版本」 |

所以：**自己不量、不改坐标**。发现官方地图和现场对不上，动作是回报组长，不是自己重测。

`config/field.yaml` 目前是本仓库的**占位版**（`_meta.status: placeholder`，坐标是推理值），仅为让代码先跑通；官方文件到手即替换。

## 一、拍标志视频（≥5 段，每段 ≥50 秒）—— 唯一必拍

```powershell
# 在仓库根 cquick-recruitment-main 下执行
cd 算法组\Week3-4\mositao
.\run.bat tools\capture_video.py --index 1 --seconds 50 --name marker_s01
```

| 段 | 命令里的 `--name` | 拍什么（对应细则 §2.4 多样性要求） |
| --- | --- | --- |
| M01 | `marker_s01` | 场地边缓慢平移，一次扫过 3–6 个不同标志（正常场景） |
| M02 | `marker_s02` | 近距离特写 1–2 m，单个标志，绕它转不同角度 |
| M03 | `marker_s03` | 远距离 6–10 m，多个标志同框、画面里很小 |
| M04 | `marker_s04` | 部分遮挡：用脚或纸板遮住标志一角 / 一半 |
| M05 | `marker_s05` | 逆光 / 侧光，或换时段的不同光照 |
| M06（可选） | `marker_s06` | 低机位俯拍、高机位平视，改变视角 |

判据：每段都要能看到**完整的 L/T/X 几何形态**（交点在画面内、不被切边），遮挡段除外。

> 拍摄时只拍**现场真实存在**的标志类别。现场没有的类别不拍、不训、不评分（细则 §2.3）。

## 二、拍外参标定帧（5 分钟，别忘）

相机架在桌沿固定好，拍一张**同时看到 ≥4 个已知标志**的静止画面，标志分布尽量铺开（不要挤在一角）。

```powershell
.\run.bat tools\capture_video.py --index 1 --seconds 3 --name ext_01
```

多拍 3–5 个不同朝向候选（`ext_01..05`），挑标志最多、分布最好的那张解外参。

外参（高度 / 俯角 / 滚转 / 朝向）由 ≥4 个已知地图标志 PnP 一次解出。卷尺量的离地高度只作互校，不写进算法。

## 三、拍 3 个测试点（可选，素材 + 自查）

细则 §2.12：测试点的**参考位置 / 朝向由组长提供，且不得作为算法输入**。所以：

1. 向组长索要 3 个测试点的参考 (x, y, yaw)；
2. 每个点相机对准后录 15–20 秒：

```powershell
.\run.bat tools\capture_video.py --index 1 --seconds 15 --name pose_P1
```

3. 参考值记在 `data/extr/testpoints.txt`，**只用于算误差、不进算法**。
