# 11-19 历史 PnP 三点数据归档与复现说明

## 数据来源与原始文件

本目录保存 2026-11-19 历史 `task2_manual_pnp_v1` 三点静止窗口原始记录及派生计算材料：

- `static.log`：历史运行日志；
- `static_segments.json`：P1/P2/P3 静止窗口逐帧统计与四种半场条件计算；
- `CONSOLIDATED_POSE_RESULT.md`：当日原始综合报告，保留其当时“半场待确认”的历史状态，不覆盖原始记录；
- `C0_history_20261119_recompute.py`：从原始 JSON 重新生成稳定性和条件误差 CSV；
- `C0_history_20261119_stability_summary.csv`：三点固定窗稳定性及全流程记录统计；
- `C0_history_20261119_conditional_errors.csv`：四种半场组合的逐帧条件误差，保留全部组合供审计；
- `P1/P2/P3_half_confirmation_addendum_20261123.md`：用户于 2026-11-23 确认半场符号后的逐点核定；
- `P1/P2/P3_confirmed_plusX_historical_metrics.csv`：逐点确认后的机器可读结果；
- `C0_three_point_confirmed_summary_20261123.md` 和 `C0_three_point_confirmed_metrics_20261123.csv`：统一三点最终汇总。

## 3. 计算复现

在本目录执行：

```bash
python3 C0_history_20261119_recompute.py
```

脚本读取同目录 `static_segments.json`，生成：

- `C0_history_20261119_stability_summary.csv`
- `C0_history_20261119_conditional_errors.csv`

确认半场后，脚本将 +X/+X 行标为 `CONFIRMED_FIELD_CONDITION_HISTORICAL_ONLY`，其他三种组合作为 `ALTERNATIVE_FIELD_CONDITION_NOT_SELECTED` 保留。脚本不会修改原始 JSON、日志或综合报告。

## 4. 指标口径与限制

1. 位置误差是固定窗口逐帧程序位置与现场参考坐标之间的欧氏距离统计。
2. 近似朝向差使用相机垂足指向伞尖 A 的伞杆方向作为参考；伞杆竖直度、主点对齐、相机滚转和卷尺读数引入的不确定度尚未可靠量化，不应称为计量级航向精度。
3. `jitter_xy_m.p95` 是固定静止窗口相对窗口中位数的短时波动，不是绝对定位误差。
4. 全流程有效/有源记录比例的分母包含重复、陈旧的有源记录，不是 YOLO 检测准确率或标准召回率。
5. 本目录数据属于 2026-11-19 历史人工初始化＋光流＋PnP，不是新版 YOLO 自动定位结果，也不证明当前物理安装外参已独立复核。
6. 2026-11-23 新截图属于另一次运行；P1 的 X 输出符号与 11-19 历史结果不同，必须单独核查地图配置、运行版本和实际摆位，不能拼接或混算。
7. 三点位置误差低于此前讨论的 0.5 m 参考值；该参考值是否属于正式考核阈值，以队长发布的评分细则为准。
