# 11-19 历史 PnP 三点数据二次计算包

## 用途
基于同目录原始 `static_segments.json`，重新生成：
- `C0_history_20261119_stability_summary.csv`
- `C0_history_20261119_conditional_errors.csv`

## 运行
把本包中的 `C0_history_20261119_recompute.py` 放到已归档的 `history_20261119` 目录，与原始 `static_segments.json` 放在一起，然后在 WSL 中运行：

```bash
python3 C0_history_20261119_recompute.py
```

## 重要口径
1. 这是 2026-11-19 历史 `task2_manual_pnp_v1` 数据，不是 2026-11-23 新截图/新版 YOLO 自动定位数据。
2. 四种半场组合全部保留，不根据误差大小选择组合。
3. 位置/朝向误差在半场符号确认前标为条件结果，不标成正式验收误差。
4. `jitter_xy_m.p95` 是固定静止窗相对中位数的波动，不是绝对定位误差。
5. 全流程有效/有源记录比例的分母含重复、陈旧有源记录，不能称为 YOLO 检测准确率。
6. 现场报告指出 P1/P2 半场符号待确认，P3 相机与 A 同半场已确认但共同符号待确认；用户此前确认 P1 位于 +X，但仍需确认该确认是否同时覆盖伞尖 A。
