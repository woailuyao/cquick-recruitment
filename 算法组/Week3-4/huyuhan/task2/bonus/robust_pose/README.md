# 稳健位姿优化实验（Robust Pose Estimation）

## 1. 实验目的

针对二维场地定位中错误匹配和异常对应点造成的位姿估计偏差，
研究Huber损失与迭代重加权最小二乘（Huber IRLS）的鲁棒性。

对照方法：
- SVD：普通最小二乘二维刚体变换拟合
- Huber IRLS：基于Huber权重的迭代加权SVD

估计参数为二维旋转矩阵R和二维平移向量t。

## 2. 算法实现

核心代码：scripts/robust_fit_irls.py

算法流程：
1. 使用等权SVD计算初始位姿。
2. 根据对应点残差计算Huber权重。
3. 使用加权SVD更新旋转矩阵和平移向量。
4. 根据相邻迭代的位姿变化量判断收敛。
5. 输出位姿、残差、权重、迭代次数和收敛状态。

实验参数：
- Huber delta = 0.02 m
- 最大迭代次数 = 500
- 收敛阈值 = 1e-9

## 3. 单异常点实验

正常噪声条件下：
- RMS = 3.613 mm
- 所有对应点权重均为1
- 算法正常收敛

加入一个人为构造的异常匹配点：

| 指标 | SVD | Huber IRLS |
|---|---:|---:|
| 航向误差 | 7.8169° | 0.5482° |
| 位置误差 | 17.209 mm | 1.867 mm |

IRLS将异常点权重降低至0.0362，经过11次迭代收敛。

## 6. 收敛性专项诊断

原始50次迭代上限不足以覆盖部分多异常点场景。

针对9个原先未收敛的随机种子进行专项诊断：

| 最大迭代次数 | 收敛案例 |
|---:|---:|
| 50 | 9个案例均未达到原设置的收敛要求 |
| 200 | 8/9 |
| 500 | 9/9 |

最大实际迭代次数为313。

进一步使用500次迭代上限重新运行完整多异常点实验，12组条件均达到30/30收敛。

因此，最终实现将最大迭代次数调整为500。

## 8. 复现方法

运行环境：
- Python 3.10
- NumPy
- Matplotlib（仅绘图需要）

    cd scripts

依次运行：

    python test_robust_fit.py
    python test_robust_sweep.py
    python test_multi_outliers.py
    python diagnose_irls_convergence.py

    MPLBACKEND=Agg python plot_robust_results.py

绘图结果保存在上级目录figures/。

## 9. 实验结论与局限

本次合成数据实验表明：

1. Huber IRLS能够降低异常匹配点对二维位姿估计的影响。
2. 在测试的单异常点和多异常点条件下，IRLS均取得低于SVD的位姿误差。
3. 对应点数量较少、异常点占比较高时，算法收敛所需迭代次数可能显著增加。
4. 将最大迭代次数由50提高到500后，本次360次多异常点实验全部收敛。

实验局限：

- 实验使用人工构造的二维对应点、随机噪声和异常偏移，属于合成数据验证。
- 本实验尚未接入正式实时定位的geometry.match()位姿估计链路。
- 正式定位程序仍使用原有SVD方法，不能声称IRLS已经部署到实时系统。
- 实验误差不能直接等同于真实足球场定位精度。
- 门限通过率为实验脚本定义的指标，不代表独立真实场地精度验收。

后续可在真实场地对应点数据上进行SVD与IRLS对照，并测量实际定位耗时。
