  俯角来源：笔记本合页内角 120° → 屏幕与桌面成 60° → 背板法线（=相机光轴）与水平面成 30°，相机用胶带贴在背板上
- 地面投影方法：
  1. `cv2.undistortPoints(pts, K, dist, P=K)` 得到去畸变像素；
  2. 射线方向 `d_c = K⁻¹·[u, v, 1]ᵀ`；
  3. 用安装角 `R_vc(pitch=30°)` 转到载体坐标系：`d_b = R_vc·d_c`，相机光心 `O_b = [0, 0, 0.98]`；
  4. 与地面 `Z=0` 求交：`λ = −O_b,z / d_b,z`，`P_b = O_b + λ·d_b`；
  5. `d_b,z ≥ 0`（射线朝上/平行地面）或距离越界（0.3–6.0 m）时判该观测无效，不产生 NaN。
- 地图匹配算法与同类标志消歧方法：
  观测端类型写 `L/T/X`、地图端写 `LCross/TCross/XCross`，先统一归一化；
  按类型分组后**枚举所有同类候选组合**（如 1 个 L × 5 个候选、1 个 T × 6 个候选 = 30 组；多标志时组合数相乘），
  每组用 SVD 求 **SE(2) 刚体变换（无缩放）**，取残差 RMS 最小的组合；
  RMS > 0.6 m → `high_residual`；有效标志 < 2 → `insufficient_markers`（单标志只有 2 个约束、未知量 3 个，属欠定，按细则 2.8 必须判无效）。
  **对称歧义处理**：本场地左右近似对称（`L1/T5` 与 `L2/T6` 关于 x≈2.99 镜像，`L3/T1` 与 `L4/T4` 也近似镜像），
  只有 1 个 L + 1 个 T 时，镜像解的残差几乎相同。因此求解时保留**次优解**：
  当 `次优残差 − 最优残差 < max(0.06 m, 0.5 × 最优残差)` 且两者位置相距 > 0.5 m 或朝向差 > 15° 时，判为 `ambiguous`，
  不输出有效位姿（并在结果里给出 `second_residual` / `second_dx` / `second_dyaw` 供排查）。
  实测 12 段视频中，两段只有 L+T 的视频正是这种情况（残差 0.012 与 0.015，相距 1.8 m、朝向差 96°）。
- 输出坐标系（camera_frame / base_link / rig_frame）：`rig_frame`。本次把「相机光心正下方的地面点」定义为载体原点，故 `x_camera_map/y_camera_map/yaw_camera_map` 与 `*_carrier_map` 数值一致
- 3 个以上测试点的参考相机地图坐标 X/Y/Yaw 与估计误差：
- marker_count / residual / valid / status 定义：
  - `marker_count`：本帧参与匹配的有效标志数
  - `residual`：SE(2) 拟合后各标志映射到地图的 **RMS 距离（m）**
  - `second_residual` / `second_dx` / `second_dyaw`：次优解的残差、与最优解的位置差、朝向差（用于判断歧义）
  - `valid`：`marker_count ≥ 2` 且 `residual ≤ 0.6 m` 且不存在对称歧义

## 问题与解决过程

**问题 1：相机内参标定结果异常（k3 = −14.71）**
- 现象：标出来的畸变系数 k3 = −14.71，主点 cx 比画面中心偏左 51 px；用这组参数做反畸变，画面边缘会明显被拉伸。
- 排查：把 24 张 `det_*.png` 里画出的角点区域提取出来量了一下，标定点只覆盖画面宽度的 **27%**、最大半径只到半对角的 **45%**——四角完全没有采样。径向畸变只在画面边缘才有信息，k3 于是被拟合成噪声。
- 佐证：用 4 参数（k3=0）重标，**RMS 从 0.3254 只变到 0.3255**（几乎没差），而反畸变自检显示 5 参数模型会把图像**折叠 7826 px**，物理上不成立。
- 解决：标定脚本改为同时拟合 3/4/5 参数模型，按「精度接近时优先少参数 + 反畸变映射必须单调」自动选型，最终采用 3 参数模型：k1=0.2302、k2=−1.2237，RMS 0.332 px；主点回到 cx=629.8、cy=355.0。

**问题 2：定位结果全部是 `insufficient_markers`**
- 现象：明明有 2–3 个标志的视频也判无效。
- 排查：点选 json 里类型写的是 `L/T/X`，而 `field.yaml` 里是 `LCross/TCross/XCross`，分组时对不上，直接返回“标志不足”。
- 解决：在匹配入口加类型归一化（`LCross→L`、`TCross→T`、`XCross→X`、`PenalityPoint→P`），观测端与地图端任意写法都能匹配。

**问题 3：交点细化把红圈“跳到别处”**
- 现象：手动点在交点上，细化后的点却偏出十几到几十像素。
- 排查：细分三步——① 用 Canny 找的是**胶带边缘**，一条胶带有两条边，拟合出来的是边线不是中心线；② `_angle_between` 公式写错（用了 `acos(1−dot)`），平行线被判成 90°、垂直线被判成 0°，导致“同一条胶带的两条边”被当成两条相交线；③ 剔除第一条线时只去掉 RANSAC 的窄内点，第二条仍然找到同一胶带的另一条边。
- 解决：改为在**白色掩膜像素**上做 RANSAC（掩膜包含两侧，拟合出来即中心线）；修正夹角公式为 `acos(|n₁·n₂|)`；剔除时按 12 px 带宽去掉整条胶带；并加“交点距点击 ≤ 35 px 才采纳”的护栏。

**问题 4：双击 bat 闪退**
- 原因：`cv2.imread` 读不了含中文的路径（返回 None 且不报错）；bat 用 LF 换行 + 中文，cmd 解析失败。
- 解决：图片统一走 `np.fromfile + cv2.imdecode`（`src/imgio.py`）；bat 改为纯 ASCII + CRLF 换行。

**问题 5：场地对称导致"坐标对但位置错"**
- 现象：只有 1 个 L + 1 个 T 时，解出来的位姿残差只有 1.2 cm，看起来非常准；但场地左右近似对称，同一个观测还可能匹配到镜像的那一对标志上，得到的坐标在场地另一半。
- 排查：把匹配过程改成保留**所有候选解并按残差排序**，发现 line6/line10 的次优解残差分别是 0.015 m / 0.037 m，与最优解只差 3 mm、4 mm，而两者位置相距 1.8 m / 2.9 m、朝向差 96°——典型的镜像歧义。
- 解决：加入 `ambiguous` 判定（次优残差差距小于 max(0.06 m, 0.5×最优残差) 且位姿差超阈值即判无效），并在结果里输出 `second_residual / second_dx / second_dyaw`。只有三个标志的 line7（次优 0.336 m vs 最优 0.172 m）才判 `ok`。
- 后续：可用 L/T 的臂朝向（场地线轴向已知）约束 yaw，从而在两点情况下也消歧；或现场尽量选择能看到 3 个标志的位置。并且目前因为并没有要求我们做出对于球门的识别，对于当前在哪一个半场没有办法精准识别，所以放弃对称的区分，只做一个半场的识别与定位。

**问题 6：openCV下标识点的飘移，以及不能连续实时识别定位**
- 现象1：在`openCV`路径中，用第一周和第二周学习的掩膜处理方法并不能很好地去实现交点的提取，总会多出一些点，参数十分地难以调整。
- 现象2：在`openCV`的路径下，必须得每次开始前在当前图片下选出三个L/X/T的点位，并且三个不能完全重复，选完后，算坐标。但是点位经常飘移，并且由于工具不足，没有三脚架，用胶带将摄像头绑在了电脑上，并不十分稳定，当摄像头有任何晃动时，点位就会移动，然后不与画面上`L/X/T`的位置重合。这种路径显得十分笨拙，摄像头并没有能够较为精准地去识别`L/X/T`的能力。每次换点为都要重新选取屏幕上的点，并没有实现出能够自动实时识别点位并标出`x,y`的目的，显得十分的不智能。
- 解决：我从新新录了一段视频，从这段视频里面按照任务一的模式，进行抽帧，使用`MakeSence.ai`进行训练，以此来实现能够较为精准并且实时识别到不同的点位，并能够按照公式算出投影坐标以算出当前的x,y的坐标。

**问题 7：标志物不足**
- 现象：在外参为`H=0.98m`，`pitch=30`时,出现在屏幕画面中的标志点基本只有一个或两个，然而计算时需要三个及以上不完全相同的标志点，不管怎么调位置都不能满足需求
- 排查：原因很简单，就是因为高度不够导致的视野受限。
- 解决：但由于本人没有购置三脚架，只能在实验室就地取材，在询问学长，得到使用允许后，拿实验室的布满了灰尘的放置拖把的支架来作为支撑架，并且用硬纸片用量角器做了一个有一个角为30度的三角形，用胶带黏贴固定，以实现让相机的视野变宽。结果能够成功地识别到三个及以上点位，输出x,y的坐标位置，以及朝向

## 当前局限与下一步计划

- **对称歧义**：场地存在多个同类型 L/T 点且左右近似镜像，仅靠 2 个标志时几何上存在镜像解（实测次优解残差与最优解只差 3–4 mm）。本次用"枚举全部组合 + 次优解残差检查"处理，判为 `ambiguous` 时不出有效位姿；后续应引入"标志臂朝向约束 yaw"或"多帧一致性"来消歧。
- **单标志欠定**：1 个标志无法确定 (x, y, yaw)。若确实只有 1 个标志，可利用 L/T 的臂方向（场地线轴向已知）求 yaw，再反推平移，这是下一步可加的能力。
- **外参依赖胶带**：俯角来自合页几何（120°→30°），胶带粘贴的细微偏差会带来 2–3° 误差，而 1° 俯角误差 ≈ 6.8 cm 地面误差；后续应在现场用“已知距离一点法”反解真实俯角。
- **光照/地面**：草地反光、胶带磨损、地面不平整都会影响白色掩膜与交点细化。
