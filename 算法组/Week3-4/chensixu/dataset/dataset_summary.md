## 2. 标注

- 标注工具：LabelImg（Pascal VOC XML），再用 `src/tools/convert_xml_to_yolo.py` 转成 YOLO txt（`class x_center y_center w h`，归一化）。
- 足球：`class_id 0 = ball`，只框足球可见区域；画面里没有足球的帧保留为负样本（无 txt），用于压制白色机器人、球鞋等误检。
- 场地标志：`0 = LCross`、`1 = TCross`、`2 = XCross`；框内需覆盖 L/T 的线交点或 X 的中心。

## 3. 数据集划分方式

- 足球：`src/tools/split_ball.py`，从 `images/raw` 中**随机**取 80% 进 train、20% 进 val（未固定随机种子）。
- 标志：`src/tools/extract_field.py` 先把全部帧放 train，再用 `src/tools/split_field.py` 随机抽 20% 图片及对应标签移到 val。
- **当前没有独立 test 集。**
- 训练时 `ball_data.yaml` / `marker_data.yaml` 用的是本机**绝对路径**（`path: C:/Users/.../dataset_ball` 等）；本提交目录里的两个 yaml 改成了相对路径，数据集本体不上传仓库，本地按说明放置即可。

### 已知问题（如实记录）

1. **相邻帧泄漏**：随机划分会把同一段视频的相邻帧同时放进 train 和 val，验证指标偏乐观（任务书明确要求按独立视频片段划分，本数据集尚未满足）。
2. **没有 test 集**：README 中的指标均为 val 集结果，不能当作独立测试集指标。
3. 足球负样本（无球帧）与正样本来自同一批视频，同样存在场景重叠。
