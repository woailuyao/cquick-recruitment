## 2. 抽帧与格式

- 抽帧规则：按 `SAMPLE_FPS = 4.0`（约每 7~8 帧取 1 帧）间隔抽取，并对相邻帧做 64×64 灰度缩略图差分，相似度过低的重复帧丢弃，降低连续相似样本占比。
- 图片格式：JPEG，质量 92，保留原始 1280 × 720。
- 标注格式：YOLO 检测格式，每行 `class_id x_center y_center width height`，坐标归一化到 0~1。
- 数据集配置：`ball_data.yaml`（`path` / `train` / `val` / `test`，`nc: 1`，`names: {0: ball}`）。

## 3. 类别分布

| class_id | 类别名 | 标注对象 | 实例数 |
|---:|---|---|---:|
| 0 | `ball` | 足球（蓝白/红白比赛用球） | 259 |

- 本任务只训练 `ball` 一个类别，未添加 `robot`、`goal_frame` 等其他类别。
- 空帧（画面中无可标注足球）保存为空标签文件，共 95 张，用于抑制背景误检。

## 4. 标注口径

- 检测框始终为水平/垂直外接矩形，紧贴足球上、下、左、右四个极点，不为凑正方形放大。
- 被门柱、球网、人腿等实体遮挡时，只框可见部分，不替画面外被遮挡区域补全；画面边缘截断的球贴边标注。
- 远处小球、靠近白线的球照常框选；白线横穿球身不算遮挡。
- 不标注：黄色小球；场地中静止放置的备用蓝白五角星球；阴影、场地白线、鞋、人手等干扰物。
- 认不出或无球的画面保存空标签。

## 5. 场景覆盖

- 足球在画面左 / 中 / 右、近 / 中 / 远等不同位置与尺寸；
- 静止、滚动与走动跟随；
- 被人腿 / 门柱 / 网部分遮挡、贴近画面边缘；
- 不同背景、阴影与实验室正常光照；
- 靠近白色场地线等易混淆困难场景。

## 6. 配对与质量校验

- 图片与标签一一配对：train 240/240、val 45/45、test 69/69，无缺漏、无多余标签。
- 标签坐标越界 / 宽高非正校验：0 处异常。
- 训练前已按 train / val / test 抽查并将标签画回原图复核（见 `tools/verify_labels.py` 输出）。

## 7. 已知局限

- 整体样本量偏小，val（clip_05，门柱后连续遮挡帧）与 test（走动、脚边、远景、白线干扰）场景分布差异较大，存在 domain gap；
- 远景小球、遮挡帧与运动模糊帧覆盖不足，是测试集 Recall 偏低的主要原因。
