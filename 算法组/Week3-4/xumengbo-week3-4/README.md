## 问题与解决过程

1. **GPU 轮子与解释器版本不匹配**
   - 现象：RTX 5060 Laptop（Blackwell 架构）在默认 PyTorch CUDA 12.1/12.4 轮子下无法调用 GPU；系统裸 `python` 指向 3.13，缺少 cv2/numpy 等依赖。
   - 排查：核对显卡架构与 CUDA 版本，确认需 CUDA 12.8（cu128）轮子；区分系统 3.13 与项目 Python 3.10 两套解释器。
   - 解决：安装 `torch 2.11.0+cu128 / torchvision 0.26.0+cu128`，脚本统一用 Python 3.10 全路径运行，`torch.cuda.is_available()=True`，识别到 8123 MiB 显存。

2. **首版内参标定上下覆盖不足**
   - 现象：标定棋盘样本多落在画面中下部，解出的主点 `cy=160.11` 偏离画面中心（360）较多，`k3=-9.02` 偏大。
   - 排查：逐图看重投影误差与棋盘位置，确认画面上部/四角/不同距离样本缺失。
   - 解决：保留当前 15 张有效图的内参结果并记录局限；复标需补拍覆盖画面上部、四角、倾斜与不同距离的标定图，本次挂起（见"当前局限"）。

3. **标志 val 类别口径复核**
   - 现象：门柱根部特写帧初看像把柱身/网绳误标为标志，一度按噪声标签隔离。
   - 排查：回到原图逐帧核对，柱根右侧地面端线与另一条场地线成 T 型交汇，框落在地面白线交汇处、未把柱身/网绳当主体。
   - 解决：现场确认类别为 TCross 后恢复标签；记录共性问题是框偏大、交点偏在框左缘未居中，后续在标注工具内收紧框位。
