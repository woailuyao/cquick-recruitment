## 实际场地测试记录与同类标志消歧分析
在实地测试中：
- **X 型和 T 型**：在光照正常、未严重反光的情况下能稳定识别。
- **L 型标志**：模型成功检测到了画面中的 L 点，但右侧地图上显示的是场地另一个角落的 L 点。
- **原因分析（二义性）**：这是单目视觉中典型的“同类特征匹配二义性”。因为球场对称，且存在多个 L 型角点。在单特征点匹配时，程序取了地图列表中第一个同类型 L 去硬算，导致坐标瞬移。
- **改进思路**：1. 加入物理边界校验（算出的坐标超出场宽高即判定错误）；2. 引入多点联合解算（如同时看到 X 和 L），利用相对距离关系进行组合消歧，通过 SVD 计算唯一位姿。

## 问题与解决过程
- **问题**：现场光线较暗时，模型置信度下降。
- **解决**：代码中引入 `cv2.convertScaleAbs` 进行对比度自适应提升，并将置信度阈值降为 0.15 以保证鲁棒性。
