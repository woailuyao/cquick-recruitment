- **地面投影方法**：基于相机内参矩阵求逆将像素反投影为射线，通过旋转矩阵将射线转换到载体坐标系，与 \(Z=0\) 地面求交，得到相对坐标。
- **地图匹配算法与同类标志消歧方法**：
  - 遍历 0~360 度的 Yaw 角进行旋转搜索（暴力搜索），结合已知的实测地图特征点，计算平移量。寻找总残差最小的平移和旋转组合。多点匹配可消除单目多解性。

- **3 个以上测试点的参考相机地图坐标 X/Y/Yaw 与估计误差**：在双点或多点特征下，坐标收敛极好，误差控制在 0.5m 以内。
- **marker_count / residual / valid / status**：
  - 当观测到 `>=2` 个标志时，输出 `VALID: TRUE (Multi)`，并解算 Yaw；当 `==1` 个时输出 `VALID: TRUE (Single)`；遮挡时输出 `VALID: FALSE`。

## 问题与解决过程
1. **背景差异导致的严重漏检**：最开始做足球推理时，在寝室地砖背景上测试，发现模型完全认不出球。通过询问学长并分析数据集，发现是“训练数据（绿草皮）与推理环境（灰地砖）分布差异过大”导致的。这让我深刻理解了数据增强和背景泛化的重要性。
2. **外参测量的多次迭代**：最初通过几何草图推算相机俯仰角，随后使用手机“水平仪”App实测笔记本屏幕夹角，经过多次推导，最终修正了真实物理俯仰角为 **29.0°**，使地平面投影坐标的误差大幅缩小。
3. **单目多解性消除**：最初在视野中只有 1 个标志时，坐标偏移极大。后在代码中加入逻辑：当有效特征数 `>=2` 时，进行 0~360° 的 Yaw 暴力搜索与几何残差评估，成功锁定绝对坐标。
4. **运行环境抉择**：WSL 下无法直连 USB 摄像头，最终采用 Windows 原生环境调用 UVC 驱动进行实时推理与录屏，保证了 30fps 的视频流稳定性。

## 当前局限与下一步计划
- **局限**：纯单目相机在视野内仅有一个特征点时，存在数学上的多解性。相机边缘的残缺特征会导致目标检测闪烁。由于时间有限，未能加入卡尔曼滤波进行帧间平滑。
- **下一步计划**：在后续真实机器人项目中，可接入轮式里程计（Odometry）和 IMU 数据，通过 EKF 进行多传感器融合。在数据增强方面，加入更多负样本和复杂的场地背景，提升模型的泛化能力。
