# 场地标志手标工具

## 启动

在 `sumaolin` 目录双击：

- `标注_train.bat`：标训练集
- `标注_val.bat`：标验证集
- `标注_test.bat`：标测试集

或命令行：

```powershell
tools\venv\Scripts\python.exe tools\annotate_markers.py --split train
```

## 核心操作

| 操作 | 快捷键 |
|---|---|
| 选 L 类 | `1` 或 `L` |
| 选 T 类 | `2` 或 `T` |
| 选 X 类 | `3` 或 `X` |
| 单击放框 | 左键单击，放置当前默认尺寸的框 |
| 自由画框 | 左键拖拽 |
| 删除框 | 右键点框 |
| 撤销最后一个 | `u` |
| 清空本帧 | `c` |
| 下一帧/保存 | `n` 或 `→` |
| 上一帧/保存 | `p` 或 `←` |
| 丢弃本帧 | `d` |
| 缩放 | 滚轮，以鼠标为中心 |
| 平移 | 中键拖拽，或按住空格 + 左键拖拽 |
| 适配窗口 | `f` |
| 100 px 网格 | `g` |
| 隐藏/显示框 | `h` |
| 调默认框大小 | `[` / `]` |
| 帮助 | `?` |
| 退出 | `Esc` |

## 建议流程

1. 打开后先按 `f` 适配窗口；
2. 滚轮放大到交点附近，`g` 可开网格；
3. 先按 `1`/`2`/`3` 选类别；
4. 鼠标对准交点，左键单击放默认框；大小不合适就拖拽画框；
5. 一帧所有可见 L/T/X 都标完后按 `n`；
6. 拿不准或没有完整交点的帧按 `d`，会移到 `dataset/marker_dataset/discarded/`，不会进入训练。

## 重要说明

- 当前 `dataset/marker_dataset` 里的旧标签是错的，不要直接沿用；
- 每帧打开时如果已有旧框，先按 `c` 清空，再按正确位置重标；
- 保存时旧标签会自动备份到 `dataset/marker_dataset/labels_orig/<split>/`；
- 所有修改自动保存，切帧/退出不会丢；
- 类别必须在画框前选好，框的颜色就是当前类别；
- 默认框 120 px，可用 `[`/`]` 调；透视远处可小一点，近处可大一点；
- 标完通知我，不要一边标一边训练。

## 输出

- 标签：`dataset/marker_dataset/labels/<split>/<stem>.txt`
- 旧标签备份：`dataset/marker_dataset/labels_orig/<split>/`
- 丢弃帧：`dataset/marker_dataset/discarded/<split>/` 和 `discarded.csv`
