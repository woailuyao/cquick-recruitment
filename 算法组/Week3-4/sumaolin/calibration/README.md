# 相机内参标定说明

## 输入

- 视频：`WIN_20261115_16_36_14_Pro.mp4`（1280×720，约 29.7 fps，41.8 s）
- 标定板：棋盘格，外尺寸 24.5 × 18.1 cm，**8×6 个方格，7×5 个内角点**
- 方格边长按 0.0306 m 使用（内参标定对绝对尺度不敏感）

## 方法

1. 每 2 帧抽一帧，用 `cv2.findChessboardCornersSB(..., (7,5), CALIB_CB_ACCURACY)` 检测内角点；
2. 按 Laplacian 方差保留较清晰的 88 个视图，剔除重投影误差 > 1.3 px 的视图，最终 68 个视图；
3. `cv2.calibrateCamera` 标定，**主点固定为图像中心 (640, 360)**。

主点固定原因：自由标定时主点会跑到 (685, 276)，但重投影 RMS 只从 0.854 降到 0.821，说明这批数据对主点约束很弱，固定到中心更稳，也符合普通 USB/板载相机的先验。没有固定主点时，主点会随标定板姿态漂移，下游地面投影会出现系统性偏移。

## 结果

| 参数 | 值 |
| --- | --- |
| fx | 1563.6194 px |
| fy | 1632.7168 px |
| cx | 640.0 px |
| cy | 360.0 px |
| 畸变 `[k1,k2,p1,p2,k3]` | `[0.252780, -1.094336, -0.032371, 0.004958, 0.0]` |
| 重投影 RMS | 0.854 px（68 视图） |

结果文件：`config/camera_intrinsics.yaml`，可直接作为 `task2.py` / `task3.py` 的 `--calib` 参数；两个脚本默认也会自动加载它。

```bash
cd scr
python task2.py --calib ../config/camera_intrinsics.yaml
python task3.py --calib ../config/camera_intrinsics.yaml
```

## 注意

- 标定视频分辨率、推理分辨率必须都是 1280×720；换分辨率要重新标定或按比例缩放内参。
- fx/fy 相差约 4.4%，可能来自标定板不绝对平整、手抖或镜头；如果后续地面投影仍有系统误差，建议用更平整的标定板、更多边缘姿态重标一次。
- **安装外参（光心高度、俯角、横滚、偏航、相对载体偏移）还没有标定**，task2 里仍是占位值 0.60 m / 20°。这部分决定 task2 的地面坐标，必须实测或用地面控制点标定后再做定位验收。
- task3 使用 `--pose-mode pnp` 时不依赖安装外参，只使用内参与畸变；`plane` 模式仍需要外参。
