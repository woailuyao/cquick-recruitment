# 第 3–4 周 · 足球检测 + 单目场地自定位

> **两周合并考核，总分 100 分 + 加分 10 分。两个任务各 50 分，都必须完成实时运行和现场演示。**
> 完整任务要求、坐标系约定、评分标准、FAQ → 见 [`../考核细则_第3-4周.md`](../考核细则_第3-4周.md)

## 只有两个任务

| 任务 | 核心内容 | 分值 |
|---|---|---:|
| **任务 1 · 足球检测** | 实验室实拍 → 抽帧标注 → YOLO 训练 → 实时检测框 + 像素中心 + FPS | 50 |
| **任务 2 · 单目场地自定位** | L/T/X/点球点检测 → 相机内外参 → 地面投影 → `field.yaml` 匹配 → 输出地图 X/Y/Yaw | 50 |

**不检测球门**，不训练 `goal_frame` / `goalpost`，不输出球门方向或距离。任务 2 的最终产物是**载体/相机在场地地图里的二维位姿**。

## 三条容易误读的边界

1. **单目能给米制 X/Y，但不是凭空来的**：必须已知内参、外参，且标志位于已知地面平面（`Z=0`），再和 `field.yaml` 的米制地图匹配；
2. **`field.yaml` 不是一张球场图片**，是特征点坐标文件，也不是 Nav2 的栅格地图；
3. **检测框中心 ≠ 精确几何交点**：L/T/X 要在框内做几何细化（线段拟合 / 交点计算），取点规则要写清楚。

## C0 统一约定

- 相机固定装在机器人或移动测试架上，与载体**刚性连接**，测试期间不许松动；
- 统一分辨率 `1280 × 720`、目标 `30 fps`，不做自动对焦 / 自动变焦；
- 地图统一：`+X` 向右、`+Y` 向上，`Yaw` 从 `+X` 逆时针为正；
- 现场至少 **3 个不同位置 / 朝向** 复测，参考值由组长提供，**不得作为算法输入**；
- 基础验收目标：位置误差 ≤ `0.5 m`、航向误差 ≤ `10°`（组长可统一调整）。

## 什么不能进仓库

| 不进仓库 | 放哪 |
|---|---|
| 原始拍摄视频、屏幕录制文件 | B 站，README 贴可访问链接 |
| 抽帧图片、标注图片整套 | 本地保存，交 `dataset_summary.md` 统计 |
| `best.pt` 等权重 | 实验室共享存储 / 指定网盘，README 写获取方式 + 校验值 |
| `.venv/`、`runs/`、`__pycache__`、缓存 | 一律不交 |

> 组织方公共的 `field.yaml` / `field_geometry.yaml` 会在仓库公共目录发布，个人目录用相对路径引用或写 SHA256 即可，**不用每人复制一份**。

## 录屏（必交）

B 站上传，README 贴链接。录屏必须是**连续实时相机输入**，不接受静态图片、图片轮播或离线渲染结果。开头先执行：

```bash
echo "姓名: <你的姓名拼音>"; date "+%Y-%m-%d %H:%M:%S"
```

程序窗口按**左右分屏**：左边是真实 RGB 视频 + 足球 / L/T/X / 点球点检测与几何特征点；右边是 `field.yaml` 俯视地图 + 相机光心位置图标 + 朝向箭头 + `x_camera_map / y_camera_map / yaw_camera_map`、`marker_count`、`residual`、`valid / status`。
