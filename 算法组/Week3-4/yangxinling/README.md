- 地面投影方法：
  1. 像素去畸变 `cv2.undistortPoints` → 归一化坐标；
  2. 归一化坐标 → 相机系方向 `d_c = K⁻¹[u,v,1]ᵀ`；
  3. 相机系 → 载体系 `d_b = R_bc · d_c`；
  4. 与 `Z=0` 求交：`λ = -O_bz / d_bz`，`P_b = O_b + λ·d_b`（要求 `d_bz < 0`、`λ > 0` 且前向分量 > 0.02 m，否则判为"打不到地面"）；
  5. 位姿解出后 `P_map = R(yaw)·P_b + (x, y)`。
- 地图匹配算法与同类标志消歧方法：
  - 只用"几何一致性"，不用"按类别最近邻"：对每对观测（≥2 个、间距 ≥0.25 m）用 2D Kabsch 求 `SE(2)`，得到候选位姿 `(x,y,yaw)`，再用其它观测做内点投票；
  - 候选生成时**遍历所有同类别与跨类别的点对**（含同类，天然覆盖同类歧义），最多 4000 个假设；
  - 打分：`score = 内点数 - 0.6 × 残差项`；
  - 消歧：若第二优假设内点数与最优相同且位移 > 0.6 m 或航向差 > 10° → `status=ambiguous` 且 `valid=false`（宁可不给，也不给错）；
  - **硬门 1（内点数）**：`solver.min_inliers` 默认 **3**。只有 2 个观测时位姿欠定——任意一组同类配对都能把残差压到很小，
    实测出现过"航向偏 158°、残差仍只有 0.13 m"的假解（现场实测：站在 `(−2, +1)` 朝球门 `yaw=0°`，
    界面却给出 `yaw=158.56°`），所以内点 < 3 一律降级为
    `insufficient_markers`、`valid=false`（本项即细则"valid 仅当 ok 且内点 ≥ 3"的落实）；
  - **硬门 2（与先验自洽）**：给了 `--prior` 时，解与先验的位置/航向偏差超过 `solver.prior_gate_sigma`（默认 3σ）即判
    `high_residual`（界面会显示 `high_residual (prior_gate)`），并且**不触发"去掉先验重搜"**——
    因为重搜出来的往往正是左右镜像的错误分支；
  - 残差 > `max(0.5×tol, 0.12 m)` → `high_residual`；观测不足以形成点对 → `insufficient_markers`；无观测 → `lost`；
  - 自测：300 组随机位姿 → `ok` 165 组全部正确、`ambiguous` 30、观测不足 105、**错误 0**。
  - **本场地是严格镜像对称的**（24 个标志关于中线 `y=0` 一一对应），所以"关于中线反射"是一个
    **数学上等价**的解：不给先验时，首帧必然同时存在 `(x, y, yaw)` 与 `(x, −y, −yaw)` 两个等残差解，
    求解器会如实输出 `ambiguous`（实测 `video/场地新/5.avi` 前 30 帧：30/30 全是 `ambiguous`）；
  - **初始先验**：给一个粗到 1 m / 30° 的初始位姿（现场量一下站哪儿、朝哪儿）即可破除反射歧义，
    之后靠帧间连续性（上一帧位姿作先验）维持。命令行：
    `python -m cquick_field_localizer.localize --prior=1.0,-1.0,180 ...`
    （**坐标带负号时必须用等号写法**，否则 argparse 会把 `-2.0,1.0,0` 当成另一个选项报 `expected one argument`）
    实测同一段 60 帧：`ok` 60/60、valid 100%、残差均值 **0.052 m**（P95 0.073 m）、端到端 **26.1 FPS**
    （该段多数帧只检出 2 个标志；按上面的"硬门 1"，这类帧现在会显示 `insufficient_markers`，
    这也是把现场机位选在"每帧 3~6 个交点"处的原因，见 `docs/拍摄计划表.md`）。
    这不是"作弊"，而是把"操作者知道相机大致摆在哪"这一先验显式化；ROS2 节点里对应
    `set_initial_prior()`，也可由上一帧或里程计给出。
- 输出坐标系（camera_frame / base_link / rig_frame）：
  - `camera_frame`：`x_camera_map / y_camera_map / yaw_camera_map`，含义是**相机光心地面投影点**在地图中的坐标（米、度）；

## 问题与解决过程

1. **标定板不是标准棋盘格，角点排序每帧乱跳，标定 RMS 高达 12~57 px**
   - 现象：`cv2.findChessboardCornersSB` 能检出 9×6 网格，但每帧返回的首行方向在 -93°、91°、178°、3° 之间跳变；直接标定得到 `rms=14.27`，甚至 `fx=413500` 这种荒谬值。
   - 排查：把检测点画回原图，确认点落在黑格之间的白缝上（即黑块中心网格）；进一步发现根因是**镜像**——枚 4 旋转 × 2 镜像再按残差选优时，不同帧被贴上互为镜像的标签，`calibrateCamera` 拿到的是非刚体点对应。
   - 解决：禁止镜像，只枚举 4 个旋转（凸包四角按 `atan2` 排序、以最上角为起点、统一环绕方向），35 帧 → `rms=1.6094 px`。
   - 教训：标定失败时先怀疑"点对应关系"而不是"检测精度"；对称图案一定要固定手性。

2. **实拍画面整体过曝，固定 HSV 阈值把草皮当白线**
   - 现象：`S<60, V>180` 的固定阈值下，一个 180×180 的 ROI 里有 3600+ 像素被判为白色，细化直接退化。
   - 解决：改用**白顶帽**（`morphologyEx(TOPHAT, 15×15 椭圆核)`）取"相对局部背景更亮"的像素，阈值取 `max(18, P92)`，再叠加低饱和/亮度门限；掩膜从"整片草皮"变成"细白线"。
   - 教训：室外/体育馆光照变化大，绝对阈值不可迁移，优先用相对亮度。

3. **HoughLinesP 在低分辨率 ROI 里只检出一个方向**
   - 现象：bbox ROI 只有 50×50 px，白线宽 6~9 px，`HoughLinesP(minLineLength=18)` 只能拿到水平线，配不出交点。
   - 解决：放弃 Hough，改用 **Sobel 梯度方向直方图**找线方向（白线的梯度方向 = 线法向），再在法向上做一维投影定位直线；两条线求交得到亚像素交点（合成图误差 0.17–0.41 px）。
   - 教训：像素级霍夫对短线段不友好，方向统计 + 投影更稳。

4. **同一视频的相邻帧被分散到 train/test，指标虚高**
   - 解决：`tools/split_dataset.py` 以**片段目录名**为单位划分 70/20/10，`tools/make_dataset_summary.py` 再按片段核对是否有跨集合泄漏。
   - 教训：视频数据集必须先按片段切分，再做帧级划分。

## 当前局限与下一步计划

- **每帧可观测标志数**：求解需要一帧内 ≥3 个标志（`min_inliers: 3`，硬门）。只有 2 个时位姿欠定，任意同类配对都能把残差压到 0.1 m 级却给出错误位姿（会表现为方向反了），因此宁可不给也不猜，输出 `insufficient_markers`。现场做法：退半步/转一点，让罚球区或球门区的角同时进画面。
- **外参（现场实测值，2026-11-22 定版）**：高度 `h=0.75 m`（卷尺量到光心）、俯仰 `pitch=18.5°`、滚转 0°。
  最终值由 `tools/fit_pitch.py` 在**实时推流画面上反算**得到：固定 h，把 pitch 从 10° 扫到 30°，
  每个候选值都跑一遍"检测 → 投地面 → 位姿求解"，取有效帧最多/残差最小者
  （实测 `h=0.75` 时 18.5° 残差 0.085 m、`h=0.70` 时 18.0° 残差 0.084 m，两者等价）。
  写入：`python tools/make_extrinsics.py --height 0.75 --pitch 18.5 --roll 0`。
- **同类标志间距过小导致歧义**：重建后 `TCross1↔TCross3` 只隔 0.500 m（球门线上球门区/罚球区两条边线的交点），
  `LCross5↔LCross7` 隔 1.118 m。只靠"最近邻"匹配必然错，必须用本方案的 SE(2) 全组合搜索 + 内点投票 + 歧义判定。
- **标志分布不足 / 视野过窄**：广角不够时画面常只含 1~2 个交点，建议换 100° 以上镜头或把相机俯角增大到 30°。
- **场地镜像歧义是结构性的**：本场地 24 个标志关于中线 `y=0` 完全对称，纯几何下 `(x,y,yaw)` 与 `(x,−y,−yaw)` 等价。
  当前做法是要求一个粗初始先验（1 m / 30° 内即可）来选定分支，之后靠帧间连续性维持；
  更彻底的办法是引入不对称线索（球门网、观众席、场地外轮廓）或多帧累积投票，列为下一步。
- **光照变化**：强逆光/正午过曝会让白线掩膜断裂，细化回退 bbox 中心后精度下降到 ~10 px。可加入自适应 gamma 或 ROI 内局部对比度归一化。
- **地面不平 / 外参变化**：`Z=0` 平面假设在草皮起伏、地毯接缝处有 1~3 cm 误差；相机被碰撞后外参失效，需要重新 `tools/make_extrinsics.py` 标定。
