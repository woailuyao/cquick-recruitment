# 数据集说明（dataset_summary）


## 一、任务 1：足球数据集（`dataset/ball`）

### 2.1 来源视频

| 片段（= 划分单位） | 原始帧数 | 抽帧保留 | 说明 |
| --- | ---: | ---: | --- |
| 近景 | 193 | 60 | 球占画面 1/6 以上，纹理清晰 |
| 中景 | 198 | 50 | 常规比赛距离 |
| 远景 | 187 | 40 | 球 bbox 约 40–60 px（本数据集最小尺度） |
| 滚动 | 239 | 40 | 球在草皮上滚动，有运动模糊 |
| 滚动_远 | 135 | 40 | 远距离 + 运动模糊 |
| 遮挡 | 117 | 40 | 被腿/机器人/门柱部分遮挡 |
| **合计** | **1069** | **270** | 6 段独立视频（要求 ≥5 段） |

### 2.2 标注与统计

| 项目 | 数值 |
| --- | ---: |
| 抽帧图片总数（去重后） | 270 |
| 有效标注图片数（含空标注） | 270（要求 ≥200） |
| `ball` 实例数 | 243 |
| 空标注（无球负样本）图片数 | 27 |
| 极小框（面积 <1e-4）数量 | 0 |
| 图像尺寸 | 全部 1280 × 720 |

标注规范：框住球的完整可见轮廓；被遮挡时框可见部分（不脑补）；球 <8 px 或运动模糊到看不出轮廓不标；画面无球则保存空 txt；不标白色机器人/门柱/椅子。

> 那 27 张空标注全部集中在 `滚动`（13 张）与 `滚动_远`（14 张）——这两段是球滚出画面后的镜头，
> 逐张核对过确实是纯场地/脚/腿，属于**有效负样本**，不是漏标。

### 2.3 划分方式

**按视频片段划分**，同一段视频的所有帧只进入一个集合，比例 70% / 20% / 10%：

| 集合 | 片段 | 图片数 | 占比 |
| --- | --- | ---: | ---: |
| train | 近景、中景、远景、遮挡 | 190 | 70.4% |
| val | 滚动_远 | 40 | 14.8% |
| test | 滚动 | 40 | 14.8% |

为什么这么分：6 段视频无法精确切成 70/20/10 的帧数比例，**优先保证"同一段视频不跨集合"**（细则硬性要求），
帧数比例只做近似。验证集放"远景 + 模糊"，训练集覆盖近/中/远/遮挡，测试集放整段运动模糊的真实滚动画面
（训练集里没有任何模糊样本，是对泛化能力最诚实的检验）。

> **2026-11-22 重拍

### 3.1 来源视频

| 片段     |     原始帧数 |        时长 |              抽帧保留 | 主要可见标志                         |
| ------ | -------: | --------: | ----------------: | ------------------------------ |
| 1.avi  |     1225 |    37.2 s |                83 | 球门区/罚球区角点（L）、丁字口（T）、中圈与中线交会（X） |
| 2.avi  |     1223 |    41.0 s |               100 | 同上，含罚球区一侧完整四角                  |
| 3.avi  |     1567 |    47.6 s |               100 | 球门前方与中圈一带                      |

| 5.avi  |     1456 |    48.8 s |               100 | 球门区密集丁字口（T 最多）                 |
| **合计** | **6618** | **6′34″** | **479 → 清洗后 422** | 5 段独立视频（要求 ≥5 段）               |

### 3.2 标注与统计

| 项目 | 数值 |
| --- | ---: |
| 抽帧图片总数 | 479 |
| 清洗移出的废帧 | 57（6 张空标注 + 51 张手抖模糊/被人腿遮挡 → `out/rejected_marker2/`） |
| **清洗后有效标注图片数** | **422**（要求 ≥300） |
| 标注框总数 | **1301**（平均每帧 3.08 个） |
| `LCross` 实例数 | 628 |
| `TCross` 实例数 | 384 |
| `XCross` 实例数 | **289** |
| `PenaltyPoint` 实例数 | **0**（见下方说明） |
| 图像尺寸 | 全部 1280 × 720 |

**清洗规则（重要）**：这批数据几乎每帧都有场地线，**空 txt 会被 YOLO 当成"这帧没有交点"的负样本**，
所以"标不出来"的帧（人挡、拖影）应当**整帧移出**，而不是留空标注。

**取点规则：**

- `LCross`：两条白线成直角的交会顶点（角点）；
- `TCross`：一条线顶在另一条线中部的丁字交点；
- `XCross`：两条线互相穿过的十字交点。**本场地的 X 观测取"中圈弧线与中线交会中心"**，
  按实测中圈半径 0.75 m 重建地图后落位为 `XCross1 = (0.000, +0.750)`、`XCross2 = (0.000, −0.750)`；
- `PenaltyPoint`：规定为场地中心，但实际场地中心并无标志点
  该类**没有训练样本**，不伪造标注；地图里也不含该类条目。

### 3.3 划分方式

按视频片段划分（`tools/split_dataset.py --assign`，并加 `--clean` 清掉上次残留），
保证同一段视频不跨集合：

| 集合 | 片段 | 图片数 | 占比 |
| --- | --- | ---: | ---: |
| train | 1、2、3 | 241 | 57.1% |
| val | 4 | 90 | 21.3% |
| test | 5 | 91 | 21.6% |

> 划分理由：5 段按 3:1:1 切，`test=5` 的 T 类实例最多（33 个），能真实暴露 T 的弱点；
> 不按 70/20/10 是因为只有 5 段，强行切会让 val 只剩半段、指标抖动极大。

## 五、已知不足

- 足球数据集里**没有 <32 px 的极小目标**（远景最近处球直径也有 ~40 px），因此"小目标表现"无法用本数据集证明，
  已在 README 的局限一节写明；
- 运动模糊样本只在 val/test（滚动、滚动_远），训练集没有同类样本，导致 test 指标（mAP50 0.867）明显低于 val（0.982）——
  这是按"整段划分"的必然结果，也如实反映了跨域泛化差距；
- 空标注 27 张全部来自"球已滚出画面"的镜头，缺少"球在画面里但被完全遮挡"的负样本；
- 场地标志数据集：
  ① **`PenaltyPoint` 零样本**——规定为场地中心，但实际场地中心并无标志点
  该类无法训练，运行时输出为空
  ② **标注框固定 40 px**，把"线是否继续延伸"的信息切掉大半，导致 `TCross` 与 `LCross` 难区分
  （v5 的 `TCross` mAP50 0.498、召回仅 0.115）；同一权重换 `imgsz=960` 可把 T 的 mAP50 提到 0.571，
  但端到端只有 12.3 FPS，因此交付默认 640；
