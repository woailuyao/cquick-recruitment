## 问题与解决过程

**标志检测模型完全不收敛（mAP50 = 0.017）**：训练集 mAP50 0.989、验证集 0.017，验证损失持续上升。先校验标签（类别、归一化、框面积）无异常，再在训练集上评估确认能拟合，判断为过拟合；查日志发现仅 108 张图、700 次迭代且 `lr0=0.01`。改为 182 张训练图、`lr0=0.002`、`cos_lr`、`freeze=8`、加强尺度增强后，验证集 mAP50 依次提升到 0.433、0.545。

**定位结果跑到原点后方 3.3 m**：某帧 4 个标志均识别正确、残差 0.07 m，但解出的位置为 (−3.34, −1.70)。用合成数据复现后确认：场地左右镜像对称会产生两个同残差、位置相反的位姿。加入 `side_hint` 与 `near_pose` 先验，无先验时输出 `ambiguous`，合成测试错误解降为 0。

## 当前局限与下一步计划

| 场景 | 当前表现 | 下一步 |
| --- | --- | --- |
| 标志遮挡 | 置信度下降可能漏检，仅剩 1 个标志时报 `insufficient_markers` | 增加遮挡样本，用直线拟合补全交点 |
| 标志分布不足 | 可见标志 <2 个无法定位 | 调整相机位姿保证 ≥3 个标志可见 |
| 场地对称歧义 | 依赖 `side_hint` / `near_pose`，无先验时报无效 | 引入连续跟踪或不对称标志 |
| 光照变化 | 强光下白线过曝，检测下降 | 训练加入亮度增强 |
| 地面不平 | 假设地面严格 Z=0 | 拟合地面平面或分区域补偿 |
| 相机外参变化 | 外参一变米制坐标失效 | 固定支架并每次测试前复核高度与俯仰 |

## 两条处理链路

- 足球检测：相机帧 → YOLOv8n 推理 → 检测框 `(x1,y1,x2,y2,conf,class)` → 中心像素 `u=(x1+x2)/2, v=(y1+y2)/2` → 画面叠加框、类别、置信度、像素中心、帧号与 FPS
- 场地定位：相机帧 → YOLOv8n 检测 L/T/X → 框中心像素 → 去畸变 + 内参得射线 → 按外参转到载体系 → 与地面 Z=0 求交得地面坐标 → 与 `config/field.yaml` 匹配 → 输出地图位姿 (x, y, yaw) 与 `marker_count / residual / valid / status` → 左屏 RGB、右屏俯视图与朝向箭头
