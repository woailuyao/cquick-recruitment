## 两条处理链路

**足球检测：**相机帧 → YOLOv8n（单类 ball）→ 框 → 中心像素 → 左栏红框 + ball 置信度；每 2 帧推理一次省 CPU。

**场地定位：**相机帧 → YOLOv8n（L/T/X）→ 框 + 交点 → 初始化（枚举 4 点）→ PnP 位姿 → 逐帧增量跟踪（帧间同名配对 → 上一帧像素投到地面 → 只解旋转）→ 输出 x/y/yaw + marker_count + residual + status。
