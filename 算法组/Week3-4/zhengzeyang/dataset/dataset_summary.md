## 一、任务 1：足球检测数据集（ball）

| 项目     | 数值                           |
| ------ | ---------------------------- |
| 采集日期   | 2026-11-08                   |
| 原始视频数量 | **6 段**（合计 211.4 s / 6344 帧） |
| 抽帧数量   | **307 张**                    |
| 标注实例数量 | **304 个**（其中 3 张为无足球负样本）     |
| 类别数    | 1 类：`ball`（class_id = 0）     |

**类别分布**：仅 `ball` 一个类别，单框单类；304 个标注实例全部为足球，按可见区域标注（部分遮挡按可见部分框选）。

**数据集划分方式**：按**独立视频片段整体划分**，同一段视频的相邻帧不跨集合打散，避免相邻帧泄漏导致指标虚高。

| 集合    | 视频来源         | 图片数 |
| ----- | ------------ | --: |
| train | 实拍视频 1、2、4、6 | 204 |
| val   | 实拍视频 3       |  41 |
| test  | 实拍视频 5       |  62 |
| 合计    | 6 段视频        | 307 |

**场景覆盖**：足球位于画面左/中/右、近/中/远不同位置；静止、滚动与运动模糊；被机器人等物体部分遮挡；不同背景、阴影与实验室正常光照变化。

## 二、任务 2：场地标志检测数据集（marker）

| 项目     | 数值                                         |
| ------ | ------------------------------------------ |
| 原始视频数量 | **5 段独立视频**（不同距离、方向、尺度、光照与部分遮挡）            |
| 抽帧数量   | **374 张**                                  |
| 标注框总数  | **1341 个**（train 877 / val 195 / test 269） |
| 类别数    | 3 类：`LCross`（0）/ `TCross`（1）/ `XCross`（2）  |

**类别分布说明**：

- 三个类别对应场地实际存在的 L/T/X 型标志（地图共 L×8 / T×10 / X×2 / P×1，中圈半径 0.75 m）；
- `PenaltyPoint`（点球点）**未训练**：点球点为场地中心白线上的一点，无明显特征标志，YOLO 训练效果差。实际定位中采用 OpenCV 中圈圆弧拟合求圆心 + 两个 X 交点地面中点兜底的几何方法替代，不依赖该类别的检测框；
- 分类别标注框数量以标注导出统计为准；模型分类别 mAP50：L 0.969 / T 0.939 / X 0.946（test）。

**数据集划分方式**：同样按**独立视频片段整体划分**，5 段视频对应 3 个集合，相邻帧不跨集合。

| 集合    | 图片数 | 标注框数 |
| ----- | --: | ---: |
| train | 235 |  877 |
| val   |  59 |  195 |
| test  |  80 |  269 |
| 合计    | 374 | 1341 |
