### 1.6误检与漏检案例分析

a.当足球占画面比例较大（百分之六十以上）时出现漏检。训练使用的测试集缺少足球占画面比例大的场景，当足球占画面比例大绿色地面少时会出现漏检

## 任务 2：K1 风格单目场地自定位

- 代码位置与运行方式：`week3-4/task2/`，检测层为 YOLO（`src/yolo_marker.py`），框内白线与线段工具在 `src/line_utils.py`
  - 实时：`python src/ocv_live.py --cam 0`
- field.yaml 文件版本：结合官方文件定义方式的自建实测版，21 个标志点（L×8 / T×10/ X×2 / P×1），中圈半径 0.75 m
- 地图原点、X/Y 轴方向、单位：场地中心，x轴正方向指向球门，y轴正方向指向面向x轴正方向的左侧，长度单位为m（米）
- 场地实际尺寸是否与地图一致：点位为卷尺实测，由点位反推 7.92 m × 6.00 m（端线 x=±3.96、边线 y=±3.00），禁区深 0.96 m、宽 2.98 m；外参与实拍尚不一致，一致性待相机固定后复核
- 使用的场地标志类别：L、T、X、点球点（场地中心即为原点）
- 场地标志检测模型与训练参数：YOLOv8n → `best2.pt`，3 类（LCross / TCross / XCross），`epochs=60`、`imgsz=640`、`batch=16`、`optimizer=SGD`、`lr0=0.001`
  - 数据集：374 张，按 5 段独立视频整体划分，train 235 / val 59 / test 80，标注框 877 / 195 / 269
  - 未训练点球点，点球点为场地中心白线上一点，没有明显的特征标志，训练yolo效果差，故采取opencv提取场地中心大圆拟合求中心＋双X点求连线中点实现定位
- 场地标志检测指标：val mAP50 **0.909**；test Precision **0.924** / Recall **0.967** / mAP50 **0.951** / mAP50-95 **0.382**，分类别 mAP50 为 L 0.969 / T 0.939 / X 0.946
- best2.pt 保存位置：<span style="color:rgb(133, 133, 133)">通过百度网盘分享的文件：best2.pt 链接: <https://pan.baidu.com/s/1ToIGIp5DHcBQWJ6NLbYSBA?pwd=27vp> 提取码: 27vp</span>
- 几何特征点提取方法：YOLO 出框 → 框内白线距离变换脊线 → `HoughLinesP` 取线段 → 两线求交（夹角 ≥20°、交点须落在框内）→ 交点作为 `(u,v)`
  - 退化策略：细化失败退回框中心，界面标注 `ctr`
  - 点球点：取两个 X 交点的地面中点，两点关于圆心对称、误差抵消
- 相机内参 fx / fy / cx / cy：1880.004 / 1921.913 / 624.636 / 437.291，分辨率 1280×720
- 畸变系数 k1 / k2 / p1 / p2 / k3：0.332096 / -1.843936 / 0.012842 / -0.003313 / 0.0
- 相机外参 / 高度 / 俯仰 / 滚转：单轴俯仰模型，光心高度 1.02 m、俯仰 20°、滚转 0
- 地面投影方法：相机画面使用内参去畸变 → 相机系归一化射线 → 按俯仰角旋到水平系 → 与 `Z=0` 求交，`λ = -h / d_z`，输出 `(a 前向, b 左向)`；拒绝 `d_z ≥ 0`、`λ ≤ 0`、距离 >12 m
- 地图匹配算法与消歧方法：两点假设（观测对 ↔ 地图同类对）解 SE(2) 候选 → 边长一致性剪枝 → 内点阈值 0.30 m、最少 3 内点、残差上限 0.25 m → 前 8 个候选用最小二乘刚体拟合精化
  - 消歧：位姿差 >0.60 m 或 yaw 差 >20° 视为不同解；场地中心对称、镜像解同分，用上一帧位姿消歧，无先验时输出 `ambiguous`
- 输出坐标系：camera_frame（相机光心为参考原点），`yaw_camera_map` 为相机朝向相对地图 +X 逆时针，单位度
- 3 个以上测试点的参考坐标与估计误差：见c0现场测试部分
- marker_count / residual / valid / status：匹配到的标志点数/残差：图案坐标相较于地图的误差/布尔值01，本帧是否产出可信坐标/字符串ok=定位成功 insufficient_markers=观测到的标志点不足 no_match=无匹配坐标
