# 数据集统计说明

数据全部为本人于 C0 场地用实验室统一发放的单目相机实拍，未使用任何网络素材。

## 一、原始采集

| 项 | 数值 |
|---|---|
| 采集起始日期 | 2026-11-08 |
| 采集批次 | 4 批 |
| 留存录制 | 66 段（角点/场地 63 段，足球 3 段） |
| 采集设备 | 实验室统一单目 RGB 相机，1280×720 @30 fps |
| 原始视频是否入库 | 否（体积原因，按细则要求仅在此记录数量） |

## 二、足球检测数据集

| 项 | 数值 |
|---|---|
| 抽帧总数 | 404 张 |
| 标注实例 | 370 个（全部为 `ball` 类） |
| 负样本（无标注空场/空镜） | 34 张 |
| 类别分布 | `ball` 370，其余 0 |
| 划分方式 | **按视频片段划分**：同一段视频的帧只进一个集合，不跨集合 |
| train / val / test | 328 / 40 / 36 张 |
| 划分依据 | `train` 5 个视频前缀组、`val` 2 个、`test` 2 个，按组整组分配 |

## 三、场地标志数据集

| 项 | 数值 |
|---|---|
| 图片总数 | 291 张（277 张有标注 + 14 张纯背景负样本） |
| 标注框总数 | 454 个（train 382 + val 72） |
| train / val | 247 张（233 有标注 + 14 负样本）/ 44 张 |
| 划分方式 | 组内**每 5 张取 1 张**进 val；R 组（18 段横向偏移站位视频各抽 2 帧，共 36 帧）**整组进训练集**，避免同段视频的帧被拆到两侧造成泄漏 |

各类别标注框数量：

| 类别 | train | val |
|---|---|---|
| `corner_front_left` | 14 | 3 |
| `corner_front_right` | 12 | 3 |
| `corner_back_left` | 22 | 5 |
| `corner_back_right` | 15 | 3 |
| `goalarea_far_left` | 139 | 24 |
| `goalarea_far_right` | 124 | 21 |
| `goal` | 56 | 13 |
| **合计** | **382** | **72** |

> 任务 2 实际只用 `goalarea_far_left/right` 两个小禁区远边角点参与解算；
> 场地四角用于在更靠后的站位下提供额外标志；`goal` 仅用于冷启动判断前后场，
> 不参与位姿解算、也不在界面绘制。
>
> 本场地没有 K1 标准场地上的 LCross / TCross / XCross 与点球点，
> 依据细则 2.3「现场没有的类别不得强行要求训练或评分」，改用白线角点作为标志。
