# 数据集说明（dataset_summary）

> 按细则要求：不提交图片与视频，只用本文件记录视频数量、抽帧数量、类别分布、数据来源与划分方式。

## 1. 数据来源

全部数据由本人在实验室 C0 场地使用本次考核的同一台单目 RGB USB 摄像头（1280×720@30fps）实拍：

| 编号 | 文件 | 采集日期 | 原始帧数 | 时长 | 拍摄内容 |
| --- | --- | --- | ---: | ---: | --- |
| v00 | `ball.avi` | 2026-11-18 | 619 | 20.6 s | 早期采集，球在近处 |
| v01 | `ball_v01.avi` | 2026-11-22 | 1548 | 51.6 s | 近距大球（框宽中位 648 px） |
| v02 | `ball_v02.avi` | 2026-11-22 | 558 | 18.6 s | 球快速滚过画面（运动模糊） |
| v03 | `ball_v03.avi` | 2026-11-22 | 1143 | 38.1 s | 球贴近白色场地线 |
| v04 | `ball_v04.avi` | 2026-11-22 | 766 | 25.5 s | 球被纸板部分遮挡 |
| v05 | `ball_v05.avi` | 2026-11-22 | 1070 | 35.7 s | **远处小球（框宽 107~163 px）、贴近画面边缘** |
| v06 | `ball_v06.avi` | 2026-11-22 | 604 | 20.1 s | 相对较暗、球在画面角落 |
| — | `marker.avi` | 2026-11-18 | 785 | 26.2 s | 场地 L/T 标志 |

合计 **7 段足球视频 + 1 段标志视频**。

> 未使用任何网络图片、他人拍摄数据、手机视频或其他相机素材。
> 原始视频与录屏均不上传 GitHub，保存在本地供抽查。

## 2. 抽帧、去重与标注

| 项目 | 数量 | 说明 |
| --- | ---: | --- |
| 足球抽帧 | 668 张 | 每 15 帧抽 1 张 |
| 去重后 | 545 张 | 按图像相似度剔除近重复帧（阈值 0.03，剔除 18%） |
| 足球标注 | **323 张 / 323 个实例** | 单类别 `ball`（class_id=0），每张 1 个框，全部手工标注 |
| 标志抽帧 | 99 张 | `marker.avi` 每 8 帧 1 张 |
| 标志标注 | **67 张 / 91 个实例** | LCross 55 个、TCross 36 个 |

去重原因：细则要求"同一段视频连续抽取的高度相似帧不能被当作大量独立样本"，
因此先密抽、再按 32×18 灰度图 + HSV 直方图的相似度剔除近重复帧。

## 3. 类别分布

| 数据集 | class_id | 类名 | 实例数 |
| --- | ---: | --- | ---: |
| 足球 | 0 | `ball` | 323 |
| 标志 | 0 | `LCross` | 55 |
| 标志 | 1 | `TCross` | 36 |

> 经现场查看，C0 场地只绘制了 L 型与 T 型交叉标志，未绘制 X 型交叉与点球点。
> 按细则"现场没有的类别不得强行要求训练或评分"，标志模型只训练这 2 类（nc=2）。
> `field.yaml` 中的 `XCross1/2` 与 `PenalityPoint` 保留在文件中，但本次不可观测、不参与匹配。

## 4. 数据集划分

**足球（按独立视频片段划分，不按帧打散）**

| 划分 | 来源片段 | 张数 |
| --- | --- | ---: |
| train | ball.avi + v01 + v02 + v03 + v06 | 233 |
| val | **v04**（遮挡场景） | 48 |
| test | **v05**（远处小球场景） | 42 |
| 合计 | | 323 |

**标志（单段视频，无法按片段划分）**

| 划分 | 张数 | 说明 |
| --- | ---: | --- |
| train | 54 | 随机划分 80/10/10，seed=0 |
| val | 7 | 同上 |
| test | 6 | 同上 |

> 标志数据的局限：只有一段 26 秒视频，无法满足"按独立视频片段划分"。
> 采用随机划分会使指标偏乐观（相邻帧可能跨集合），这一点已如实记录，真实性能以现场复测为准。

## 5. 复现命令

```bash
# 足球数据集（按视频片段划分）
python tools/split_dataset.py --src raw/frames --out soccer_dataset \
    --val ball_v04 --test ball_v05

# 标志数据集（单段视频，随机划分）
python tools/split_dataset.py --src raw/frames_marker/marker --out marker_dataset \
    --random-split 0.80,0.10,0.10 --names "LCross,TCross"
```

两个命令都会自动生成对应的 `data.yaml`。
