### 1.2 零安装方案（推荐，完全不用下载任何 exe）

如果不想装第三方软件，用项目自带的 `tools/annotate_cv2.py` 即可。它只调用环境里
**已有的 OpenCV**，不联网、不装包、不写注册表、不改系统设置，只在 `week3` 内读写 `.txt`。

```powershell
# 任务一：标球（单类 ball）
python tools/annotate_cv2.py --dir frames_pool

# 任务二：标标志（四类，顺序必须与 config/marker.yaml 一致）
python tools/annotate_cv2.py --dir frames_pool_markers --classes L_cross,T_cross,X_cross,penalty_point
```

| 快捷键 | 作用 |
|---|---|
| 左键拖拽 / 右键点框内 | 画框 / 删除该框 |
| `n` `d` 空格 / `p` `a` | 保存并下一张 / 上一张 |
| `u` `z` / `c` | 撤销最后一个框 / 清空当前图 |
| `0` | 确认「此图无目标」→ 写空 txt 并自动下一张 |
| `1`~`9` | 切换类别；**若有选中框，则把该框改成这个类**（复核改错类别用） |
| `Tab` / `v` / `x` | 循环选中已有框（白色高亮）/ 取消选中 |
| `f` | 开关放大镜（**找远处小球必开**，鼠标周围放大 3 倍） |
| `s` / `q` | 立即保存 / 保存退出 |

界面是英文（OpenCV 自带字体不支持中文，仅此而已）。其他特性：

- **直接产出 YOLO txt**（同名、同目录），完全跳过第 3 节的 X-AnyLabeling 导出步骤
- `empty_field_*` 29 张负样本自动生成空 txt，等价于 `make_empty_labels.py`
- **只有画了框或按过 `0` 的图才写 txt**，漏标的图会被 `check_labels.py` 报「缺标签」，安全阀还在
- 断点续标：启动自动跳到第一张还没有 txt 的图；`--start N` 可强制起点
- **`--only-labeled` 复核模式**：只过「有框的图」+「还没标 txt 的图」，跳过已确认的空负样本；配合 `Tab` 选中 + 数字键改类，用来补标漏掉的三类 / 修正类别，不用重画已有框
- 退出时自动打印**全目录四类框数统计**，随时确认三类是否补齐
- 逻辑自检（不弹窗）：`python tools/annotate_cv2.py --selftest`

> 用这个工具时：**第 1、3 节整节跳过**，第 2 节（球画框规则）和第 4 节（标志画框规则）照常适用。
> 后面的划分 / 训练命令一条都不用改。

## 2. 标球（frames_pool，282 张）

### 2.1 初始化（只做一次）

1. 打开 X-AnyLabeling → **Open Dir** → 选 `frames_pool`
2. 打开标签编辑器（工具栏 **Edit Labels / Change Labels**）→ **只添加一个标签：`ball`**，拼写全小写
3. ⚠️ **类别顺序决定 YOLO 编号**。我们的 `config/data.yaml` 规定 `0: ball`，所以 `ball` 必须是列表第一个（也是唯一一个）。**标到一半千万别往列表里插新类**，否则所有已标文件的编号全部错位。

### 2.2 画框规则（重要程度 ★★★）

| 情况 | 怎么标 |
|---|---|
| 清晰的球 | 紧贴球外沿的矩形，四边离球边缘 **≤ 2px** |
| 模糊/运动拖影的球 | **照样标**，框住整个拖影区域 |
| 半遮挡（露出一半） | 只框**可见部分** |
| 完全看不见（被挡死/出画） | **不标**，这不是漏标 |
| 远处的小球（几个像素大） | **必须标！** 这是评委盯漏检率的地方，漏一张小目标 = 白丢指标 |
| 空场/画面里根本没球 | **不画任何框**（负样本，见 2.4） |
| 水瓶、机器人、人脚、椅子 | **绝对不标**，ball 类里混入一个异物 = 训练直接被污染 |

### 2.3 操作节奏

- `D` / `A`：下一张 / 上一张；`Ctrl+Z` 撤销；`Del` 删除选中的框（具体快捷键以软件内 Help → Shortcut 为准，不同小版本略有出入）
- 画框：点工具栏矩形（Rectangle）按钮 → 拖拽 → 选标签 `ball` → 确认
- **每标 10 张左右按一次保存**（File → Save All，或开 Auto Save 选项），别一口气标 100 张再存——软件崩一次你就懂了

### 2.4 负样本处理（必做，29 张）

`empty_field_*.jpg` 不画框，但 YOLO 需要每张图都有同名 `.txt` 才会被收进数据集（空 txt = "这张图里什么都没有"，是宝贵的负样本，能压误检率）。标完全部球图后跑一次：

```powershell
python tools/make_empty_labels.py --prefix empty_field
```

它会只给 `empty_field_*` 开头且还没有标签的图生成空 `.txt`（用前缀过滤，避免把你漏标的球图误当负样本）。

### 2.5 自检（标完必跑）

```powershell
# 抽 30 张把框画回原图，逐张人工看
python tools/check_labels.py --sample 30
```

看输出的 `check_out/` 抽查图：有没有漏标的小球？有没有框太大框进背景？确认无误再进下一节。

## 4. 标标志（frames_pool_markers，210 张，四类；含 11-20 现场补录 35 张）

任务二的检测模型，类别对应 `config/field.yaml` 的三类交点 + 点球点：

| 类别 | 长什么样 | 对应 field.yaml |
|---|---|---|
| `L_cross` | 直角拐角（禁区框的角、场地四角） | LCross1~8 |
| `T_cross` | 丁字交点（中线压边线、球门线压禁区侧线） | TCross1~4 |
| `X_cross` | 十字交点（中圈 ∩ 中线） | XCross1~2 |
| `penalty_point` | 点球点（场地中心那个圆点） | PenalityPoint |

### 4.1 画框规则（与球不同！）

- **框是"以交点为中心的小正方形"**，边长取白线宽度的 4~6 倍，一般 **15~25px**（远处交点按比例缩小到 8~12px）
- **居中是生命线**：任务二代码会在这个小框内做亚像素细化找精确交点，框歪了中心就歪。宁可框小一点，也要让交点落在框的正中心
- 每张图里能看到几个就标几个，**同一帧通常只有 1~3 个可见，正常**
- 交点类型分辨不清（比如 L 还是 T 看不出来）就跳过这张的这个点，**宁可少标不能错标**——错类别会让位姿匹配直接选错点
- 空场/无人图里看不清的交点不标
- 标签列表顺序固定为：`L_cross, T_cross, X_cross, penalty_point`（对应编号 0/1/2/3，与后续 `config/marker.yaml` 一致，先建好四个类再开标）

### 4.2 导出与自检

导出 YOLO 后：

```powershell
python tools/check_labels.py --images frames_pool_markers --labels frames_pool_markers --sample 30 --class-id 0 1 2 3 --names L_cross,T_cross,X_cross,penalty_point
```

训练时另建配置文件（我来做），训练命令换成：

```powershell
python tools/train_yolo.py --data config/marker.yaml --name markers
```

### 4.3 复核 / 补标流程（2026-11-21 首轮标注后必做）

首轮 210 张标完后的自检结果：**156 个框全部是 `L_cross`（类别 0）**，
`T_cross` / `X_cross` / `penalty_point` 三类零样本。原因是画框前没按 `1`~`4`
切类别，工具默认一直是 0。素材本身不缺三类（中圈∩中线的十字、中线压边线的 T、
白色圆点点球点在 `markers_sweep_*` 多帧里都清晰可见），**不需要重拍**，只需复核补标。

一步启动「复核模式」（只过 121 张：120 张有框 + 1 张漏标，自动跳到漏标那张）：

```powershell
python tools/annotate_cv2.py --dir frames_pool_markers --classes L_cross,T_cross,X_cross,penalty_point --only-labeled
```

逐张操作节奏：

1. **先补那张漏标的**：启动后自动停在 `markers_sweep_20261120_175438_f000780.jpg`，
   看清交点 → 按对应数字 → 拖小正方形框 → `n`。
2. **改已有框的类别**：按 `Tab`（或 `v`）循环选中框（白色高亮 + `SEL#`），
   确认它是 L / T / X / 点球点后，**直接按 `1` / `2` / `3` / `4`** 改类，
   框的位置和大小都不动，不用删了重画。
3. **补标漏掉的交点**：把当前类别切到目标类（先按数字，看状态栏 `cls=` 变了），
   再拖框。原则仍是「以交点为中心的小正方形、宁可少标不能错标」。
4. 一帧里几个交点就标几个，分不清类型的跳过；确实一个都看不清才按 `0`。
5. `q` 退出，终端会打印**全目录四类框数**，确认三类都 > 0 再往下走。

复核完重新自检、再划分训练：

```powershell
python tools/check_labels.py --images frames_pool_markers --labels frames_pool_markers --sample 30 --class-id 0 1 2 3 --names L_cross,T_cross,X_cross,penalty_point
python tools/split_markers.py --dry-run
python tools/split_markers.py
python tools/train_yolo.py --data config/marker.yaml --name markers
```

> 加速：先看 `check_out/markers_review_p1.jpg`、`p2.jpg` 两张拼图（35 张 sweep 帧 +
> 5 张旧段空图），按帧号直接定位有 T / X / 点球点的画面，再回标注器里精修。
> 拼图只用来找帧，**点选仍须本人目视**，AI 不代点。

## 5. 常见坑（血泪预防针）

1. **半途加类** → 全部编号错位。开标前把类建齐。
2. **漏标远处小球** → 漏检率暴涨，这是考核指标里最容易被刷下来的一项。
3. **把拖影球跳过** → 滚动视频全部作废，这些帧就是专门为困难样本抽的。
4. **负样本忘生成空 txt** → 29 张负样本全部被 split 脚本丢弃，误检率没人压。
5. **导出后不核对类别号** → 训练时报错或指标诡异。
6. **相邻帧长得几乎一样** → 正常，都标，防泄漏划分由 `split_dataset.py` 按视频前缀处理，你只管标。
