# 数据集统计说明

> 原始拍摄视频、抽帧图片、标注图片整套均**本地保存，不提交 GitHub**；本文件只记录统计口径与划分方式。

## 任务 1 · 足球检测（ball）

| 项目 | 内容 |
| --- | --- |
| 采集摄像头 | 同一台单目 RGB 摄像头（设备节点 `/dev/video0`，待现场确认） |
| 采集日期 | 2026-11（实验室实拍） |
| 原始视频段数 | 5 段（`football_1.avi` ~ `football_5.avi`，本地留存） |
| 抽帧间隔 | 每 15 帧抽 1 张（见 `src/extract_sep.py`） |
| 有效标注图片数 | 待补充（要求 ≥ 200 张） |
| 足球标注实例数 | 待补充（要求 ≥ 200 个） |
| 类别 | 仅 `ball`（class_id=0） |
| 划分方式 | 按**独立视频片段**划分 train / val / test（约 70% / 20% / 10%），不把同一段视频相邻帧打散到三个集合，避免帧泄漏 |
| 场景覆盖 | 左/中/右、近/中/远；静止、滚动、运动模糊；部分遮挡；不同背景与光照；靠近白色场地线等困难情况 |

## 任务 2 · 场地标志检测（LCross / TCross / XCross / PenaltyPoint）

| 项目 | 内容 |
| --- | --- |
| 采集摄像头 | 与任务 1 同一台单目 RGB 摄像头 |
| 采集日期 | 2026-11-15（实验室实拍，5 段 webm 视频） |
| 原始视频段数 | 5 段（`2026-11-15-181310.webm` 等，本地留存，见 `src/extract_frame.py`） |
| 抽帧间隔 | 每 5 帧抽 1 张 |
| 有效标注图片数 | 待补充（建议 ≥ 300 张） |
| 类别 | `LCross`(0) / `TCross`(1) / `XCross`(2) / `PenaltyPoint`(3) |
| 划分方式 | 按独立视频片段划分 train / val / test |
| 场景覆盖 | 不同距离、方向、尺度、光照；部分遮挡；同类型多标志并存的歧义场景 |

## 标注质量检查

- 训练前随机抽查 ≥ 30 张，将标签框画回原图核对：漏标 / 错标 / 类别编号、框大小、坐标是否越界、宽高是否大于 0。
- 核对 train / val / test 是否存在相邻视频帧泄漏。
