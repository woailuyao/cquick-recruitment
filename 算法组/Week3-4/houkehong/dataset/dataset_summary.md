| 类别 | 仅 `ball` 一类 |

### 划分方式：按视频片段划分（杜绝相邻帧泄漏）

| 集合 | 图片 | 框 | 空标注 |
|---|---:|---:|---:|
| train | 1556 | 2185 | 0 |

**同一段视频的所有帧只会出现在同一个集合中。** 这样 test 的指标才是对"没见过的场景"的真实估计。

### 覆盖的拍摄条件

- 球在画面中央 / 边缘、近距离（2 m）到远距离（10 m）
- 球静止、滚动、贴白色场地线、被脚部分遮挡
- 不同光照（室内灯光、靠窗逆光）
- 含白鞋、白斑等**干扰物**（用于压低误检）

## 三、任务 2 场地标志数据集

| 项目 | 数值 |
|---|---|
| 原始视频段数 | **18 段**（15 段有效标志 + 3 段中圈圆弧作硬负样本） |
| 抽帧总数 | **529 张** |
| 标注实例数 | **940 个框**（LCross 408 / TCross 532） |
| 空标注（硬负样本） | **120 张** |
| 类别 | `LCross`(0)、`TCross`(1) |

### 划分方式：按视频片段划分

| 集合 | 片段 | 图片 | 框 | 空标注 | LCross | TCross |
|---|---|---:|---:|---:|---:|---:|
| train | 15 | 397 | 671 | 120 | 286 | 385 |
| val | 2 | 62 | 126 | 0 | 89 | 37 |
| test | 3 | 70 | 143 | 0 | 33 | 110 |

### 视角覆盖（关键）

18 段视频对应不同的**相机位置与方位角**：

| 组别 | 片段 | 说明 |
|---|---|---|
| 手持俯视（早期） | 215225 / 215319 | 1.2~1.5 m，俯角 30~45° |
| 三脚架低机位 | 223918 / 224011 / 224242 / 224316 / 224416 / 224447 | 0.67 m / 俯角 15° |
| **多方位角（v6 新增）** | 164136 / 164156 / 164214 / 164228 / 164302 / 164315 / 164343 / 164402 / 164427 | 1.0 m / 俯角 −13°，云台转动覆盖约 ±30° |
| 硬负样本 | neg_224039_circle / neg_224140_circle / neg_224212_circle | 只拍到中圈圆弧，标注为空 |

**v6 的关键改动**：新增 9 个方位角的数据，使模型不再只对某个特定角度有效
（未参与训练的方位角召回从 0.08~0.30 提升到 0.68~1.00）。

### 为什么需要硬负样本

场地中线的直线与中圈圆弧相交，会形成**类似 T 型的交叉**，模型早期每帧误检 1 个。
120 张空标注专门训练"这里没有标志"，是压制该类误报的关键。

### 为什么只训练 2 类

现场实测确认：C0 场地只有 L 型与 T 型交叉，**没有 X 型交叉**，点球点位置已按定义固定在场地中心、无可见标志物。
依据细则 2.3「现场没有的类别不得强行要求训练或评分」，因此没有训练 `XCross` 和 `PenaltyPoint`。

## 四、划分脚本与复现

```powershell
# 任务 1
.\.venv\Scripts\python.exe scripts\train.py --src dataset_ball --task ball --prepare-only

# 任务 2（固定划分，保证与报告中的指标一致）
.\.venv\Scripts\python.exe scripts\train.py --src dataset_marker_final --task marker --only-labeled `
  --fixed-split "test=224416,164402,164427;val=224316,164214;train=223918,224011,224242,224447,215225,215319,164136,164156,164228,164302,164315,164343" `
  --neg-segs "224039,224140,224212" --prepare-only --out datasets\marker_v6
```

划分是**按片段名固定指定**的，不是随机抽样，因此任何人重跑都能得到同一份划分。
