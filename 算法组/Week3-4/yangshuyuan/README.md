## 问题与解决过程
**遇到的问题**：在任务二的场地标志检测初期，发现训练出的 YOLO 模型在真实场景下识别率极低，面对稍微远一点的 L/T/X 标志，几乎无法输出检测框，导致后续的地面投影完全无法进行。
**排查与解决过程**：
1. **排查模型置信度**：起初以为是训练数据不够，但检查 `confusion_matrix` 后发现，模型其实能够提取到特征，只是因为场景光照和角点形变的缘故，输出的置信度（Confidence）偏低，达不到 Ultralytics 默认的 0.5 阈值。
2. **降低置信度阈值**：在推理代码中，将 `conf` 阈值下调至 **0.25**。下调后，能够识别但是出现大量误检（如将L线识别为T线）。
3. **结合 OpenCV 优化**：为了弥补低置信度带来的误检和框中心偏移问题，在得到 YOLO 的 BBox 后，利用 OpenCV 对框内图像进行形态学处理（二值化与轮廓提取），提取真正的十字交点/几何中心，而不是简单使用 BBox 的几何中心，从而提高了后续地面投影的精度。

## 当前局限与下一步计划
局限：单目相机缺乏深度信息，当前系统对多目标的数据关联能力极弱（导致红点抖动）。

计划：下一步将引入卡尔曼滤波，结合连续的帧间运动模型，锁定特征点的观测 ID；同时扩充场地线的训练集（尤其是侧视角和逆光场景），提升模型的鲁棒性。
