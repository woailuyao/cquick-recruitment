# 数据集说明

本文件记录第 3–4 周考核所使用的两份数据集的采集方式、规模、类别分布与划分方式。
所有数据均为本人于实验室 / C0 场地使用同一台单目相机实拍，非网络下载、非他人拍摄。

## 3. 任务 2：场地标志数据集

### 3.1 采集

| 项目 | 数量 |
| --- | --- |
| 子数据集 | 3 份（`marker_dataset` 11-20 采集的近景高机位画面，另含 80 张更早旧帧；`marker_dataset2` 中远景；`marker_dataset3` 球门区低视角） |
| 合并后图片 | 271 张 |
| 合并后标注框 | 494 个 |
| 标注工具 | makesense.ai，导出 YOLO 检测格式 |

### 3.2 类别分布

| 划分 | 图片 | 标注框 | TCross | LCross |
| --- | ---: | ---: | ---: | ---: |
| train | 239 | 386 | 226 | 160 |
| val | 18 | 54 | 32 | 22 |
| test | 14 | 54 | 28 | 26 |
| 合计 | 271 | 494 | 286 | 208 |

说明：训练时实际采用 `TCross=0 / LCross=1`，与细则建议的 `LCross=0 / TCross=1` 顺序相反；权重内 names 与训练一致，运行时按名称映射，不影响类别判断。现场未观察到 X 型标志与点球点，因此只训练这两类。

标注规则：

- `TCross`：框住 T 形标志本体，使横线与竖线的交点位于框内可定位位置；
- `LCross`：框住 L 形标志本体，使两条线的交会顶点位于框内可定位位置；
- 框仅贴合标志本身，不包含额外的场地线延长段。

### 3.3 划分

三份数据各自按整段视频划分，同一段视频只进入一个 split。合并配置见 `dataset/marker_data_all.yaml`：

| 划分 | 图片 | 来源 |
| --- | ---: | --- |
| train | 239 | `marker_dataset` 183 + `marker_dataset2` 36 + `marker_dataset3` 20 |
| val | 18 | `marker_dataset2` 10 + `marker_dataset3` 8 |
| test | 14 | `marker_dataset2` 10 + `marker_dataset3` 4 |

val / test 不使用 `marker_dataset`：该批数据机位单一，val 与 train 存在近重复帧，放进验证集会虚高指标。

两点说明：

1. 三批数据视角与尺度互补：旧采集以近景高机位为主（框宽最大约 245 px），`marker_dataset2` 覆盖中远景（框宽 44–97 px），`marker_dataset3` 为球门区低视角（框宽 19–91 px），用于补足远距离小目标。
2. `marker_dataset2` / `marker_dataset3` 为同日同场地连续拍摄，train 与 val 存在场景级近相似帧（逐帧比对无完全重复帧，灰度相关 > 0.95 的 3 对、最高 0.956），因此 val 指标偏乐观；最终指标以独立性最好的 test 集为准。

### 3.4 未纳入的帧

另有 111 张与中圈相关的画面未加入训练集。这些画面中的交叉点是圆与直线的交点，形态上与 X 型标志相似但并非同一类场地特征，为避免类别混淆，单独存放、不参与训练与评估。

## 4. 划分方式说明

- **足球检测**：按整段视频划分。train 使用 v1–v5、v7、v8，val 使用 v9，test 使用 v10。三份数据无共用视频。
- **场地标志**：三份子数据集各自按整段视频划分，同一段视频只进一个 split；train 取三份全部，val / test 只取 `marker_dataset2` 与 `marker_dataset3`，避免 `marker_dataset` 的 val 与 train 近重复帧虚高指标。test 的独立性最好，最终指标以 test 为准。详见 3.3。
