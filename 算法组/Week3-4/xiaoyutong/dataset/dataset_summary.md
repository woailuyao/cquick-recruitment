# 数据集统计

## 任务一：足球检测（ball）

| 项目 | 内容 |
| --- | --- |
| 采集日期 | 2026-11（视频导出日期 2026-11-20） |
| 采集地点 | 本实验室足球场地 |
| 相机 | 队内统一发放的 USB 单目摄像头，1280×720 |
| 原始视频 | 1 段有效素材，抽帧 432 张（`frame_0000.jpg` ~ `frame_0431.jpg`，1280×720） |
| 标注图片 | 238 张（Roboflow 标注后导出） |
| 标注实例 | 363 个（类别 `ball`，class_id = 0） |
| 图片尺寸 | 导出为 512×512（由 1280×720 缩放而来） |

划分方式（Roboflow 导出）：

| 集合 | 图片数 | 标签数 | 说明 |
| --- | --- | --- | --- |
| train | 170 | 170 | 训练 |
| valid | 170 | 170 | **与 train 为同名帧，完全重复** |
| test | 23 | 23 | 独立，用于最终评估 |

由于 valid 与 train 重复，验证集指标（mAP50 0.995）偏乐观；
独立测试集（23 张）指标为 mAP50 0.988 / mAP50-95 0.801，见 README 2.2 节。

场景覆盖：球位于画面左/中/右，近/中/远三种距离，静止/滚动/运动模糊，部分遮挡，
以及机器人、球门等背景干扰。

标注检查：抽查 30 张将标签画回原图核对，未发现漏标与越界；但存在上述 valid/train 重复问题，
属于导出时随机划分导致，后续应改为按视频片段划分。

## 任务二：场地标志（marker）

| 项目 | 内容 |
| --- | --- |
| 采集日期 | 2026-11-10 |
| 原始视频 | 1 段，46.5 秒，1280×720，共 1330 帧 |
| 抽帧数量 | 210 张（每 5 帧取 1 张，筛掉检测不到目标的帧） |
| 标注实例 | 247 个 |
| 类别 | 单类 `marker`；L/T/X 的类型在推理阶段由几何细化判定 |
| 罚球点 | 现场未见独立罚球点，未标注 |

### 数据来源说明

本次受现场条件限制，仅采集到 1 段视频，且无法在提交前完成 300 张手工标注。
因此采用伪标签方案：先用几何检测器（`src/vision2/markers_thick.py`）对抽帧结果自动生成标注，
再用于训练。标注质量取决于该检测器，属于蒸馏性质的数据，与人工真值存在差距。

### 类型分布（伪标签原始类型）

| 类型 | 数量 |
| --- | --- |
| LCross | 9 |
| TCross | 96 |
| XCross | 142 |
| PenaltyPoint | 0 |

同一交点在部分帧中被判为 T、部分帧中被判为 X（胳膊出画面或被遮挡），
若按多类训练会造成标签自相矛盾，因此统一为单类 `marker`。

### 划分方式

按时间连续段划分，不随机打散相邻帧：

| 集合 | 划分 | 图片数 | 标签数 |
| --- | --- | --- | --- |
| train | 前 80% 连续帧 | 168 | 186 |
| val | 中间 10% | 21 | 29 |
| test | 后 10% | 21 | 32 |

### 训练结果

| 项目 | 数值 |
| --- | --- |
| 模型 | YOLOv8n，从头训练（环境无法下载预训练权重） |
| 输入 / batch | 480 / 16 |
| 轮数 | 120（实际约 55 轮判定不收敛） |
| 验证集 Precision / Recall | 0.00 / 0.00 |
| 验证集 mAP50 / mAP50-95 | 0.00 / 0.00 |

结论：该数据量下无法训练出可用模型，本次检测以几何检测器为准。
补齐 ≥5 段视频与 300 张手工标注后，使用 `src/tools/train_marker.py` 重训即可。
