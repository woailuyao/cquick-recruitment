# 数据集摘要（任务 1 · 足球检测）

## 数据来源
- 采集人：weikai
- 采集地点：本人实验室实际场地
- 摄像头：单目 RGB 摄像头（USB/UVC，Windows 侧经 ffmpeg dshow 采集 MJPG 原始流，桥接供 WSL 推理），全程同一台、固定焦距/固定对焦
- 采集日期：2026-11-15
- 原始视频：本人妥善保存备查，**不上传 GitHub**（原始素材未转码、未删除）
- 设备节点 / 分辨率 / 实测帧率：`1280×720`，`MJPG`，连续取帧实测约 `29.8 fps`（见工作包 capture_log）

## 视频与抽帧
- 独立视频段数：**5 段**（V1–V5）
- 各段场景：V1 球在左/近/静止；V2 滚动/运动模糊；V3 远/右/近白线；V4 被机器人部分遮挡；V5 阴影与不同背景
- 抽帧方式：每 15 帧抽 1 张，每段上限 60 张 → 初始 300 张
- 场景甄别：用 COCO 预训练权重初筛 + 逐张目视，剔除无球/不合格帧，保留有球帧
- 最终：**263 张有效标注图片，252 个 ball 标注实例**

## 标注规范
- 单类别 `ball`，`class_id = 0`，YOLO 格式 `class_id x_center y_center width height`（归一化 0~1）
- 部分遮挡只框可见区域；大面积地面、白线、鞋、背包、胶带卷框不入
- **本任务的目标只有蓝白/黑白五角星花纹足球**。场景中的黄绿 Molten 球、红蓝花纹球均属干扰物，**一律不标注**
- 标注工具：LabelImg（YOLO 格式，单类），COCO 预训练预标注草稿 + 人工逐张核对修正

## 数据集划分（按独立视频段整体划分）
| 集合 | 图片 | 来源视频 | 标注实例 |
|---|---:|---|---:|
| train | 153 | V1 / V2 / V3 | 149 |

- 明细见 `split_manifest.csv`（每行标注 image / split / source_video / frame_index）

## 质量检查
- `verify_labels.py` 随机抽查 30 张并把框画回原图：类别全为 0、坐标无越界、无过大框 → PASS
- 修正 1 处浮点边界越界（V1_f000285 右边界 1.0000005，内缩 1e-4）
- 集合间无同视频段泄漏：V1–V3 仅 train、V4 仅 val、V5 仅 test

## 干扰物负样本增强（关键做法）
训练集原始图片不含黄绿球与红蓝球（这两种只出现在 V5 测试段），模型会把它们误检为足球。
为在不污染 test 的前提下教会模型排除干扰，采用 **copy-paste 负样本增强**：

1. 用基线模型框 + 颜色判据从 V5 抠出黄绿球 RGBA 素材 48 个、红蓝球素材 8 个（只用外观，不读 test 标注）
2. 随机旋转/缩放/位置，贴到 train 图片上（共 118 张受影响图：黄绿 69 + 红蓝 65），**标签保持不变**（贴上去的球不画框 = 负样本）
3. val / test 完全不改动，保证测试集独立
4. 脚本：`src/extract_distractors.py` → `src/augment_train.py` → `src/train_eval.py`

效果见 `README.md` 的「误检与漏检案例」与 `outputs/`。
