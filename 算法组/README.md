## 提交方式（和电控组一样）

1. **Fork** 本仓库 → 2. **Clone** 你的 Fork → 3. 进 `算法组/WeekN/` 建 `<姓名拼音>/` → 4. 放代码 + 图 + 说明 → 5. `commit` + `push` → 6. 发起 **Pull Request**。

> **不要再打包 ZIP 交到群里。** 以前是「交 ZIP」，现在统一走 PR：代码、图、说明都在仓库里，评审批量看、也能直接跑你的脚本。

## 目录规范

```
算法组/Week1/
└── <你的姓名拼音>/
    ├── README.md          # 环境、运行方式、参数、踩坑记录
    ├── src/               # task1_basics.py / task2_processing.py / task3_color_detect.py
    ├── data/images/       # 你的测试图片（公开素材请注明来源）
    └── outputs/           # 中间结果、mask、标注结果、对比图
```

## 三条铁律

1. **只交最终截图不算完成**——必须保留中间结果（`outputs/`），并且代码能被人跑起来；
2. **路径用相对路径**，别写死 `C:\Users\你\Desktop\...`，否则别人一 clone 就报错；
3. **图片别太大**：单张控制 1 MB 内、单文件不超过 10 MB；不要提交数据集、模型权重、conda 环境和 `__pycache__`。

## 防抄袭

关键截图带「**姓名拼音 + 时间戳**」，截图前先执行：

```bash
echo "姓名: <你的姓名拼音>"; date "+%Y-%m-%d %H:%M:%S"
```

把这行输出和你的运行结果截在同一张图里。**用别人的图、跑不出同样结果 → 该项 0 分。**
