## 3. 任务一：图像基础操作
已使用 `task1_basics.py` 对 3 张图片进行了读取、尺寸打印、缩放（50%）、中心裁剪（200x200）及灰度转换。处理结果保存在 `outputs/task1/`，原图未被覆盖，并成功进行了保存后重读验证。

## 4. 任务二：基础图像处理对比
针对 `image1.jpg`，进行了不同参数的处理对比，结果保存在 `outputs/task2/`：
1. **滤波对比 (3x3 vs 9x9)**：`3x3` 高斯滤波去除了细微噪点且保留了边缘；`9x9` 滤波更平滑，但物体边缘变得模糊、细节丢失。
2. **阈值对比 (80 vs 160)**：阈值设为 `80` 时（宽松），提取的白色区域较多，包含了部分较暗背景；阈值设为 `160` 时（严格），大量灰色区域变黑，只保留了更亮的主体部分。
3. **边缘检测 (Canny 50/150 vs 100/200)**：低阈值下边缘提取丰富，但碎线和噪点较多；高阈值下边缘更干净连续，但部分微弱边缘（如阴影交界处）丢失。
4. **形态学处理**：对二值图进行**开运算**去除了孤立的白色噪点；进行**闭运算**填补了目标主体内部因反光产生的小黑色空洞，使区域更连贯。

## 5. 任务三：颜色目标提取与轮廓定位
在 `task3_color_detect.py` 中，针对 3 张不同特征的照片设置了自适应的 HSV 参数与面积过滤阈值，提取结果存于 `outputs/task3/`。

**运行结果记录**：
- **图1（浅蓝眼镜盒）**：找到目标，中心坐标 `(439, 1277)`，面积 `13503`。
- **图2（黄色液体瓶）**：找到目标，中心坐标 `(486, 1031)`，面积 `71013`。
- **图3（红色花朵）**：找到 2 个目标。目标1中心 `(293, 192)` 面积 `1199`；目标2中心 `(153, 113)` 面积 `6258`。

**HSV 与面积阈值设置依据**：
- **图1（浅蓝眼镜盒）**：HSV 范围 `[80, 30, 40]` 至 `[130, 255, 255]`。由于物体偏灰且大面积反光，饱和度极低，因此大幅放宽了 S 的下限。面积阈值设为 `10000` 以排除背景杂物干扰。
- **图2（黄色液体瓶）**：HSV 范围 `[15, 40, 80]` 至 `[40, 255, 255]`。针对高光反光，放宽了 V（明度）和 S（饱和度）的范围。面积阈值设为 `2000`。
- **图3（红色花朵）**：由于红色在 OpenCV HSV 模型中跨越了 0 和 180 边界，采用了双区间提取并取并集 `[0, 80, 50]-[10, 255, 255]` 与 `[160, 80, 50]-[180, 255, 255]`。面积阈值设为 `1000`。
- **形态学优化**：使用了 `15x15` 的较大核进行闭运算，旨在将因反光断裂的颜色块强行连接成一整个目标，再进行开运算去除周边噪点。

## 6. 失败案例与改进思路
- **现象**：在处理图1（浅蓝眼镜盒）初期，使用常规蓝色阈值时，算法只框选了盒子上偏蓝的文字部分，未能框选整个盒子；后续放宽阈值后，虽然成功框选主体（面积 13503），但由于反光和阴影干扰，边缘不够精确。
- **原因分析**：传统颜色阈值法过度依赖光照和材质。眼镜盒表面材质反光且饱和度极低，光照不均导致其大面积偏向灰白色，难以用单一固定的 HSV 范围完美分割。
- **改进思路**：
  1. 在进行 `inRange` 提取前，先对图像做直方图均衡化（CLAHE）或边缘检测（Canny），结合梯度信息辅助提取。
  2. 改用自适应阈值，或结合深度学习的目标检测模型（如 YOLO）来处理复杂光照下的目标识别。
