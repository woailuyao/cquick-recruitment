## 二、学习内容

| 内容 | 操作范围 |
|---|---|
| **基础操作** | 图像读取与保存（`imread` / `imwrite`）；显示图像；查看尺寸、通道数；缩放、裁剪；理解 BGR 与 RGB 的区别 |
| **颜色空间** | 灰度图、BGR、HSV；通道拆分；用 `inRange` 设置颜色范围；用掩膜提取目标区域 |
| **图像预处理** | 均值 / 高斯 / 中值滤波；固定阈值与自适应阈值；Canny 边缘检测；观察不同参数对结果的影响 |
| **形态学处理** | 腐蚀、膨胀、开运算、闭运算；理解「去除小噪声 / 连接断裂区域 / 填补小孔」各自的作用 |
| **轮廓与几何信息** | `findContours`、`contourArea`、`boundingRect`、矩；绘制轮廓、外接矩形和中心点，读取目标位置与面积 |
| **结果验证** | 保存中间结果；对比原图与处理图；记录参数；**在不同图片上验证，不以单张图片成功作为完成标准** |

> **练习提示**：每掌握一个操作就立刻运行看输出；先确认输入图像、尺寸、通道数，再调参数。**保留关键中间结果，不能只交最终截图。**

## 三、练习任务

本周以**传统 OpenCV 图像处理**为主：暂不要求训练深度学习模型，也不要求接入机械臂控制。重点是理解处理流程、能解释参数、并验证算法在不同样本上的表现。

### 任务一：图像基础操作

新建 `task1_basics.py`，在**至少 2 张**图片上完成以下操作，结果保存到 `outputs/task1/`：

1. 读取图片并检查是否读取成功，打印图像宽、高和通道数；
2. 分别完成**缩放**、**指定区域裁剪**、**灰度转换**，显示或保存处理结果；
3. 将处理后的图片写入文件，并检查保存的文件能否重新读取。**原图不得被覆盖。**

**完成标准**：代码可独立运行；每种操作至少有一张输出图片；路径用项目内相对路径，或在 README 中说明。

### 任务二：基础图像处理对比

选一张目标清晰的图片，分别输出：**灰度图**、**高斯滤波结果**、**阈值分割结果**、**Canny 边缘图**，以及**一次形态学处理结果**，保存到 `outputs/task2/`。

在 README 中简要记录：

**至少更换 2 组参数**做对比。

**完成标准**：不少于 **5 张**中间结果图，且能说明**至少 2 个参数**对结果的影响。

### 任务三：颜色目标提取与轮廓定位

1. 选一种颜色较明确的物体（建议蓝色、绿色或橙色），把图像从 BGR 转到 **HSV**，用 `inRange` 生成二值掩膜；
2. 用开运算或闭运算改善掩膜；用 `findContours` 查找目标轮廓，按**轮廓面积**过滤明显噪声；
3. 在原图上绘制目标的**外接矩形**和**中心点**，输出中心坐标 `(x, y)` 与轮廓面积；保存 `mask.png` 和 `result.png`；
4. **至少用 3 张**不同背景或光照条件的图片测试，记录哪些情况识别稳定、哪些情况容易误检或漏检。

**完成标准**：输出掩膜图、标注结果图及坐标 / 面积记录；**能解释 HSV 范围与面积阈值是怎么定的**。

## 七、常见问题

**Q1：`cv2.imshow` 报错 / 窗口一闪就没了 / 黑屏。**
A：虚拟机没装图形界面或走了 Wayland 时很常见。**直接改成 `cv2.imwrite` 存图再看文件**，效果一样，不影响验收。

**Q2：用中文路径（比如桌面\图片\）读图，`imread` 返回 `None`。**
A：OpenCV 的 `imread` 对中文路径支持不好。两个办法：① 路径全改英文（**推荐**，也符合仓库的相对路径要求）；② 用 `np.fromfile` + `cv2.imdecode` 读。

**Q3：HSV 范围该怎么设？**
A：先用画图工具或 `cv2.cvtColor` 看目标像素的 H/S/V 实际值，再留一定余量。**H 是 0~179（不是 0~360）**，这是新手最容易踩的坑。

**Q4：开运算和闭运算到底啥区别？**
A：**开运算 = 先腐蚀后膨胀**，去掉小噪点、断开细连接；**闭运算 = 先膨胀后腐蚀**，填补小孔、连接断裂区域。记「开后去噪、闭后补洞」。

**Q5：面积阈值怎么定？**
A：先把所有轮廓面积打印出来看数量级，再取一个「明显大于噪点、明显小于目标缺失值」的数。**并在 README 里写清依据**——这是评分点。

**Q6：图片太大，`git push` 卡住。**
A：压到 1 MB 内再传（`cv2.imwrite` 时加 `[cv2.IMWRITE_JPEG_QUALITY, 85]`，或存 PNG 前先缩放到 1280 宽以内）。不要为了清晰传十几 MB 的原图。

**Q7：任务四没摄像头怎么办？**
A：用手机录一段视频传到电脑，`cv2.VideoCapture('xxx.mp4')` 一样能做。**选做题，不做不扣分。**
