# 使用说明（快速上手）

本工程是 CQuick 战队算法组第 3–4 周招新考核的**完整工程骨架**，覆盖两条链路：

1. **任务 1 · 足球检测**：实拍 → 抽帧 → 标注 → 训练 YOLO → 实时检测框
2. **任务 2 · 单目场地自定位**：标定 → 标志检测 → 地面投影 → field.yaml 匹配 → 位姿输出

> 注意：实拍数据、B 站录屏、C0 现场测试需你本人在实验室完成，本骨架提供全部代码与配置模板。

## 任务 1：足球检测

### 1. 相机自检
```bash
python scripts/camera_selfcheck.py --device /dev/video0
```

### 2. 抽帧（按独立视频片段划分，避免泄漏）
```bash
python scripts/extract_frames.py \
    --videos v1.mp4 v2.mp4 v3.mp4 v4.mp4 v5.mp4 \
    --out soccer_dataset --interval 5
```

### 3. 标注（LabelImg/CVAT 输出 YOLO 格式），然后检查
```bash
python scripts/check_labels.py --data soccer_dataset --sample 30
```

### 4. 生成 data.yaml + 训练
```bash
python scripts/make_data_yaml.py --data soccer_dataset --names ball --out soccer_dataset/data.yaml
python scripts/train_yolo.py --data soccer_dataset/data.yaml --name ball --epochs 50 --device 0
```

### 5. 独立测试集评估
```bash
python scripts/eval_yolo.py --weights runs/ball/weights/best.pt --data soccer_dataset/data.yaml
```

### 6. 实时检测
```bash
python scripts/detect_ball.py --weights runs/ball/weights/best.pt --device /dev/video0
```

## 任务 2：单目场地自定位

### 1. 相机内参标定（棋盘格，≥15 张，覆盖四角/中心/不同角度）
```bash
python scripts/calibrate_intrinsics.py \
    --images ./calib_images/*.jpg --rows 6 --cols 9 --square 0.025 \
    --out calibration/camera_intrinsics.yaml
```

### 2. 外参模板（按实测填 height/pitch/roll）
```bash
python scripts/make_extrinsics.py --height 0.35 --pitch 15 --roll 0 \
    --out calibration/camera_extrinsics.yaml
```

### 3. 训练标志检测模型（类别 LCross/TCross/XCross/PenaltyPoint）
```bash
python scripts/make_data_yaml.py --data marker_dataset \
    --names LCross TCross XCross PenaltyPoint --out marker_dataset/data.yaml
python scripts/train_yolo.py --data marker_dataset/data.yaml --name marker --epochs 50
```

### 4. 实时定位（左右分屏）
```bash
python scripts/localize_field.py \
    --field config/field.yaml --geometry config/field_geometry.yaml \
    --intrinsics calibration/camera_intrinsics.yaml \
    --extrinsics calibration/camera_extrinsics.yaml \
    --marker_model runs/marker/weights/best.pt --device /dev/video0
```

## 关键算法说明

### 地面投影（像素 → 载体地面坐标）
1. 像素 `(u,v)` 先去畸变；
2. 反投影射线 `d_c = K⁻¹[u,v,1]ᵀ`；
3. 外参变换到载体坐标 `d_b = R·d_c`；
4. 与地面平面 `Z=0` 求交 `P_b = O_b + λd_b`，`λ = -O_bz/d_bz`。

### 地图匹配（观测 → 地图位姿）
- 观测标志（载体坐标地面点 + 类别）与 field.yaml 同类特征做候选匹配；
- RANSAC + SVD 最小二乘求解 SE(2) 位姿 `(x, y, θ)`；
- 内点数量、残差、类别分布共同判断 `valid/status`；
- 同类标志多候选匹配，歧义/残差过大时输出 `valid=false`。

### 定位有效状态
- `insufficient_markers`：标志数 < 3
- `ambiguous`：同类点匹配多解无法消除
- `high_residual`：匹配残差超阈值（默认 0.5m）
- `not_converged`：位姿落在场地范围外
- `ok`：定位有效
