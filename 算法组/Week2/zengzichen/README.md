\## 任务 3：ROS2 通信



1\. 消息字段与话题名

消息字段：

'bool detected'：本帧是否检测到目标。

'float32 u'：目标中心的图像横坐标（像素）。

'float32 v'：目标中心的图像纵坐标（像素）。

'float32 area'：目标轮廓面积（像素平方）。

话题名：'/target\_position'



2\. 发布/订阅流程

Publisher：通过定时器以固定频率（2秒/次）触发。读取测试图片，执行任务一的视觉算法（HSV 转换、掩膜提取、形态学去噪、轮廓计算），将算出的真实中心点坐标 '(u, v)' 和面积 'area' 封装为 'TargetPosition' 消息，发布到 '/target\_position' 话题。

Subscriber：订阅 '/target\_position' 话题。在回调函数中接收消息，若 'msg.detected' 为 True，则打印检测成功与坐标数据；若为 False，则打印未检测到目标的警告。



3\. 实际检测结果如何接入

在发布节点的 'timer\_callback' 中，将任务一原本的 'print' 输出改为了对 'TargetPosition' 消息对象的赋值：

```python

msg.detected = True

msg.u = float(u)

msg.v = float(v)

msg.area = float(area\\\_c)

```
