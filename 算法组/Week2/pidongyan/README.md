## 任务 3：ROS2 通信


#为什么 `u、v` 不能直接当机器人运动指令
注：1和2是个人理解，345是AI给的解答，个人有所理解。、

1.`u/v` 是像素，指目标点出现在图片的哪个位置，和机器人移动没关系。
2.属于二维（个人理解）。在三维世界里，一个uv点可能是 1 米外的球，也可能是 5 米外的球。只有uv无法区分远近。

3.没做畸变校正和坐标变换。相机有畸变（图像边缘更明显），且相机装在车上某个位置、有安装角度。像素坐标要变成车体坐标，需要内参标定（焦距、主点、畸变系数）+ 外参（安装位置与朝向）。
4."怎么动"属于控制决策，不是视觉的职责。视觉只回答"目标在哪"；"该左转 5° 还是 10°、该走多快"是由控制模块根据偏差、速度、时延去算的。把 `u` 直接塞给轮子，等于把两个模块的职责混在一起。
5.正确用法是"用偏差，不用绝对值"。例如 `u - 540`（图像宽度一半）为正说明目标偏右，可用于转向；`v - 960` 说明目标偏上/偏下，可用于云台俯仰。用的是相对画面中心的偏差量，仍然要经过控制律换算，不能直接当速度。
