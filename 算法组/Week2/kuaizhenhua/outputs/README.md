# 结果文件

- detection：5张公开照片的原始mask、形态学mask、标注图、原图对比及summary.json。
- comparison：两组必做参数实验。01_v_min是玻璃球V下限70→40；02_min_area是合成小圆面积500→100。各组有对比PNG与原始统计节选。
- ros2/manual：本人现场实验完整接收记录，共5843条；summary.json记录实际起止时刻。截图时为5581条，程序继续运行至停止，因此最终条数更多。
- ros2/dynamic_test：助手实际执行默认参数15条、动态调参后15条的独立ROS2检查，含命令、发布日志和接收记录。

照片及其标注、对比图沿用原照片许可和署名，见[来源说明](../data/real_images/来源说明.md)。CC BY-SA照片的衍生图仍按原SA许可发布。代码许可证不替代照片许可。

所有运行记录的原始时间保留。图片预览截图的时间是查看结果时刻，检测运行时间见个人目录的01_检测输出.png。
