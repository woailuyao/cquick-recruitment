## 任务 1：颜色目标检测
目标颜色：红色
HSV 阈值：下限 (0, 120, 80)，上限 (10, 255, 255)
最小面积：300
中心点计算方法：对轮廓使用 `cv2.moments()` 计算轮廓矩，由矩公式得到轮廓质心坐标 cx, cy。
测试图片结果：程序遍历文件夹中多张测试图片，成功提取红色目标轮廓，计算中心点，绘制标记并保存结果图到 output 文件夹。

## 任务 2：可视化与参数对比
参数A：最小面积300；参数B：最小面积1000
结果变化：面积阈值300时，小色块也会被识别，存在误检；面积阈值调高到1000后，过滤掉微小噪点，只保留大目标，但过小的真实目标会漏检。
误检/漏检案例：画面里红色小噪点在低阈值下被当成目标（误检）；尺寸偏小的红色物体在高阈值下直接被过滤（漏检）。

## 任务 3：ROS2 通信
消息字段：float64 x，float64 y（TargetPoint.msg）
话题名：/target_point
发布/订阅流程：
1. multi_img_pub 节点读取图片、颜色检测、算出中心点；
2. 封装成自定义 TargetPoint 消息，通过话题 /target_point 发布；
3. sub_node 节点订阅 /target_point，收到消息后打印坐标。
实际检测结果接入：图像检测得到的 cx、cy 直接赋值给消息的 x、y，交给ROS发布。

## 问题与解决过程
问题：执行 `ros2 interface show detect_interface/msg/TargetPoint` 提示找不到该消息。
排查过程：一开始写完消息文件后没有单独编译接口包，也没有 source 环境；
解决：单独编译 detect_interface，执行 `source install/setup.bash` 刷新环境，命令正常运行，成功查看消息结构。
