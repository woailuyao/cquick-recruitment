# W2 视觉算法第二周作业

## 1. 环境与运行说明

- **开发环境**：Ubuntu 22.04.5 LTS (WSL2)，ROS2 Humble，Python 3.10.12，OpenCV 4.5.4
- **依赖安装**：`sudo apt install ros-humble-desktop python3-opencv python3-numpy`
- **运行方式**：先在工作空间编译，再开两个终端分别跑发布和订阅
  ```bash
  cd ~/ros2_ws
  colcon build
  source install/setup.bash
  ros2 run cquick_vision publisher     # 终端 1
  ros2 run cquick_vision subscriber    # 终端 2
  ```
- **话题**：`/target_position`，消息类型 `cquick_interfaces/msg/TargetPosition`
- **输入输出**：输入是测试图，每秒读一次；输出是每秒一条目标位置消息

## 2.任务一

- **目标颜色**：橙色（橙色球）。
- **HSV阈值**：下界 `(0,50,50)`，上界 `(15,255,255)`。橙色偏红，H 落在 0~15 之间。
- **最小面积**：`MIN_AREA = 100`（像素平方），低于它的轮廓当噪点丢掉。
- **多候选选择**：先用面积阈值过滤，再取面积最大的轮廓作为目标。
- **中心点**：用轮廓矩计算，`cx = m10/m00`、`cy = m01/m00`，`m00 == 0` 时按未检测处理，输出 0 而不是未初始化的坐标。
- **测试图片结果**：一共 4 张（清晰、冷光、偏暗、暖光），尺寸有 469×265 和 1280×720 两种。前三张都能稳定检出，目标中心都落在画面中部一带；暖光那张把背景也检进来了，属于误检。
- **失效情况**：光照变化、反光、背景同色、目标遮挡，以及目标太小被 `MIN_AREA` 当噪点丢掉。

## 3.任务二

- **可视化**：在原图上画绿色外接矩形、红色中心点和 `u=..., v=...` 文字，结果保存到 `outputs/`，不依赖临时窗口。
- **参数对比一（最小面积）**：`MIN_AREA` 往下调结果基本不变，因为这几张图噪点本来就少；往上调得很大时，目标会被当成噪点过滤掉，直接变成漏检。所以这个值要落在噪点面积和目标面积之间，不能随手设。
- **参数对比二（H上界）**：暖光图把 H 上界放宽后，mask 里背景白点连成一大片，检测框明显变大、把背景也框进去了；收得太紧误检是少了，但目标边缘被削掉一块，中心点也跟着偏。最后取了中间的值。
- **参数对比三（开运算）**：5×5 开运算去掉了 mask 边缘的毛刺，中心点只动了一点点，对定位基本没影响；噪点多的图上效果会更明显，代价是目标边缘被削薄。
- **误检案例**：暖光图背景与目标同色，面积最大的那块轮廓把背景吞了，检测框比正常图大一圈。
- **漏检案例**：最小面积设得过大时，目标被当成噪点过滤，直接报未检测到。
- **像素坐标**：`(u, v)` 只是目标在图像里的位置，左上角是原点，u 向右、v 向下。它不是场地坐标也不是米制距离，换成真实坐标要做相机标定和坐标变换。

## 4.任务三

- **消息字段**：`bool detected`、`float32 u`、`float32 v`、`float32 area`，`ros2 interface show` 能正常显示。
- **发布端**：`publisher.py` 每秒读一次测试图，检测后把 `detected / u / v / area` 填进消息发到 `/target_position`。
- **订阅端**：`subscriber.py` 订阅同一话题，打印这四个字段。
- **实际接入**：发的就是任务一检测出来的坐标，不是写死的值；本帧没检测到就把 `detected` 置 False、坐标置 0。
- **实测结果**：让发布端连着发十几条，订阅端每条都收到了，四个字段也对得上。
- **为什么 u、v 不能当运动指令**：像素坐标既不是角度也不是距离，相机一移动同一个目标的 u 就跟着变，中间缺标定和坐标转换，控制模块拿到一个像素值不知道该转多少度。

## 5.失败案例

- **失败原因**：`test3_orange_warm.jpg` 背景与目标 HSV 接近，`inRange` 把背景也算了进来，mask 连成一片，检测框比正常图大很多。
- **改正方法**：把 H 上界从 25 收到 15，背景白点散开了，中心点也回到目标上。但只是压制没彻底解决，背景里还有大量同色像素。
- **另外踩的坑**：图片路径一度写死成绝对路径，换台机器就找不到图，改成随包安装到 share 目录再用 `get_package_share_directory` 定位；还有在包目录里误跑 `colcon build`，`build/install/log` 混进 `src`，导致 `ros2 interface show` 找不到消息，删掉重编译才恢复。

## 6.目录结构

- **src**：`cquick_interfaces`（消息接口包）和 `cquick_vision`（检测与通信节点）。
- **data/images/**：测试用的原图。
- **outputs**：掩膜图和标注结果。
- **截图**：`01_检测输出.png`、`02_结果可视化.png`、`02_参数对比.png`、`03_interface_show.png`、`03_pub_sub分屏.png`。
