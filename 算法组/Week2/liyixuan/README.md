## 任务 1：颜色目标检测
- **目标颜色**：绿色（苹果）。
- **HSV 阈值**：下限 [35, 43, 46]，上限 [90, 255, 255]。
- **最小面积**：500。
- **中心点计算方法**：通过 cv2.boundingRect 获取外接矩形，再用 x+w//2 和 y+h//2 计算。
- **多目标选择规则**：使用 max(contours, key=cv2.contourArea) 只选择面积最大的轮廓。
- **失败原因分析**：1. 光线太暗导致 V 值不够；2. 背景有绿植导致误检；3. 目标太小面积低于 500 被过滤。

## 任务 2：可视化与参数对比
- **参数对比**：参数 A（正常阈值）识别面积大（42821.0），完美框住苹果；参数 B（严格阈值）识别面积小（692.5），发生了漏检，只识别到了苹果最亮的一小块反光。
- **坐标概念**：u、v 只是图像上的像素坐标，不是真实距离。需要相机标定才能转换成机器人坐标。
