## 任务 1：颜色目标检测
- **目标颜色**：绿色。
- **HSV 阈值**：下界 `[35, 43, 46]`，上界 `[85, 255, 255]`。
- **最小轮廓面积**：`500`。
- **中心点计算方法**：使用 `cv2.moments` 计算轮廓矩，通过 `m10/m00` 和 `m01/m00` 得到图像坐标系下的 `u` 和 `v`。
- **多个候选目标时如何选择**：程序会提取所有绿色区域的轮廓，然后根据面积从大到小进行排序。随后遍历排序后的列表，选取第一个面积在 500（最小面积）到 300000（最大面积）范围内的轮廓作为最终目标。
- **测试图片结果**：
  - 对 5 张图片进行了测试。img3和img4成功检测到目标。
  - img3 的图片尺寸约为 1543×2048，目标实际中心大致位于画面正中偏下 `(u=720, v=977)`。

## 任务 2：可视化与参数对比
- **可视化**：利用 `cv2.drawContours` 画绿框，`cv2.circle` 画红点，`cv2.putText` 写坐标，并将结果全部保存为 `result_*.jpg` 文件。
- **参数对比实验（结果变化分析）**：
  1. **最小轮廓面积**：将最小轮廓面积为50000时img4无法检测到目标，改为500后检测成功
  2. **是否使用形态学开闭运算**：对于img4,不使用形态学时，草地碎斑和反光导致中心点跑偏；使用后，填补了苹果反光造成的空洞，轮廓平滑，中心点稳定。
  3. **HSV 上下界调整**：HSV原始阈值为HSV_LOWER = [35, 43, 46]，改为HSV_LOWER = [35, 100, 100]，提高 S(饱和度) 和 V(明度) 下界后，有效过滤了颜色较暗的草地，成功检测到苹果，但也过滤了苹果较暗部分。
  4. **光照变化**：
- **误检案例**：img1.jpg，因为草地颜色与目标相近，且树荫干扰，导致误检。
- **漏检案例**：img5.jpg，因为白布阴影带有轻微黄绿色调，导致算法将苹果与阴影连通，发生过度分割。

## 任务 3：ROS2 通信
- **消息字段**：`bool detected`, `float32 u`, `float32 v`, `float32 area`。
- **话题名**：`/target_position`。
- **发布/订阅流程**：
  - **输入**：发布节点（`publisher_node`）读取静态测试图片。
  - **处理**：使用 HSV 阈值和面积筛选逻辑寻找目标。如果找到，`detected` 设为 `true` 并填入坐标；如果没找到，`detected` 设为 `false`，坐标清零。
  - **输出**：通过 `/target_position` 话题发布出去；订阅节点（`subscriber_node`）接收并打印。
- **实际接入**：发布的数据不是写死的假数据，而是直接读取了 img3 和 img1，经过真实检测计算得到的坐标，并在分屏截图中展示了不同图片的交替发送。
