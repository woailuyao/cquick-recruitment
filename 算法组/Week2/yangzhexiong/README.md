## 任务 1：颜色目标检测
- **目标颜色**：红色、橙色 
- **HSV 阈值**：红色取 [0,100,100]-[10,255,255] 和 [160,100,100]-[180,255,255]；橙色取 [11,100,100]-[25,255,255] 
- **最小轮廓面积**：`min_area = 500` 
- **中心点计算方法**：使用外接矩形 `cv2.boundingRect` 获取左上角 (x,y) 和宽高 (w,h) 通过 `center_x = x + w // 2` 计算中心点 
- **失败原因分析**：1. 光照过暗时 明度（V）过低无法提取；2. 背景有相近颜色（如草地里的枯黄落叶）容易误检 

## 任务 2：可视化与参数对比
- **可视化**：在原图上使用 `cv2.rectangle` 绘制了绿色外接矩形 `cv2.circle` 绘制了中心点 并在终端打印了像素坐标 
- **参数 A（min_area = 500）**：能够框出画面中的所有目标 
- **参数 B（min_area = 5000）**：调大面积阈值后 成功过滤了噪点 但**导致距离较远的较小目标漏检** 
- **坐标理解**：像素坐标只代表图像内的相对位置 不能直接发给底盘控制运动 需要相机标定和坐标转换 

## 任务 3：ROS2 通信
- **消息设计**：创建了 `custom_interfaces` 包 定义了 `TargetPosition.msg` 包含 `bool detected`、`float32 u`、`float32 v`、`float32 area`
