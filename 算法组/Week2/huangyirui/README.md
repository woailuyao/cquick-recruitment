## 三、任务一 · HSV 颜色分割与中心点
src/task1_hsv_detect.py 把图转成 HSV，用 (36,85,60)–(60,255,255) 分割出黄绿色区域；
先做开运算去除噪点，再做闭运算填补孔洞；
只保留最外层轮廓，并过滤掉面积不足 500 的轮廓；
最后用 moments 计算中心。sample_1 检出中心 (402,66)、面积 682 px²，
掩膜、标注图和 target.json 存入 out/task1/

## 四、任务二 · 可视化与参数对比
src/task2_compare.py 用六组参数运行四张球图，并输出“原图 + 掩膜 + 标注”的三联图；
base 全部检出，loosen 会把背景并进来（sample_1 面积从 682 增加到 6056），
kernel9 会腐蚀边缘（从 4025 变为 3622），area2000 会让小目标漏检；
报告在 out/task2/report.md

## 五、任务三 · ROS2 发布与订阅
在 Ubuntu 22.04 + ROS2 Humble 下，target_position 包定义 detected/u/v/area 四个字段的消息；
target_detector 包的 detector 节点每 0.1 s 处理一帧并发布到 /target_position，listener 订阅并打印；
在 colcon build 后，分别运行 ros2 run target_detector detector 与 listener，
用 ros2 topic echo 与 ros2 topic hz 
验证频率约为 10 Hz。

## 六、失败案例与改进思路
1.最开始只有sample_6能读取，因为其他几张照片里的球都是白色的，不利于读取
    我仔细读了一下要求，并且考量了一下这一周之内，若要识别白球需要用到模型调用之类的机械训练，目前我暂时没有这个条件，且时间比较紧迫
    我将图片里的白球染成了荧光绿以切合这周的要求
    但是在改变图片后发现H和V区间的限定难以锁定sample_6，我尝试了几乎所有的区间，都没法实现两者同时读取
    这个问题大概要留到以后使用机械学习的时候来进一步解决了，目前能保证其他几张成功读取

2.读取球区间不定，有的过大有点过小
    我本以为是面积设定的问题，改了好几版面积area限定但都没能成功
    经过排查发现较大的噪点核kernel_core会让球边缘被吃掉很多

3.读取球读不准，可能锁到背景上的一些相近色块
    通过面积锁定和球轮廓contour的弧度、四点和计算中心的误差就能较准确地读到球形
