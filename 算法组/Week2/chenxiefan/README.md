像素坐标与真实世界坐标的区别解释：
像素坐标 (u, v) 是在二维图像平面上的坐标。图像左上角为原点 (0,0)，u 轴向右增大，v 轴向下增大。它不能直接代表真实世界中的米制距离（如目标离机器人的实际距离）。因为相机拍摄存在透视畸变、镜头缩放（焦距）等因素。要将像素坐标转换为真实世界坐标，必须经过相机标定，获取相机的内参矩阵和畸变系数，再通过几何投影变换（如单应性矩阵）结合已知的安装高度或距离才能实现。

消息字段：
接口包：vision_interfaces
消息文件：msg/TargetPosition.msg
| 字段 | 类型 | 含义 | 未检测到目标时 |
|---|---|---|---|
| detected | bool | 本帧是否检测到目标 | false |
| u | float32 | 目标中心的图像横坐标（像素） | 0.0 |
| v | float32 | 目标中心的图像纵坐标（像素） | 0.0 |
| area | float32 | 目标轮廓面积（像素平方，近似值） | 0.0 |

话题名：
| 项目 | 内容 |
|---|---|
| 话题名 | /target_position |
| 消息类型 | vision_interfaces/msg/TargetPosition |
| 发布节点 | target_publisher |
| 订阅节点 | target_subscriber |
| 发布频率 | 10 Hz |
| QoS 队列深度 | 10 |

发布/订阅流程：
发布节点 vision_nodes/publisher_node.py：
1. 按 image1.jpg 到 image5.jpg 的顺序循环读取 ~/ros2_ws/data/images 下的图片；
2. 转 HSV，用两个红色区间分别生成掩膜后合并；
3. 做 10x10 闭运算和开运算，提取外轮廓，取面积最大的轮廓；
4. 轮廓面积大于 500 时，用外接矩形的中心作为目标中心；
5. 把 detected、u、v、area 填入消息，发布到 /target_position，频率 10 Hz。

订阅节点 vision_nodes/subscriber_node.py：
1. 订阅 /target_position；
2. 每收到一条消息，打印 detected、u、v、area。

实际检测结果如何接入：
返回值(cx, cy, max_area)填入消息：
detected：process 返回 None 时为 false，否则为 true；
u、v：外接矩形中心 cx、cy；
area：最大轮廓面积 max_area。
