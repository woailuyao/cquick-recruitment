# 第 2 周考核：颜色目标检测与 ROS2 通信

- 姓名：许勐搏（xumengbo）
- 完成日期：2026-10-29
- 环境：Ubuntu 22.04 / ROS2 Humble / Python 3.10 / OpenCV 5.0.0

## 一、整体流程

图像 → HSV 阈值分割 → 形态学处理 → 提取轮廓 → 计算目标中心点 (u, v) → 在图上标注并输出 → 通过 ROS2 话题发布 → 订阅端打印结果。

## 二、任务 1：颜色目标检测

### 2.1 参数

| 参数     | 值              |
| ------ | -------------- |
| 目标颜色   | 绿色             |
| HSV 下界 | (35, 80, 60)   |
| HSV 上界 | (85, 255, 255) |
| 最小面积   | 500            |
| 形态学    | open，核 5×5     |
| 多目标    | 按面积降序取最大       |

中心点用轮廓矩计算：u = m10/m00，v = m01/m00；如果 m00 == 0（轮廓退化），改用外接矩形中心。没检测到目标时输出"未检测到目标"，不返回坐标。

### 2.2 测试结果（6 张图）

合成图（640×480）：

| ---------------- | ------ | ----- | ----- | ------ |

| test2_small      | 成功     | 120.0 | 110.0 | 954    |

### 2.3 失效原因

- 背景和目标颜色相近时误检（test3、草地）；
- 目标颜色不在阈值范围内时漏检（篮球不是绿色）；
- 光照、反光会改变 S/V，目标可能超出阈值范围；
- 目标太小会被 min_area 过滤掉。

## 三、任务 2：可视化与参数对比

### 3.1 可视化

结果图上画出：轮廓（绿色）、外接矩形（黄色）、中心点（红色十字 + 蓝色圆点）、坐标文字（黑底白字）。没检测到时图上显示 NO TARGET DETECTED。结果图和掩膜图存到 out/ 目录。

### 3.2 参数对比（每次只改一个参数）

- 收紧 HSV 下界：草地足球那张，lower 从 (35,80,60) 改成 (52,145,100) 后，从"整片草地被框"变成"未检测到"；
- 加大 min_area：500 → 8000 后，test2（面积 954）被漏检。

结论：HSV 阈值松一点误检多，紧一点漏检多；min_area 太高会漏掉小目标。

### 3.3 像素坐标说明

u/v 原点在图像左上角，u 向右、v 向下，单位是像素。它表示目标在图像里的位置，不等于真实世界坐标，要用于机器人需要相机标定，本周没做。

## 四、任务 3：ROS2 通信

### 4.1 消息

话题：/target_position，类型 target_interfaces/msg/TargetPosition，4 个字段：

| 字段       | 类型      | 含义    |
| -------- | ------- | ----- |
| detected | bool    | 是否检测到 |
| u        | float32 | 中心横坐标 |
| v        | float32 | 中心纵坐标 |
| area     | float32 | 轮廓面积  |

detected 为 false 时 u/v/area 填 0。

### 4.2 节点

- target_publisher：读测试图 → 调用检测 → 发布到 /target_position（2 Hz 轮换）
- target_subscriber：订阅并打印 detected/u/v/area

### 4.3 验证

- interface show 输出 4 个字段；
- 发布端、订阅端分屏运行，订阅端连续收到 14 条消息；
- topic info 显示 Publisher count: 1、Subscription count: 1；
- 消息内容和检测结果对应，例如 test1 → detected=true, u=320.0, v=240.0, area=15172。
