- 失败状态：`insufficient_markers`（<2 个标志）、`baseline_too_short`（基线 <0.25 m）、`ambiguous`（多解未锁定）、`high_residual`、`not_converged`，此时 `valid=false`、坐标输出 `null`，界面显示原因。

## 问题与解决过程

1. **像素→地面投影全错**：`cv2.undistortPoints` 传了 `P=K` 却当归一化坐标用，且 `t = −h/d_z` 符号写反。改用归一化输出和 `λ = h/(cos p·y_n + sin p)`，往返误差降到 1e-9。
2. **位姿乱跳且永远 valid=true**：原实现只取任意一对观测、残差只校验第二个点。改为候选生成 + 全观测内点 + Umeyama 精化 + 门槛 + 多解判定 + 连续帧先验。
3. **标志“识别不出来”**：旧版只给投影成功的标志画框。改为全部画框，投影失败标 `no ground`。
4. **固定不动仍跳动、偶发 x>4**：2 内点噪声大、错误配对残差也小。收紧 2 点残差门槛、先验半径、按内点数区分平滑，超过 0.8 m/20° 的跳变要连续 3 帧一致。
5. **标志闪烁、X/T 混淆、褶皱误检**：加短轨迹确认（连续帧 + 类别投票 + 像素平滑），匹配层 T/X 兼容；根因是数据覆盖不足（见任务 2 的独立 test）。
6. **按“实测 20°”跑不出位姿（`pair1-2`=0.55）**：两个 T 标志卷尺实测 45 cm（与地图一致），但程序只投出 16 cm；用该帧三个特征点反推，8° 时三角误差 <5 cm，且画面能看到围墙（说明光轴接近水平）。pitch 20°→**8°** 后 `pair1-2` 回到 1.00。
