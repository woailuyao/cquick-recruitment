## 四、一次失败案例与改进思路

- **现象**：Avatar 图第一组范围产生 13 个轮廓。
- **我是怎么查的**：用独立 TrackBars 比较三组 HSV 参数的 mask 和 result。
- **原因**：H 范围包含了较多蓝色背景。
- **改进**：将范围收窄到 `(75,100,70) → (90,255,255)`。
- **改进后效果**：得到 1 个轮廓，中心 `(765,585)`，面积 `5,824`，对应绿色眼睛。
